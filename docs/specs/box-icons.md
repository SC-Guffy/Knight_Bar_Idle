# 전리품 상자 아이콘 개성화 (16×16)

- 상태: 완료
- 브랜치: `season6`
- 관련 코드: src/box-art.js (BOX_ART·CHEST_ART), src/ui.js (boxIcon·raidChestIcon·paintGearIcons), src/drops.js (dropLook·dropSprite — 필드 드롭), dev/box-preview.py
- 최종 갱신: 2026-10-13

## 목표
원정 상자 8종과 레이드 처치 상자 16종(24종)이 12×12 모양 3개(crate·chest·jewelbox)를 색만 바꿔 쓴다. 장비 아이콘([gear-icons.md](gear-icons.md))과 같은 16×16 고유 도트로 바꿔,
등급 상자는 한눈에 서열이 보이고 레이드 상자는 보스가 보이게 한다. [색깔놀이 금지](../../CLAUDE.md).

## 규칙
- 16×16 + 자동 외곽선(18px), 직접 찍는 도트, 재질마다 3단계까지, 잔점 노이즈 금지 (gear-icons.md 와 같음).
- 바닥에 놓인 물건이라 아래쪽 줄(15번 줄)이 바닥에 닿게 그린다 (필드에서 상자가 떠 보이지 않게, drops.js 가 맨 아래 칠해진 줄을 땅에 맞춘다).
- **원정 상자 8종**: 등급이 오를수록 크고 화려해진다 — 실루엣으로 서열이 보이게.
  낡은 상자(작은 나무 궤짝, 못·금) → 나무 상자(둥근 뚜껑) → 철제 상자(쇠띠·리벳) → 기사단 보물상자(방패 문장) → 왕가의 보석함(작은 금 보석함, 왕관 장식) → 용의 보물궤(용 날개·발톱 장식) → 별의 성궤(별 박힌 성궤) → 태초의 함(빛나는 함, 떠 있는 고리).
- **레이드 처치 상자 16종**: 이름 그대로의 물건 + 보스 모티프 (data.js RAID_BOSSES[보스].chest.name·pal·desc).
  예: 리치 킹의 관 = 관, 그리폰 왕의 황금 둥지 = 둥지에 알·금, 수정 여왕의 알집 = 거미 알집, 콜로서스의 동력 금고 = 기계 금고.
- 화면: 가방·정산 카드 36px(2배), 필드 드롭은 기존 배율 그대로(일반 2배 · 보스 3배).
