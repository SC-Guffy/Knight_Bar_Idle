# 결투 시즌 상자 분리 · 결투 탭에서 받기

- 상태: **구현됨** (0.30.3, 사용자 확인 전)
- 관련 코드: src/season.js (SEASON_TIERS·seasonReward·claimSeasonReward), src/ui.js (loadSeason·takeSeasonRewards·viewSeason·seasonRewardText·campDots), src/raid.js (claimRaidChest·rollRareDrops 재사용), src/data.js (RAID_BOSSES chest, REROLL_DROP·RARE_DROP), server/season.js (시즌 3일 주기)
- 관련 원칙: 장비 수급(전설↑ 장비는 레이드 전용), 재화는 역할대로

## 문제

2026-10-22 사용자 보고: 아침에 "늪 군주의 이끼 궤" 3개가 들어와 있었다. 원인은 결투 시즌 7(10-22 00:00 KST 마감) 1위 보상이다.

지금 결투 시즌 보상은 순위에 따라 **레이드 처치 상자**를 준다. 상자 종류는 "열 수 있는 가장 높은 레이드 보스" 것이다(1위 3개, 2·3위 2개, 4~10위 1개). 이렇게 하면 두 가지가 어긋난다.
- 결투 보상인데 레이드 보스 상자가 나와서 버그처럼 보인다.
- 레이드를 하지 않아도 전설·신화 장비와 레이드 고유 장비가 나온다. "전설 이상 장비는 레이드 전용" 원칙과 맞지 않는다.

보상은 접속하면 자동으로 세이브에 들어가고 토스트로만 알린다. 그래서 무엇을 왜 받았는지 알기 어렵다.

## 목표

1. 결투 시즌 보상에서 레이드 처치 상자를 뺀다. 대신 결투 전용 **⚔️ 결투 시즌 상자**를 준다.
2. 보상은 자동으로 넣지 않는다. **랭킹(결투) 탭에서 직접 "받기"를 눌러서 받는다.**

## 규칙 (제안 수치 — 확인 필요)

### 1. 결투 시즌 상자 (`dbox`)

- 순위별 개수는 지금 그대로다. 1위 3개, 2·3위 2개, 4~10위 1개, 그 아래는 0개.
- 레이드 해금 여부와 상관없이 상자를 준다. 지금처럼 "레이드를 못 열면 상자 대신 재화 배율 +1"로 바꾸는 규칙은 없앤다.
- **장비는 들어 있지 않다.** 결투에서 레이드 장비가 새어 나가지 않게 하기 위해서다.
- 상자 하나에 들어 있는 것:

| 내용 | 양 | 비교 |
|---|---|---|
| 💠 강화석 | 100 + 최고 스테이지 × 1 | 늪 군주 상자의 장비 3~4개를 팔면 강화석 약 300개어치 |
| 🎲 재굴림권 | 3~5장 | 레이드 상자와 같다 (REROLL_DROP.raid) |
| 📖 비전서 | 2권 | 레이드 상자는 1~2권 |
| 📜 보호 주문서 | 25% 확률로 1장 | 레이드 상자 6%, 월드 보스 처치 30% |

  강화석을 장비 판매 환산값보다 낮게 잡는 이유가 있다. 결투는 3일마다 오는 보너스이고, 강화 쪽의 주 수급처는 레이드여야 하기 때문이다.
- 재화(골드·목재·철광석·마력석)와 비전서 보상은 지금 그대로 받는다. 순위 배율도 같다.

### 2. 받기 흐름

- 시즌이 끝나면 클라이언트가 서버 보상 행을 가져온다. 이 행은 **세이브의 "받을 보상" 목록(`S.season.pending`)에만 넣는다**. 재화·상자는 아직 넣지 않는다. 서버에는 지금처럼 ack 해서, 같은 시즌 보상이 두 번 오지 않게 한다(`claimed` 로도 막는다).
- 랭킹 탭 시즌 칸 맨 위에 **"🏆 시즌 N 보상 — 1위 · [받기]"** 카드가 뜬다. 탭 단추에는 레드닷이 붙는다.
- [받기]를 누르면 재화와 비전서가 들어오고, 결투 시즌 상자는 같은 카드 아래 "결투 상자" 칸에 쌓인다. 상자를 누르면 그 자리에서 열려 내용물을 보여 준다. "모두 열기" 버튼도 있다.
- 토스트 문구는 "결투 시즌 N 보상이 도착했어요 — 🏆 랭킹 탭에서 받기"로 바꾼다.
- 받지 않은 보상은 사라지지 않는다. 여러 시즌 것이 쌓이면 시즌마다 카드가 하나씩 뜬다.

### 3. 이미 받은 것

- 이미 들어간 레이드 상자(오늘 아침 늪 군주 상자 3개 등)는 회수하지 않는다.
- 업데이트 전에 자동으로 받은 시즌 보상은 그대로 둔다.

## 수용 기준

- [x] 시즌 보상으로 `S.raid.chests` 에 상자가 늘지 않는다 (레이드 탭 처치 상자 수 변화 없음).
- [x] 끝난 시즌 보상이 있으면 랭킹 탭에 받기 카드와 탭 레드닷이 뜨고, 받기 전에는 재화·비전서가 변하지 않는다.
- [x] [받기]를 누르면 순위표대로 재화·비전서가 들어오고, 결투 시즌 상자가 순위 개수만큼 생긴다.
- [x] 결투 시즌 상자를 열면 강화석·재굴림권·비전서가 들어오고 장비는 나오지 않는다. 보호 주문서는 확률로 나온다.
- [x] 새로 고침이나 재접속을 해도 받지 않은 보상과 열지 않은 상자가 남아 있고, 같은 시즌을 두 번 받을 수 없다.
- [x] 레이드를 아직 못 여는 기사도 상자를 받는다.
- [x] 순위별 보상 펼침 목록에 "⚔️ 결투 시즌 상자 ×N"이 보인다. "레이드 보스 처치 상자" 설명은 없어진다.

## 확인 방법

오프라인 주소 `http://localhost:8765/index.html?server=http://127.0.0.1:9&guild=0` (첫 로드 전 localStorage `knight-bar-accounts` = `{"active":"테스트","list":{"테스트":"local-test-token"}}`, 로드 후 8초 대기). 콘솔:

```js
window.ackSeason = async () => {}; window.pushSave = async () => {};
S.best = S.stage = 65; S.phase = 'camp';
S.season = { claimed: [7], pending: [{ season: 7, rank: 1, total: 40, rating: 1300, wins: 30, losses: 4 }], chests: 0, last: null };
save(); openCamp('rank'); rank.sort = 'duel'; renderCamp();
```

→ 랭킹 탭 맨 위 [받기] → 결투 시즌 상자 3개 → 하나 누르거나 "모두 열기". 서버 행이 들어오는 경로는 `await takeSeasonRewards([{ season: 8, rank: 2, total: 40 }])` 로 확인한다 (받을 목록에만 들어가고 재화는 그대로).

- 구현: `src/season.js` `DUEL_CHEST`·`queueSeasonReward`·`claimSeasonReward(i)`·`openDuelChest`, `src/ui.js` `viewSeasonClaim`·`claimSeasonAt`·`openDuelChestNow`, 액션 `season-claim`·`duel-chest-open`·`duel-chest-open-all`.
- 상자 그림은 기존 16칸 `chest` 도트에 은회색·붉은 팔레트를 입혔다 (`DUEL_CHEST.pal`). 전용 그림은 아직 없다.
