# 돌진기 (거리 좁히기) · 근접은 단단하게, 원거리는 약하게

- 상태: 완료
- 관련 코드: server/duel.js (simulateDuel · GAP), src/classes.js (SKILLS 의 `gap` · CLASSES 의 `mods.hp`), server/bot-curve.json, src/world.js (fightTick · dashSkill · duelX · dashGhost), src/skills.js (tryCastSkill 의 `only`), dev/duel-balance.js
- 최종 갱신: 2026-10-13

## 목표
결투는 양 끝(260px)에서 걸어와 사거리에 들어와야 때린다. 원거리(사거리 150~260)는 거의 바로 쏘고 근접(14~44)은 200px 가까이 걸어가야 해서,
근접이 붙기 전에 원거리가 공짜로 때린다. 돌진·도약 계열 스킬을 **멀리서 시전해 상대에게 달려붙는 이동기**로 만들고,
근접이라는 페널티는 결투 전용 보정이 아니라 **직업 특성**으로 메운다 — 몸으로 파고드는 전사·창기사 계열은 단단하고, 멀리서 쏘는 궁수·마법사 계열은 몸이 약하다. 근접 플레이어는 "돌진으로 단숨에 파고드는" 맛을 느껴야 한다.

## 규칙
- 돌진기 = SKILLS 에 `gap`(돌진 거리, px)이 있는 스킬. 서버 `server/duel.js` 의 `GAP` 표에도 같은 값 (옛 프로필·봇에도 바로 먹도록 서버가 id 로 정한다):
  | 스킬 | 직업 | gap |
  |---|---|---|
  | 강철 베기 steelCleave | 검사(1차) | 120 |
  | 관통 찌르기 piercingThrust | 창병(1차) | 120 |
  | 질풍난무 gale | 검호 | 180 |
  | 일섬 iaido | 검호 | 180 |
  | 용추락 dragonFall | 용기병 | 180 |
  | 대지 가르기 earthSplitter | 할버드 | 180 |
  | 돌진 격돌 ramCharge | 대검전사 | 180 |
  | 기병 돌격 cavalryCharge | 기병 | 180 |
- 돌진: 사거리 밖에서 돌진기가 준비됐고 `상대와의 거리 − 내 사거리 ≤ gap` 이면 **500px/s** 로 달려 사거리에 닿는 순간 그 스킬을 시전한다
  (피해·쿨타임·시전 시간은 원래 스킬 그대로). 여러 개면 목록 앞쪽. 이미 사거리 안이면 평범한 스킬로 쓴다.
- 결투:
  - 돌진기는 개전 0.3초에 준비되고 걸어가는 동안에도 쿨타임이 돈다 (다른 스킬은 지금처럼 교전 시작 후부터, 0.3 + 순번×1.5초).
  - 원거리끼리의 결투는 바뀌지 않는다 (같은 seed 결과 동일).
- 원정·도전의 탑·재료의 미궁 (`fightTick`): 돌진기 쿨타임은 원래 원정 내내 흐른다. 앞의 적이 사거리 밖이고 돌진 거리 안이면 달려붙어 시전한다. 걷는 속도는 그대로.
- 레이드는 돌진 규칙이 바뀌지 않는다.
- 직업 체력 (`CLASSES[*].mods.hp`, 모든 콘텐츠에 적용): 1차 이상 근접 직업은 이전 값 ×1.1, 원거리 직업은 ×0.9 (소수 둘째 자리 반올림).
  예: 검사 1.25→1.38 · 창기사 1.25→1.38 · 레인저 1.0→0.9 · 마법사 0.95→0.85 · 천마장군 2.7→2.97 · 신궁 1.55→1.4. 견습 기사는 그대로.
  봇 성장 곡선(server/bot-curve.json)도 새 값으로 다시 구웠다.
- 2차 조정 (같은 전투력 리그전 결과로, 사용자 선택 '직업 특성 보강'):
  - 검사 1차 강철 베기도 돌진기 (gap 120) — 검사 계열만 1차 돌진기가 없어 초반에 밀렸다.
  - 대검전사·파천검왕·검성·검신 `guard: 0.15` (받는 피해 −15%, 막기 기술). 성기사 계열은 이미 guard 가 있어 제외.
  - 석궁 계열 사거리: 거대 석궁 200→160, 공성 석궁 240→200 (공성포수가 같은 전투력에서 61~82%).
- 3차 조정 (튀는 직업, 시드 4벌 곡선 평균 리그전으로 진단):
  - 진단: 결투가 2~3초라 시작 직후 스킬 한두 개가 승부를 내는데, 전투력은 쿨타임 평균 지속 DPS 라 어긋난다. 그래서 '튀는 스킬'은 결투에서만 튀는 것 —
    스킬 배율을 결투에 맞추면 원정이 틀어지므로 스킬 수치는 두고 직업 특성(사거리·받는 피해 감소)으로 맞췄다.
  - 결투 길이 늘리기(체력 배수에 스킬 DPS 포함, DUEL_SEC 12·20)도 시험했지만 회복·피해 감소 직업(성좌기사)이 73~90% 로 치솟아 폐기.
  - 사거리: 장궁(저격수) 230→180 · 공성 석궁 200→180 · 화염 지팡이 160→180 · 뇌전 지팡이 165→185 · 마력궁 170→190 · 뇌제의 홀 175→195.
  - 받는 피해 감소: 성기사 0.25→0.15 · 랜서 0.2→0.1 · 빙결술사 0.1→0 · 용기병·용황 0→0.1 (용의 비늘).

## UI
- 돌진하는 동안 기사는 빠른 걸음 모션 + 0.05초마다 직업 색 잔상(0.22초)을 남긴다 (원정 기사·결투 재생 공용 `dashGhost`).
- 결투 기록: `moves[side].dash = { t, x }`(돌진 시작 시각·위치), `fight.dashSpeed`.
  예전 클라이언트는 이 값을 몰라 걷는 모습으로 재생한다 (위치만 덜 따라감, 결과는 같음).

## 밸런스 근거 (`node dev/duel-balance.js 40,80,120,150 150`)
봇 성장 곡선의 3차 계열 12종(근접 6·원거리 6)을 같은 최고 스테이지끼리 리그전. 기본은 **전투력 정규화**(공격력·체력에 같은 배수를 곱해 모든 계열 전투력을 평균에 맞춤) —
같은 전투력이면 근접 vs 원거리가 50% 근처여야 공정하다.

| 근접 vs 원거리의 근접 승률 | St40 | St80 | St120 | St150 |
|---|---|---|---|---|
| 이전 | 29% | 17% | 12% | 20% |
| 돌진기만 | 41% | 46% | 35% | 48% |
| 돌진기 + 근접 2배 걸음 (폐기) | 47% | 52% | 41% | 51% |
| 돌진기 + 결투 전용 근접 체력 ×1.15 (폐기) | 53% | 54% | 42% | 53% |
| **돌진기 + 직업 체력 근접 ×1.1 · 원거리 ×0.9 (적용)** | **57%** | **56%** | **41%** | **54%** |
| (참고) 모두 같은 사거리 — 순수 직업 성능 | 54% | 61% | 52% | 61% |

- 원거리가 먼저 때리는 시간: 평균 1.7~2.4초 → 0.4~0.6초.
- 새 곡선(직업 체력 반영해 다시 구움)으로 본 같은 리그전: 전투력 정규화 36/46/41/45%, 곡선 그대로 54/73/63/75% (변경 전 곡선+돌진 64/76/56/84%).
  직업 체력은 전투력(√(DPS×체력)) 숫자에도 들어가서, 근접은 같은 진행도에서 전투력 숫자가 더 높다 → 전투력 숫자를 맞추면 근접이 손해처럼 보인다.
  그래서 이 변경의 공정성은 위 표의 '같은 진행도(이전 전투력)에서 체력만 바꾼' 비교로 본다. 곡선 그대로는 계열당 시드 하나라 흔들림이 크다.
- 봇 곡선 12일 최고 스테이지: 근접 오름(아르콘 140→160, 전쟁군주 158→169, 파천검왕 166→174), 원거리 줄지 않음(신궁 148→160, 나머지 160 안팎 — 160 은 필드 보스 관문).
- 돌진 거리를 1.25배로 늘려도 +1~3%p 뿐이라 거리는 그대로 두었다.
- 직업 체력 후보 (근접/원거리): 1.1/0.9 57/56/41/54 · 1.15/0.9 60/57/42/55 · 1.1/0.85 61/58/42/56 · 1.2/0.9 63/59/43/57. 같은 진행도(이전 전투력)에서 체력만 바꾼 비교.
- 원정 영향 (진행 봇, 계열별 4일·12일 최고 스테이지): 1.1/0.9 는 시드 오차 범위 — 원거리도 느려지지 않았다 (원거리는 몬스터가 붙기 전에 쏘므로 체력 의존이 작다).
- 경과: 근접 걸음 2배 → (사용자) "이동 속도보다 몸이 단단한 쪽" → 결투 전용 체력 ×1.15 → (사용자) "보정 말고 직업 특성으로, 결투뿐 아니라 전사·창기사는 단단하고 마법사·궁수는 약하게" → 직업 체력.
- St120 이 낮은 건 서리군주(frostlord)가 사거리와 상관없이 89% 로 튀고 아르콘(성기사, 돌진기 없음)이 38% 라서다.
- 곡선 그대로(raw, 정규화 없음)는 근접 58~84% — 곡선상 같은 스테이지의 근접 계열이 전투력이 더 높아서다. 결투 상대는 점수(Elo)로 붙으니 공정성은 같은 전투력 기준으로 본다.

- [x] 원거리끼리 결투 결과(같은 seed 90판)는 바뀌지 않는다 — 전후 결과 해시 동일.

- [x] 같은 진행도 근접 vs 원거리 승률 41~57% (위 표).
- [x] 직업 체력이 원정 진행을 크게 흔들지 않는다 — 진행 봇 계열별 비교 (위).
