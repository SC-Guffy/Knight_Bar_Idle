# 직업 캐릭터 통짜 스프라이트 전환 (초안)

- 상태: 초안. 도구 시험 전이라 구현은 아직 하지 않았고, 스펙도 확정 전이다.
- 관련 코드: `src/body2.js` (몸통 22×26), `src/limbs.js` (팔), `src/motion/*.js`·`src/cuts/*.js` (평타 컷), `src/jobs/*.js`, `src/classes.js` `CLASSES`
- 최종 갱신: 2026-10-13

## 목표

직업 캐릭터를 몸통·팔·다리·무기를 따로 조립하는 방식에서 **통짜 스프라이트 시트**(동작별 프레임)로 바꾼다.
사용자는 부위를 따로 움직이는 방식이 모션에서 어색하다고 느낀다. 몬스터보다 직업 캐릭터 퀄업이 우선이다.

## 대상

- 직업 29종: 견습 1, 1차 4, 2차 12, 3차 12 (`classes.js` `tier`)
- 직업마다 필요한 동작 후보: 대기, 걷기, 평타(무기별 연속기 1~2개), 스킬 시전, 피격, 사망, 마을 앉기
- [색깔놀이 금지](../../CLAUDE.md), 2차에서 3차로 특징 잇기 규칙은 기준 그림 단계에서 지킨다.

## 다음 단계

1. (사용자, 회사 PC) PixelLab 가입 → 무료 체험으로 견습 기사(squire) 1종 시험: 기준 그림 → 대기·걷기·평타·시전·사망
2. 마음에 들면 API 토큰을 Windows 사용자 환경변수 `PIXELLAB_API_KEY` 에 등록한다 (값은 출력·기록·커밋 금지). 한 달 정액으로 29종을 몰아서 만든다.
3. Claude: 이 스펙을 확정한다. 시트 규격(프레임 크기·화면 배율), 무기·이펙트 기준점(손·화살 발사 위치), 기존 조립 코드를 어떻게 걷어 낼지를 정한 뒤 견습 기사부터 게임에 적용하고 기존과 비교 스크린샷을 찍는다.
