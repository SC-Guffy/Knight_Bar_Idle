# 재굴림권 넉넉히 뿌리기

- 상태: 완료
- 관련 코드: src/data.js (`REROLL_DROP`, `RARE_DROP`), src/gear.js (`openBox`), src/raid.js (`claimRaidChest`, `rollRareDrops`), src/worldboss.js (`claimWbReward`), src/ui.js (보상 문구·토스트)
- 최종 갱신: 2026-10-14

## 목표
🎲 재굴림권이 확률 뽑기(레이드 상자 6%·월드 보스 15~30%)라 거의 안 나왔다. 옵션 재굴림을 실제로 돌려 볼 수 있게 적당히 뿌린다.
사용자 기준: "원정에서도 1~2장, 레이드 가면 3~5장".

## 규칙
- 원정: 전리품 상자를 열 때마다 12% 확률로 재굴림권 1장이 상자 내용물에 더 붙는다 (`REROLL_DROP.box`). 원정 1회 상자 약 13개 → 평균 약 1.5장.
  - 소비 아이템 칸(`SUPPLIES.w`)과는 따로 굴리므로 보호 주문서·다른 보급품 드롭은 그대로다.
- 레이드 처치 상자: 하나 열 때마다 3~5장 확정 (`REROLL_DROP.raid`).
- 월드 보스 하루 보상: 3~5장 확정 (`REROLL_DROP.wb`, 사용자 선택: "레이드와 같게"). 잡은 날·못 잡은 날 같다. 보상에 딸린 레이드 처치 상자는 열 때 따로 3~5장.
- 📜 보호 주문서는 그대로 (레이드 상자 6%, 월보 15%/잡은 날 30%).
- 상점 판매는 여전히 없음.

## UI
- 원정 상자를 열면 내용물 줄에 🎲 재굴림권이 한 칸으로 나온다.
- 레이드 상자 토스트 `🎲 재굴림권 +n`, 월드 보스 보상 문구 `🎲 재굴림권 n`.
- 재굴림대 칩 툴팁·부족 안내: "원정 상자에서 가끔, 레이드 처치 상자·월드 보스 보상에서 3~5장씩".
