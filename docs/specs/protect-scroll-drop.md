# 보호 주문서 드롭 전용 · 보급품 가격 절반

- 상태: 완료
- 관련 코드: src/data.js (`SUPPLIES.protect`), src/core.js (`buySupply`), src/ui.js (`viewSupplies`), src/gear.js (`rollLoot`)
- 최종 갱신: 2026-10-13

## 목표
보호 주문서는 골드로 사서 쓰는 소모품이 아니라 원정에서 운 좋게 줍는 귀한 아이템이어야 한다.
상점(🏠 홈 보급품)에서는 빼고, 그만큼 상자에서 더 자주 나오게 풀어 준다.

## 규칙
- 보호 주문서는 살 수 없다. `SUPPLIES.protect.shop = false` — 보급품 목록에 나오지 않고 `buySupply('protect')` 는 거절한다.
- 얻는 곳: 원정 전리품 상자 (`rollLoot` 의 소비 아이템 칸). 우편·운영 지급은 그대로.
- 드롭 가중치 `w` 4 → 60 (소비 아이템 칸 안에서 다른 보급품 합 100 대비, 사용자 선택: "원정마다 1장 가까이").
  - 전리품 1개당 확률: 일반 0.58% → 5.6%, 보스 첫 칸 0.38% → 3.75%
  - 원정 1회(상자 13개 중 보스 3개) 기대: 약 0.09장 → 약 0.92장
  - 같은 칸을 나눠 쓰므로 다른 보급품 드롭은 원정당 약 2.4개 → 1.5개로 준다 (대신 값이 절반)
- 보급품 가격(최고 스테이지 몬스터 골드 배수) 절반: 도시락 30→15, 회복 물약 20→10, 행운의 부적 60→30, 투지의 영약 60→30.
- 이미 가진 주문서는 그대로 남는다. 쓰는 규칙(하락·초기화가 있는 단계에서 강화마다 1장)은 그대로.

## UI
- 🏠 홈 보급품 줄에서 보호 주문서 줄이 사라진다.
- 대장간 강화 패널의 `📜 보호 주문서 (보유 n)` 체크는 그대로. 설명에 "원정 상자에서만 나옴"을 붙인다.

## 수용 기준
- [x] 홈 보급품 목록에 보호 주문서가 없다 — `viewSupplies()` 출력에 4줄(도시락·물약·부적·영약)만
- [x] 콘솔에서 `buySupply('protect')` 가 false, 골드·보유량 그대로
- [x] 상자 드롭 비율: `rollLoot` 10만 번 → 일반 5.59%, 보스 첫 칸 3.78%; `openBox` 원정 2만 회 → 원정당 0.92장
- [x] 보급품 구매가가 전보다 절반 — `SUPPLIES` price 15·10·30·30, 홈 버튼 30·20·60·60 (1스테이지 골드 ×2)
- [x] 강화 패널 보호 주문서 체크 — 코드 변경 없음(설명 문구만 추가)
