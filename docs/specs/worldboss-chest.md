# 월드 보스 처치 상자 분리

- 상태: **구현됨** (0.30.4, 사용자 확인 전)
- 관련 코드: src/worldboss.js (wbReward·claimWbReward), src/ui.js (takeWbRewards·wbRewardText·viewWbNews·월드 보스 칸·campDots raid), src/raid.js (rollRareDrops 재사용), src/data.js (WORLD_BOSSES, RARE_DROP·REROLL_DROP)
- 앞선 작업: [duel-season-chest.md](duel-season-chest.md). 결투 시즌 보상에서 레이드 처치 상자를 뺀 것과 같은 이유로 바꾼다.
- 관련 원칙: 장비 수급(전설↑ 장비는 레이드 전용), 재화는 역할대로

## 문제

월드 보스를 잡은 날에는 참가자 모두가 처치 보상으로 **레이드 처치 상자 1개**를 받는다. 상자 종류는 "열 수 있는 가장 높은 레이드 보스" 것이다.
- 월드 보스 보상인데 레이드 보스 상자가 나와서 버그처럼 보인다.
- 레이드를 하지 않아도 전설·신화 장비와 레이드 고유 장비가 나온다.
- 레이드를 아직 못 여는 기사는 상자 대신 재화를 ×1.5 받는다. 같은 처치인데 보상 종류가 갈린다.

## 목표

1. 월드 보스 처치 보상에서 레이드 처치 상자를 뺀다. 대신 그날 보스 이름이 붙은 **🌍 월드 보스 전리품 상자**를 준다.
2. 보상은 자동으로 넣지 않는다. 결투 시즌처럼 **🐉 레이드 탭에서 [받기]를 눌러서 받는다** (2026-10-22 사용자 결정).

## 규칙 (제안 수치 — 확인 필요)

### 1. 상자 (`S.wb.chests`)

- 보스를 잡은 날, 참가한 기사 모두에게 1개를 준다. 지분과 상관없이 같다(지금과 같음).
- 레이드 해금 여부와 상관없이 준다. "레이드를 못 열면 재화 ×1.5"는 없앤다.
- 이름은 그날 보스를 따른다. 대지의 베헤모스의 전리품 상자, 아홉 머리 히드라의 전리품 상자, 공허룡의 전리품 상자.
- **장비는 넣지 않는다.** 결투 시즌 상자가 강화 쪽(강화석·보호 주문서)이라면, 월드 보스 상자는 **재료 쪽**으로 잡는다. 지금 건물 병목이 🪵 목재·🪨 철광석이라서다.

| 내용 | 양 (S = 최고 스테이지, scale = 1 + (S−1)×0.04) | 65스테이지 예 |
|---|---|---|
| 🪵 목재 | 60 × scale | 214 |
| 🪨 철광석 | 45 × scale | 160 |
| 💎 마력석 | 12 × scale | 43 |
| 💠 강화석 | 50 + S × 0.5 | 82 |
| 🎲 재굴림권 | 2~3장 | |

  - 목재·철광석·마력석은 평균 지분(3몫) 하루 보상과 비슷한 양이다. 잡은 날은 재료를 하루치 더 받는 셈이다.
  - 강화석은 결투 시즌 상자(100 + S)보다 낮게 잡았다. 결투 상자는 3일에 한 번이고, 월드 보스는 매일 잡힐 수 있어서다.

- 상자 밖 처치 보상(강화석 +5, 비전서 +3, 보호 주문서 확률 30%)은 지금 그대로 둔다.

### 2. 받기·열기

- 날이 바뀐 뒤 접속하면 서버 보상 행을 가져와 **세이브의 받을 목록(`S.wb.pending`)에만 넣는다.** 서버에는 지금처럼 ack 하고, `claimed` 로 같은 날을 두 번 가져오지 않게 막는다.
- 🐉 레이드 탭 맨 위에 **"🌍 월드 보스 보상 — ○○ 처치 ✅ · N명 중 M위 · 보상 · [받기]"** 카드가 날마다 하나씩 뜬다. 탭에는 점이 뜬다.
- [받기]를 누르면 재화·강화석·비전서가 들어오고, 재굴림권·보호 주문서를 굴린다. 처치한 날이면 상자가 "월드 보스 상자" 칸에 쌓인다. 이 칸은 레이드 처치 상자 칸과 따로다.
- 상자를 누르면 그 자리에서 열려 내용물 카드가 보인다. "모두 열기"도 있다. 안 연 상자가 있어도 레이드 탭에 점이 뜬다.
- 토스트 문구: "🌍 월드 보스 보상이 도착했어요 — 🐉 레이드 탭에서 받기".

### 3. 이미 받은 것

- 이미 받은 레이드 처치 상자는 회수하지 않는다. 지난 보상 기록에는 원래 이름(레이드 상자)으로 보인다.

## 수용 기준

- [x] 월드 보스 처치 보상으로 `S.raid.chests` 가 늘지 않는다.
- [x] 보상이 도착하면 레이드 탭에 받기 카드와 점이 뜨고, [받기] 전에는 재화가 변하지 않는다. 같은 날 보상은 두 번 받을 수 없다.
- [x] 처치한 날 보상을 [받기]로 받으면 `S.wb.chests` 가 1 늘고, 월드 보스 칸에 그날 보스 이름의 상자가 보인다.
- [x] 상자를 열면 목재·철광석·마력석·강화석·재굴림권이 들어오고 장비는 나오지 않는다.
- [x] 레이드를 못 여는 기사도 상자를 받고, 재화 ×1.5 는 붙지 않는다.
- [x] 보스가 살아남은 날은 상자가 없다.
- [x] 새로 고침 후에도 받지 않은 보상과 안 연 상자가 남아 있다.
- [x] 보상 문구(지난 보상 줄·토스트)에 "🌍 ○○의 전리품 상자"가 나온다. 옛 기록은 레이드 상자 이름 그대로 보인다.

## 확인 방법

오프라인 주소 `http://localhost:8765/index.html?server=http://127.0.0.1:9&guild=0` (준비는 [duel-season-chest.md](duel-season-chest.md) "확인 방법"과 같다). 콘솔:

```js
window.ackWorldBoss = async () => {}; window.pushSave = async () => {};
S.best = S.stage = 65; S.phase = 'camp';
await takeWbRewards([{ day: 100, boss: 'hydra', dmg: 500, rank: 3, total: 3000, players: 6, killed: true },
                     { day: 101, boss: 'voidwyrm', dmg: 200, rank: 5, total: 5000, players: 6, killed: false }]);
openCamp('raid'); renderCamp();
```

→ 레이드 탭 맨 위 받기 카드 2장 → 처치한 날 [받기] → "월드 보스 상자" 칸에 🐍 전리품 상자 → 누르거나 "모두 열기".

- 구현: `src/worldboss.js` `WB_CHEST`·`WB_CHEST_PAL`·`queueWbReward`·`claimWbReward(i)`·`openWbChest(i)`, `src/ui.js` `viewWbClaim`·`claimWbAt`·`openWbChestAt`, 액션 `wb-claim`·`wb-chest-open`·`wb-chest-open-all`.
- 상자 재료에도 장비 옵션 🎲 "목재·철광석·마력석 획득"(matPct)이 붙는다 (다른 재료 보상과 같게).
- 상자 칸 이름은 짧게 "🐍 전리품 상자", 전체 이름("아홉 머리 히드라의 전리품 상자")은 툴팁·보상 문구에.
