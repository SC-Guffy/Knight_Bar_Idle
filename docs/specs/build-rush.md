# 건설 즉시 완료

- 상태: 완료 (0.21.1)
- 관련 코드: src/data.js (`BUILD_RUSH_GOLD`), src/core.js (`rushPrice`·`rushBuild`), src/ui.js (`viewTown` 건설 중 카드, `LIVE.rushPrice`, `tickLive`, 액션 `build-rush`)
- 최종 갱신: 2026-10-14

## 목표
사용자: "건물 대기시간이 너무 길다. 재화 써서 완료하는 기능." 건설 시간(×1.8/Lv)은 그대로 두고, 남는 골드로 기다림을 살 수 있게 한다 (골드 소비처 겸).

## 규칙
- 건설 중인 건물은 언제든 골드로 바로 끝낼 수 있다. 끝나면 보통 완공과 똑같이 처리(`advanceBuild` — 창고 비축 정산·여관 스태미나·완공 토스트).
- 가격 = 남은 분(올림) × 최고 스테이지 잡몹 골드(`monsterStats(S.best).gold`) × **2.2** (`BUILD_RUSH_GOLD`).
  진행 봇 기준 원정 1시간 ≈ 잡몹 263마리 → 남은 1시간 ≈ 원정 30분 골드 (사용자 선택). 기다릴수록 싸지고, 스테이지를 따라 오른다(교역과 같은 방식).
- 예: 스테이지 121 · 훈련장 Lv9→10(1시간 50분) ≈ 1.55T.

## UI
- 마을 건물 카드의 건설 중 칸: 진행 막대 · 남은 시간 아래 `즉시 완료 · 🪙 가격` 버튼. 가격은 틱마다 갱신, 골드가 모자라면 비활성.
