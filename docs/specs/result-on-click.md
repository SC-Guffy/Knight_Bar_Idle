# 결과는 눌러야 본다

- 상태: 구현 (0.28.12, 사용자 확인 전)
- 관련 코드: src/ui.js (`onRaidResult`·`raidCatchUp`·`openCamp`·`campStatus`·`campDots`·`startDuel`·`tellInbox`·`takeSeasonRewards`·`takeWbRewards`·`hooks.onTowerEnd/onDungeonEnd/onCastleEnd`), src/season.js, src/worldboss.js
- 최종 갱신: 2026-10-20

## 목표

콘텐츠 결과(승패·보상·순위)가 갑자기 창을 가리거나 토스트로 지나가 버리지 않게 한다. 원정처럼 **"끝났어요 — 기사를 눌러 확인"** 까지만 알리고, 결과는 플레이어가 눌렀을 때 본다.

계기 (2026-10-20): 캠프 창을 보며 다른 사람에게 설명하던 중 레이드 결과가 와서 캠프 창이 닫히고 전투 재생 → 정산 창이 자동으로 열려 당황.

## 규칙

1. **알림 토스트에는 결과를 넣지 않는다.** "무엇이 끝났다 / 도착했다 + 어디를 누르면 본다" 만. 승패·점수·순위·얻은 재화·층수 등은 빼고 정산 화면에서 보여 준다.
   - 내가 방금 누른 동작의 즉시 피드백(강화·분해·구매·노드 찍기 등)은 이 규칙 대상이 아니다 — 눌러서 나온 결과다.
2. **창을 저절로 닫거나 열지 않는다.** 서버에서 결과가 도착해도 캠프 창·현재 화면은 그대로 둔다.
3. 확인 안 한 결과는 **기사 말풍선 ❗ + 해당 탭 레드닷**으로 남는다 (탑·미궁·성벽의 `last.seen === false` 방식과 같게).

### 콘텐츠별

| 콘텐츠 | 지금 | 바꾼 뒤 |
|---|---|---|
| 🐉 레이드 | 결과 도착 → 캠프 창 강제 닫힘 → 하단바 전투 재생 → 정산 창 자동 열림. 1초마다 한가하면 자동 재생 | 결과 도착 → 토스트 "🐉 레이드 전투가 끝났어요 — 기사를 눌러 확인하세요" + 말풍선 ❗ + 레이드 탭 점. **기사를 누르면**(또는 레이드 탭의 "⚔️ 전투 보기") 그때 재생 → 끝나면 정산 창. 자동 재생 없음 |
| 🐉 레이드 (기사단, 안 보는 기사) | 토스트에 승패 | 승패 빼고 "레이드가 끝났어요 — 이 기사로 가서 확인" |
| ⚔️ 결투 (신청한 쪽) | 재생 뒤 / 다른 화면으로 갔으면 토스트로 승패·점수 | 재생은 그대로(직접 건 것). 재생이 끝나면 토스트 대신 결과를 "안 본 결투"로 남기고 말풍선 ❗ + 랭킹 탭 점 → 기사를 누르면 랭킹 탭 맨 위에 결과. 다른 화면에 있었으면 "결투가 끝났어요 — 기사를 눌러 확인" |
| 📬 받은 결투 (방어) | 토스트에 방어 성공/패배·점수 | "📬 받은 결투 N건 — 🏆 랭킹 탭에서 확인" (결과 숫자 뺌) |
| 🏆 결투 시즌 보상 | 토스트에 등급·순위·보상 | "🏆 결투 시즌 보상이 도착했어요 — 🏆 랭킹 탭에서 확인" + 랭킹 탭 점(볼 때까지). 탭에 이미 있는 "내 보상" 줄로 확인 |
| 🌍 월드 보스 하루 보상 | 토스트에 처치·순위·보상 | "🌍 월드 보스 보상이 도착했어요 — 🐉 레이드 탭에서 확인" + 레이드 탭 점(볼 때까지) |
| 🗼 탑 / ⛏️ 미궁 / 🏰 성벽 끝 | 토스트에 층수·얻은 재화 + "기사를 클릭해 정산" | 결과 빼고 "🗼 도전이 끝났어요 — 기사를 눌러 정산을 확인하세요" (정산 화면은 그대로) |

기사를 눌렀을 때 여는 순서: 원정 정산 → 레이드 재생 → 탑 → 미궁 → 성벽 → 안 본 결투(랭킹) → 그 밖.

## UI

- 말풍선: 레이드 결과 대기 중이면 `❗ 레이드 정산`, 안 본 결투면 `❗ 결투 결과`.
- 레이드 탭: 대기 중인 결과가 있으면 맨 위에 "🐉 ○○ 레이드가 끝났어요 [⚔️ 전투 보기]" 한 줄(승패는 안 씀).
- 랭킹 탭: 안 본 결투 결과는 기존 "최근 결투 — …" 줄로 보여 주고, 탭을 열면 본 것으로 친다.

## 수용 기준

- [x] 캠프 창을 열어 둔 채 레이드 결과가 도착해도 창이 닫히지 않고, 토스트에 승패가 없다.
- [x] 그 뒤 기사를 누르면 레이드 재생 → 정산 창이 열린다. 레이드 탭의 "⚔️ 전투 보기" 로도 된다.
- [x] 방치하면 레이드가 저절로 재생되지 않는다 (`raidCatchUp` 자동 재생 제거).
- [x] 레이드 대기실을 보고 있을 때(출정을 누름 / 준비하고 기다림) 결과가 오면 '전투 보기'를 거치지 않고 바로 재생한다 (사용자 지시 10-21).
- [x] 재생 기록이 없을 때(`raidUi.queued` 없음)도 서버 방에 그 결과가 남아 있으면 그걸로 재생한 뒤 보상이 들어온다. 방도 사라졌을 때만 바로 정산 (`watchRaid` → `finishRaid`).
- [x] 앞 판 전투를 보기 전에는 출정·같은 파티로 다시 도전·준비를 못 한다 — 그 자리에 "⚔️ 전투 보기". (새 결과가 오면 `settleRaid` 가 앞 판을 재생 없이 지급해 버리던 구멍)
- [x] 결투 재생이 끝나면 결과 토스트 대신 말풍선 ❗, 기사를 누르면 랭킹 탭에 결과.
- [x] 받은 결투·시즌 보상·월드 보스 보상 토스트에 숫자 결과가 없고, 해당 탭에 점이 뜨며 탭을 보면 꺼진다.
- [x] 탑·미궁·성벽 끝 토스트에 결과가 없다.

## 확인 방법

오프라인: `.claude/launch.json` `result-web`(9083) → `http://localhost:9083/index.html?server=http://127.0.0.1:9&guild=0` (localStorage `knight-bar-accounts` 는 docs/dev-testing.md). 재생용 기록은 서버 계산기로 만든 `dev/review/result-on-click-raid.json`·`result-on-click-duel.json`.

```js
// 레이드 결과 도착 (캠프 창을 열어 둔 채)
openCamp('town');
const res = await (await fetch('dev/review/result-on-click-raid.json')).json(); res.id = 'demo-' + Date.now();
onRaidResult(res);          // → 창 그대로, 말풍선 ❗ 레이드 정산, 레이드 탭 점 + '⚔️ 전투 보기'
// 결투 결과 (서버 대신 기록 주입)
closeCamp();
const d = await (await fetch('dev/review/result-on-click-duel.json')).json();
window.requestDuel = async () => d; startDuel('연습상대');   // 재생 뒤 ❗ 결투 결과 → 기사 클릭 = 랭킹 탭
// 시즌·월드 보스 보상 (서버 호출 막고)
window.pushSave = async () => {}; window.ackSeason = async () => {}; window.ackWorldBoss = async () => {};
takeSeasonRewards([{ season: 999, rank: 3, total: 40 }]);
takeWbRewards([{ day: 'test-' + Date.now(), boss: Object.keys(WORLD_BOSSES)[0], killed: true, players: 12, rank: 2, dmg: 500, total: 3000 }]);
```

미리보기 창이 뒤에 있으면 재생이 거의 안 흐른다 → `for (let i=0;i<900 && raidActive();i++) update(1/30)`.
