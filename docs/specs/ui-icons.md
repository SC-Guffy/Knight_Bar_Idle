- 상태: 완료 (0.19.22 — 화면·캔버스의 이모지 전부 도트 + 스킬 40종 고유 배지, 아이콘 224개)
- 관련 코드: `dev/make-icons.js` (도트 데이터·생성기) → `src/skin/icons.png`·`src/skin/icons.css` (생성물), `src/iconmap.js` (생성물: 이모지 → 이름, 칸 순서), `src/ui.js` `ico()`·`iconize()`, `src/icondraw.js` (캔버스), `dev/icon-art/*.js` (묶음별 그림), `dev/icon-preview.py` (미리보기 PNG), `dev/icons.html` (이모지 비교 페이지)
- 최종 갱신: 2026-10-13

## 목표

UI 퀄업 1번 ([art-upgrade.md](art-upgrade.md) "UI 퀄업 방향"). OS 이모지는 매끈한 고해상도라 도트 글꼴(Galmuri11)·도트 테두리 사이에서 튄다.
UI 톤(남보라 바탕 + 바랜 은 선)은 그대로 두고, 이모지만 같은 격자의 도트 아이콘으로 바꿔 화면을 한 벌로 맞춘다.

## 규칙

- 크기: 그림 12×12 + 잉크 외곽선 1px = 14×14. 화면에는 1배(14px)로, 크게 쓸 때는 정수배(`.x2` = 28px)로만.
- 그리기: 직접 픽셀을 찍는다 (AI 생성은 노이즈가 많아 쓰지 않는다, 참고용만). 큰 색 덩어리, 면마다 밝음/보통/그늘 3단계까지, 잔점 노이즈 금지.
  외곽선은 생성기가 칠해진 칸 상하좌우에 자동으로 두른다 (장비 아이콘 `gearSprite` 와 같은 방식). 안쪽 잉크선은 글자 `K`.
- 팔레트 (`dev/make-icons.js` `PAL`): 잉크 `#0b0a14`, 종이 `#ebe7dc`, 바랜 은 `#b9b4cc`/`#8f8aa8`/`#5e5a78`, 금 `#fff2b8`/`#e0c472`/`#a8842e`,
  빨강·초록·파랑·나무·양피지·청록·보라·분홍·주황 각 2단, 짙은 회색 `k`. 새 색이 필요하면 팔레트에 추가하고 여기 적는다.
- **재화 아이콘은 실루엣만으로 구분** (흑백·멀리서 봐도): 금화 = 동그라미, 목재 = 사선 통나무, 철광석 = 바닥 평평한 넓은 바위(봉우리 둘), 마력석 = 아래로 뾰족한 보석 ▽, 강화석 = 위로 솟은 결정 셋 ▲▲▲. 새 재화도 기존 다섯과 윤곽이 겹치지 않게 그린다.
- [색깔놀이 금지](../../CLAUDE.md): 아이콘끼리 색만 다른 같은 모양을 만들지 않는다 (예: 홈 = 집 한 채, 마을 = 망루 + 집).
- 구현: `dev/make-icons.js` 가 스프라이트 시트 SVG 한 장 + CSS(`.pi` 공통, `.pi-<이름>` 위치)를 만든다. HTML 에서는 `ico('이름')` → `<i class="pi pi-이름"></i>`.
  - 런타임 canvas → data URL 방식은 index.html CSP(`default-src 'self'`)가 `data:` 이미지를 막아서 안 된다 (첫 시도에서 확인).
  - 생성: `node dev/make-icons.js` (Node 가 없으면 docs/dev-testing.md 의 VS Code 내장 Node).
  - `#campModal nav i` 는 탭 숫자 배지 스타일이라 `:not(.pi)` 로 아이콘을 뺐다. 다른 곳에서 `i` 태그 선택자와 겹치면 같은 식으로 뺀다.
  - **화면 전체 자동 변환** (`ui.js` `iconize`): MutationObserver 가 문서에 들어오는 글자 노드를 훑어 `ICON_OF`(src/iconmap.js) 에 있는 이모지를
    `<i class="pi pi-이름">이모지</i>` 로 바꾼다. 아이콘 안에 원래 이모지를 투명 글자(`font-size: 0`)로 품어서 `textContent` 비교(tickLive·setIcoText)·복사가 그대로다.
    title 같은 속성(브라우저 툴팁), 입력칸, 캔버스는 건드리지 않는다. 표에 없는 이모지는 그대로 남는다 → 새 이모지를 쓰면 그림도 추가한다.
    토스트·설명 문장·데이터 아이콘(직업·지역·스킬·몬스터)도 이 경로로 바뀐다. 트레이 제목(`updateTray`)은 OS 글자라 이모지 유지.
  - **캔버스** (`src/icondraw.js`): `fillTextIco/strokeTextIco/measureTextIco(g, …)` 가 `g.fillText` 등을 대신한다 (world·skills·drops·town·ui 의 호출을 전부 바꿈).
    이모지가 없으면 원래 함수 그대로, 있으면 글자 조각과 스프라이트 칸을 차례로 그린다. 아이콘 크기는 글꼴 크기/14 반올림 정수배.
  - 이모지를 큰 글씨(18~22px)로 보이던 자리(`.card .ic`, `.mskill .sicon`, `.pic` 등)는 `pixel.css` 에서 아이콘을 2배(28px)로.
  - 그림 묶음: UI 기본은 `dev/make-icons.js` `ICONS`, 나머지는 `dev/icon-art/a-status.js`(상태·효과) · `b-gear.js`(무기·직업) · `c-nature.js`(자연·지역) · `d-creature.js`(생물).
    한 아이콘이 이모지 여럿을 맡을 수 있다 (`['📬 📭 📩', …]`).
  - **스킬 아이콘** (`dev/icon-art/e-skills-1~3.js`, 이름 `sk-<스킬 id>`): 스킬마다 고유 그림. 같은 이모지(☄️ 3개 등)를 나눠 쓰던 스킬도 모두 다르다.
    스킬 `icon` 을 사용자 영역 문자(U+E000~)로 바꿔서(`classes.js` 끝, 번호표 `SKILL_CP` 는 iconmap.js) 칩·카드·트리·토스트·배너·떠오르는 글자·궁극기 컷인이
    모두 자동 변환 경로로 고유 아이콘을 받는다. 원래 이모지는 `SKILLS[id].emoji`. 번호는 `dev/icon-art/skill-cp.json` 등록부에 고정 (새 스킬은 다음 번호).
    모양: 모서리 깎은 12×12 배지, 속성색 2단 바탕 + 기술 모티프. 3차 궁극기는 금테(위·왼쪽 Y, 아래·오른쪽 y).
  - `iconize`(화면 변환)는 `src/icondraw.js` 에 있다 — ui.js 를 안 싣는 dev/skills.html 에서도 돈다 (icons.css 도 연결).
  - 금화 `.gc` 는 같은 스프라이트의 `gold` 칸을 쓴다 (icons.css 가 `.gc` 도 정의, index.html 의 옛 원형 그라디언트 규칙은 지웠다). `<i class="gc">` 마크업은 그대로.
  - `.mailbtn i` 도 배지 스타일이라 `:not(.pi)` 로 뺐다.
  - `${ico()}` 는 백틱 문자열 안에서만 동작한다. 작은따옴표 문자열 안에 넣으면 글자 그대로 나온다 → 백틱으로 바꾼다.

- 새 스킬을 추가하면 `dev/icon-art/e-skills-*.js` 에 `sk-<id>` 배지를 그린다 (없으면 원래 이모지로 보인다).
- 약한 스킬 그림 후보: `sk-gale`(단순 X), `sk-ramCharge`(투구로 대신), `sk-siegeBarrage`, `sk-worldBreaker`(1배에서 망치가 상자처럼).

- 새 이모지를 UI·데이터에 쓰면 그림도 추가한다 (`dev/icon-art/` 에 넣고 `node dev/make-icons.js`). 빠지면 OS 이모지가 그대로 보일 뿐 깨지지는 않는다.
- 약한 그림 후보 (사용자 의견에 따라): `loop`(➰), `muscle`, `dragonhead`, `wing`, `coldface`, `croc`.
- 브라우저 툴팁(title 속성)과 앱 트레이 제목은 OS 글자라 이모지 그대로다.
