# UI 도트 아이콘 (이모지 교체)

- 상태: 진행 중 (1단계 캠프 탭 6개 적용, 0.19.20 배포)
- 관련 코드: `dev/make-icons.js` (도트 데이터·생성기) → `src/skin/icons.svg`·`src/skin/icons.css` (생성물), `src/ui.js` `ico()`, `dev/icons.html` (이모지 비교 페이지)
- 최종 갱신: 2026-10-13

## 목표

UI 퀄업 1번 ([art-upgrade.md](art-upgrade.md) "UI 퀄업 방향"). OS 이모지는 매끈한 고해상도라 도트 글꼴(Galmuri11)·도트 테두리 사이에서 튄다.
UI 톤(남보라 바탕 + 바랜 은 선)은 그대로 두고, 이모지만 같은 격자의 도트 아이콘으로 바꿔 화면을 한 벌로 맞춘다.

## 규칙

- 크기: 그림 12×12 + 잉크 외곽선 1px = 14×14. 화면에는 1배(14px)로, 크게 쓸 때는 정수배(`.x2` = 28px)로만.
- 그리기: 직접 픽셀을 찍는다 (AI 생성은 노이즈가 많아 쓰지 않는다, 참고용만). 큰 색 덩어리, 면마다 밝음/보통/그늘 3단계까지, 잔점 노이즈 금지.
  외곽선은 생성기가 칠해진 칸 상하좌우에 자동으로 두른다 (장비 아이콘 `gearSprite` 와 같은 방식). 안쪽 잉크선은 글자 `K`.
- 팔레트 (`dev/make-icons.js` `PAL`): 잉크 `#0b0a14`, 종이 `#ebe7dc`, 바랜 은 `#b9b4cc`/`#8f8aa8`/`#5e5a78`, 금 `#fff2b8`/`#e0c472`/`#a8842e`,
  빨강·초록·파랑·나무·양피지 각 2단. 새 색이 필요하면 팔레트에 추가하고 여기 적는다.
- [색깔놀이 금지](../../CLAUDE.md): 아이콘끼리 색만 다른 같은 모양을 만들지 않는다 (예: 홈 = 집 한 채, 마을 = 망루 + 집).
- 구현: `dev/make-icons.js` 가 스프라이트 시트 SVG 한 장 + CSS(`.pi` 공통, `.pi-<이름>` 위치)를 만든다. HTML 에서는 `ico('이름')` → `<i class="pi pi-이름"></i>`.
  - 런타임 canvas → data URL 방식은 index.html CSP(`default-src 'self'`)가 `data:` 이미지를 막아서 안 된다 (첫 시도에서 확인).
  - 생성: `node dev/make-icons.js` (Node 가 없으면 docs/dev-testing.md 의 VS Code 내장 Node).
  - `#campModal nav i` 는 탭 숫자 배지 스타일이라 `:not(.pi)` 로 아이콘을 뺐다. 다른 곳에서 `i` 태그 선택자와 겹치면 같은 식으로 뺀다.
  - `textContent` 로 넣는 곳(HUD `#status`·`#hbtn` 등)은 `innerHTML` 로 바꿔야 아이콘이 들어간다.
