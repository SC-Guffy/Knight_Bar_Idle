# 성벽 지키기: 도전 보상 바닥 = 소탕분

- 상태: 완료 (0.31.0, 사용자 확인 10-23)
- 관련 코드: src/castle.js (`endCastle`·`castleSweepBricks`·`castleBooksOf`), src/castle-ui.js (결과·판정 칩)
- 관련 스펙: [balance-audit-1023.md](balance-audit-1023.md) 항목 F, [castle-defense.md](castle-defense.md), [reward-inversion-audit.md](reward-inversion-audit.md) (탑 입장 보장 0.20.10)
- 최종 갱신: 2026-10-23

## 문제

성벽 지키기 도전은 실패하면 그때까지의 점수만 받는다(`endCastle`). 같은 입장권 1장으로 소탕하면 최고 단계를 다 막은 몫을 받는다. 그래서 새 단계에 도전해 실패하면 소탕보다 크게 손해다.

| 최고 단계 → 도전 | 소탕 🧱/📕 | 3웨이브에서 무너짐 | 6웨이브 | 9웨이브 | 다 막음(첫 돌파 🧱 ×2) |
|---|---|---|---|---|---|
| 20 → 21 | 250 / 4.06 | 56 / 1.23 | 136 / 2.46 | 218 / 3.68 | 510 / 4.09 |
| 40 → 41 | 350 / 4.72 | 78 / 1.43 | 189 / 2.85 | 303 / 4.28 | 710 / 4.75 |
| 60 → 61 | 450 / 5.38 | 100 / 1.62 | 243 / 3.25 | 388 / 4.87 | 910 / 5.41 |

9웨이브까지 막아도 소탕보다 적다 → 진행하려고 도전하면 손해라 도전을 피하고 소탕만 하게 된다(어려운 걸 하면 덜 받는 역전). 탑은 0.20.10 에 같은 문제를 "입장 때 소탕분 먼저"로 고쳤다.

## 목표

- 도전해서 실패해도 소탕보다 덜 받지 않는다. 성공하면 지금처럼 더 받는다.

## 규칙

1. 도전이 끝나면(성공·붕괴·시간 초과·후퇴·오프라인 모두) 🧱·📕 을 각각 **max(이번 도전 몫, 최고 단계 소탕 몫)** 으로 준다.
   - 소탕 몫 = `castleSweepBricks()`(최고 단계 다 막은 점수) · `castleBooksOf(최고, 10웨이브)`.
   - 최고 단계가 0(첫 도전)이면 바닥 없음.
   - 첫 돌파 🧱 ×2 는 지금처럼 이번 도전 몫에 붙는다(성공하면 늘 바닥보다 크다).
2. 탑처럼 입장 때 먼저 주지 않고 끝날 때 큰 쪽을 준다 — 결과 화면 한 줄에 합쳐 보여 주기 쉽고, 앱을 꺼도(오프라인 정산) 같다.
3. 입장권·첫 돌파·최고 기록 규칙은 그대로.

## UI

- 결과 화면: 바닥이 적용됐으면 보상 옆에 작게 "(소탕 보장)".
- 도전 버튼 옆 판정 칩에 "실패해도 소탕분" 한 줄을 더하지 않는다(칩이 길어짐 — UI 피드백 "크고 투박한 박스 금지").
