## 목표

2026-10-20 사용자 (스킬 탭 강철 베기 상세 화면을 보고): "내가 원한 스킬트리의 그림은"
1. 액티브 스킬은 찍으면 찍을수록 **위력·쿨타임만** 좋아진다.
2. **모습이 변하는 것은 서브 노드로** 뺀다 (2연참처럼). 지금 칸(레벨)에 뿌려져 있는 모습들을 노드로 바꾼다.
3. 패시브 스탯 노드는 **확실히 패시브답게, 단조롭게** 보인다.
4. 노드 구조는 **시작 지점부터 점진적으로** 찍어 나간다. 시작 지점은 **각 직업 메인 스킬 1레벨**.

지금(0.27.x)의 문제: 액티브 5칸이 위력·쿨과 모습(1칸 기본 · 2·3칸 ★ · 4칸 ★★ · 5칸 ★★★)을 한꺼번에 바꿔서, 스킬 상세의 "1칸 · 강철 베기 / 2칸 · 강철 검풍 …" 목록이 무엇을 사는지 흐리다.
스탯 노드도 아이콘 달린 큰 원이라 스킬 노드와 무게가 같아 보이고, 트리 왼쪽 끝 스탯 둘(단련·강인함)이 시작점이라 "내 스킬에서 뻗어 나간다"는 느낌이 없다.

## 규칙 (시안)

모든 15줄기 공통 (노드 id 는 지금처럼 "칸" 이름 — skill-tree-all.md). 아래 수치는 검토 페이지에서 바꿔 볼 수 있다.

### ① 액티브 칸 = 위력·쿨만
| 노드 | 지금 | 개편 |
|---|---|---|
| 액티브 (`slash`·`gale`·`iaido`·`whirl`·`flash`·`wave`·`storm`) | 5칸 × 🌟2, 칸마다 위력 +15% · 쿨 −6% **+ 모습** | 5칸 × **🌟1**, 칸마다 위력 +15% · 쿨 −6% **만** |
| 궁극기 (`ult`) | 5칸 × 🌟2, 같음 | 5칸 × **🌟1**, 위력·쿨만 |
| 융합 (`f_ab`·`f_bk`·`f_ak`) | 3칸 × 🌟4, 칸마다 +25% · −8% + 모습(2칸 ★★ · 3칸 ★★★) | 3칸 × **🌟2**, 위력·쿨만 |

- 위력·쿨 배수(`T7_RANK`·`T7_FUSE`)는 그대로. 칸 비용만 내려 모습 노드 몫을 비운다.
- 스킬 상세의 "1칸 · … 5칸 · …" 모습 목록은 없앤다. 대신 "지금 위력 ×1.45 · 쿨 ×0.82" 와 모습 노드 목록을 보인다.

### ② 모습 = 모습 노드 (◆)
- 액티브·궁극기마다 **모습 노드 3개** (★ · ★★ · ★★★), 융합마다 **2개** (★★ · ★★★). 이름은 지금 칸 모습 이름 그대로 (`stageName` / `looks` 의 ★ 단계).
  - 예 강철 베기: ★ 강철 검풍 · ★★ 강철 대검 · ★★★ 천강검. 지금 3칸 "강철 검풍 (범위 +20%)" 처럼 같은 ★ 의 두 번째 줄은 없앤다(실제 효과가 없던 이름표).
- 스킬 노드 옆에 짧은 사슬로 붙는다: 스킬 → ★ → ★★ → ★★★. 앞 모습이 있어야 다음 모습.
- 열리는 조건 (시안): 그 스킬 칸 수 — ★ 2칸 · ★★ 4칸 · ★★★ 5칸 (융합 ★★ 2칸 · ★★★ 3칸). 지금 모습이 바뀌던 시점과 같다.
- 비용: 🌟2 씩 (융합 ★★ 🌟2 · ★★★ 🌟3).
- 효과: `t7Stage(sk)` = 찍은 모습 노드 수 (융합은 ★★ 노드 = 단계 2). 모습마다 타격 모양(`SKILLS[].stages`)이 바뀌는 건 지금과 같다 — 위력 합은 단계마다 비슷하게 짜여 있다.
- 모습 고르기(`S.t7.use`, 상세의 ‹ ★★☆ ›)는 남긴다: 찍은 모습 안에서 낮은 모습을 골라 쓸 수 있다.
- 찍을 때 토스트: "✨ 강철 베기 — 모습이 「강철 검풍」으로 바뀌었어요" (지금 칸 오를 때 나오던 것을 모습 노드로 옮김).

### ③ 스탯 = 단조로운 작은 점
- 그림: 아이콘 없는 **작은 도트 점**(9×9, 화면 18px). 잠김 = 짙은 회색, 찍을 수 있음 = 은테, 찍음 = 연보라로 채움. 빛·맥동 없음. 이름표 없음 (누르면 상세에 "공격 +2%").
- 스탯 노드 5종 × 3칸 → **한 번 찍으면 끝인 점 15개**(🌟1)로 쪼개 길 위에 깐다. 효과 합계는 그대로: 공격 +2% ×3 · 체력 +3% ×3 · 공속 +2% ×3 · 치명 +1.5% ×3 · 받는 피해 −2% ×3.
- id: `c_atk1`~`c_atk3`, `c_hp1`~3, `c_spd1`~3, `c_crit1`~3, `c_def1`~3. 효과는 `fx.stat` 그대로 (칸 대신 노드마다 더함).

### ④ 메인 스킬 1칸에서 시작
- 1차 전직하면 **메인 스킬(1차 스킬, 칸 `slash`) 1칸이 공짜로 찍혀 있다** (포인트 안 씀, 되돌리기·초기화로도 0칸이 안 됨). 판 왼쪽 가운데, "시작" 표시.
- 모든 노드는 여기서 이어진다. 시작점에서 스탯 점 길 셋이 갈래 입구로 뻗는다:
  - 길 A: 강철 베기 → 공격 → 공격 → 공속 → 공속 → **2차 스킬 a** (+ 곁가지 공속)
  - 길 B: 강철 베기 → 치명 → 치명 → 공격 → **2차 스킬 b** (+ 곁가지 치명 · 키스톤 검의 길)
  - 길 K: 강철 베기 → 체력 → 체력 → 방어 → 방어 → **k 갈래 첫 스킬** (+ 곁가지 체력·방어)
  - 2연참(`s_twin`)은 시작점 바로 옆 (메인 스킬의 변형).
- 2차 스킬(갈래 입구)의 앞 노드가 `slash` 에서 **그 길의 마지막 스탯 점**으로 바뀐다. 갈래 안 구조(변형 둘 → 둘째 스킬 → 택1 → 키스톤 → 3차 키스톤 → 궁극기 변형)는 그대로.
- 궁극기는 3차 키스톤 셋 중 하나에서 이어지고, 궁극기 변형은 궁극기 다음 (게이트 규칙 — 셋 중 하나·갈래 12포인트 — 는 그대로).
- 1차 직업일 때 보이는 것: 시작점 · 모습 노드 3 · 2연참 · 스탯 점 15 · 검의 길 (갈래는 2차에서).

### 비용 (검성, 택1·궁극기 변형은 하나씩 — 검토 페이지 표)
| 종류 | 지금 🌟 | 개편 🌟 |
|---|---|---|
| 스탯 | 15 | 15 |
| 액티브·궁극기 칸 | 80 | 39 (메인 1칸 공짜) |
| 융합 칸 | 36 | 18 |
| 모습 노드 | — | 63 |
| 변형 · 키스톤 · 궁극기 변형 | 40 · 49 · 6 | 그대로 |
| **합계** | **226** | **230** |

판 전체 비용이 거의 같아서 "열심 유저 10일차에 거의 다" 속도는 그대로다. 노드 수는 41 → 79.

### 옮기기 (지금 세이브)
- 시즌 중 바꾸는 것이라 지금 찍은 상태를 새 규칙으로 바꾼다 (`S.t7.ver` 없으면 1회):
  - 스탯 `c_x` n칸 → `c_x1`~`c_xn`.
  - 액티브·궁극기 n칸 → 같은 n칸 + 그 칸에서 열려 있던 모습 노드(2칸↑ ★ · 4칸↑ ★★ · 5칸 ★★★). 융합 n칸 → n칸 + ★★(2칸↑)·★★★(3칸).
  - 길 조건 때문에 규칙에 안 맞는 노드가 생기면(예: 스탯을 안 찍고 2차 스킬만 찍은 경우) **전부 초기화하고 포인트를 돌려준다** + 무료 초기화 1회 + 자동 찍기 다시 켬(`auto`). 받은 메시지 한 줄 "스킬 트리 구조가 바뀌어 포인트를 돌려드렸어요".
  - 쓴 포인트가 남는 포인트보다 많아지면 같은 방법(초기화).
- 결투·레이드 프로필(`profile`)은 서버가 스킬 위력·단계만 받으므로 서버 수정 없음 — 단계 값이 모습 노드에서 오는지만 확인.

### 봇·밸런스
- `T7_BUILDS` (a·b·k) 순서를 새 노드로 다시 쓴다: 길 스탯 → 2차 스킬 → 칸과 모습을 번갈아.
- 칸 비용이 반이 되어 초반 위력이 조금 빨리 오른다 → `dev/lifespan-bot.js --line swordsaint --build a|b|k` 로 전후 비교, 1·3·5·10일 스테이지가 지금과 ±5% 안이면 그대로, 넘으면 `T7_RANK.pow` 를 조정.

## 수용 기준
- [ ] 액티브·궁극기·융합 칸을 올려도 모습(시전 그림)이 바뀌지 않고, 위력·쿨 숫자만 바뀐다.
- [ ] 모습 노드를 찍으면 그 스킬의 모습이 바뀌고(▶ 비주얼 확인), 칸 조건(★2·★★4·★★★5)이 안 되면 잠겨 있으며 이유가 상세에 보인다.
- [ ] 스탯 노드는 아이콘 없는 작은 점이고 빛나지 않는다. 점 15개 효과 합계가 지금 스탯 15칸과 같다.
- [ ] 1차 전직 직후 메인 스킬 1칸이 공짜로 찍혀 있고 장착 칸에 들어가 있다. 0칸으로 못 내린다.
- [ ] 2차 스킬은 시작점에서 스탯 점 길을 따라가야 열린다. 시작점과 이어지지 않은 노드는 없다 (dev/tree7-check.js).
- [ ] 15줄기 모두 같은 틀로 모습 노드 이름이 줄기 글(`looks`/`stageName`)에서 나온다.
- [ ] 지금 세이브를 불러오면 찍은 상태가 옮겨지거나, 안 맞으면 포인트 전부 환급 + 무료 초기화.
- [ ] 봇 1·3·5·10일 스테이지가 개편 전 ±5% 안.
- [ ] 캠프 창(좁은 창) 안에서 판이 가로 스크롤로 다 보이고 이름표가 겹치지 않는다.

## 정할 것 (사용자)
1. 모습 노드 조건: 칸 수 조건(★2·★★4·★★★5)을 둘지, 앞 모습만 있으면 열리게 할지.
2. 융합 모습 2개(★★·★★★) 그대로 둘지.
3. 2차 스킬에 가려면 스탯 점 3~4개(🌟4~5)를 꼭 지나가게 할지.
4. 모습 고르기(낮은 모습 쓰기) 남길지.
