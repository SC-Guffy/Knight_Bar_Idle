## 3안 — 디아블로 4 식 판 (2026-10-20 사용자: 디아블로 스킬창 그림을 보여 주며 "하 ㅈㄴ 별론데 디아블로 스킬창처럼 안되나?")
- **줄기 + 허브**: 허브 6개(시작 → 연타 → 발도 → 검기 → 융합 → 궁극)가 가로 지그재그 굵은 줄기로 이어진다. 열린 줄기는 붉게 빛난다. 허브는 찍지 않는 길목 — 전직 차수가 되면 열린다(시작 1차 · 줄·융합 2차 · 궁극 3차). 캠프 창이 가로로 넓어 세로 대신 가로.
- **방사형 가지**: 노드는 모두 자기 허브에서 뻗는다 (src/tree7-ui.js `T7_BR` = [뿌리, 각도, 반지름]).
  - 스킬(사각) → 바깥으로 ◆ 모습 사슬 (★ → ★★ → ★★★), 옆(위쪽)에 ● 변형 (궁극기는 궁극기 변형 셋).
  - 키스톤(팔각) → 바깥으로 3차 키스톤.
  - 스탯 점 사슬: 시작 허브 3사슬 × 3점(공격·공격·공속 / 치명·치명·공격 / 체력·체력·방어, 1차부터) · 연타·발도·검기 허브에 2점씩(2차). 1차 때 찍을 수 있는 수(9)가 2안 1차 길과 같다.
  - 융합 허브: 융합 셋 (두 줄의 둘째 스킬을 모두 배워야 열림 — 조건은 그대로).
- **조건**: 노드의 앞 = 자기 허브(또는 사슬의 앞 노드). 스킬끼리의 앞뒤(첫 스킬 → 둘째 스킬)·길 스탯 강제는 없앴다. 남은 예외는 택1·셋 중 하나·융합·마지막 모습(위력 최대 Lv).
- 판 크기 1740 × 520px (가로로 민다). 모든 노드가 처음부터 보인다(잠긴 것은 어둡게) — 1차 때는 허브만 "2차 전직"으로.
- 세이브: `S.t7.v = 3`. 2안(v2) 세이브는 스탯 점 종류별 개수를 새 사슬 앞에서부터 다시 깐다(총 개수 같음), 나머지 노드는 그대로.

## 2안의 원칙 (3안에서도 그대로인 것: 누르면 찍기 · 스킬 안 3줄 · 공짜 Lv · 모습/변형 노드)
- **위성 (B안, 2026-10-20 사용자 "서브노드의 의미가 뭐임?" → B)**: 배운 스킬 위에 작은 노드 두 줄이 붙는다 — 가까운 줄 ◆ **모습**(★·★★·★★★, 가운데 점 개수 = 단계) · 먼 줄 ● **변형**(궁극기는 궁극기 변형 셋). 판에서 바로 눌러 찍는다(못 찍으면 "적월일섬 — 위력 Lv5 필요" 한 줄). 안 배운 스킬엔 위성이 없다(판을 가볍게). 위성을 누르면 그 스킬 상세도 열린다. 스킬 안 3줄은 설명·같은 찍기 버튼으로 남긴다.
  - 처음 요청 2번("모습 변화는 2연참처럼 서브노드로")을 2안이 스킬 안 카드로만 바꿔 버린 것을 되살린 것.
- **판 = 스킬 지도**: 판에는 스킬 · 키스톤 · 스탯 점만 있다 (검성 33개: 스킬 11 · 키스톤 7 · 점 15).
- **스킬 안 = 언제나 같은 3줄**: 스킬을 누르면 아래에 **위력 / 모습 / 변형**. 모든 스킬(메인·액티브·융합·궁극기)이 같은 모양.
- **누르면 바로 찍힌다** (2026-10-20 사용자): 판의 점·키스톤 = 찍기, 스킬 = 배우기 / 위력 +1 Lv (최대면 열어 보기만, 아래 상세가 열림). 모습·변형은 상세의 카드를 누르면 찍힌다. 잘못 찍으면 **↩ 되돌리기** — 이번 캠프에서 찍은 것을 마지막 것부터 무료로 (`S.t7.log`).
- **열리는 조건은 하나**: "앞에 있는 걸 배우면 열린다" (+ 전직 차수). 숫자 게이트(갈래 12포인트·융합 6/6)는 없앤다. 남는 예외는 택1("또는")과 궁극기 변형(셋 중 하나)뿐이고 둘 다 스킬 안에서 카드 사이 "또는" 표시로 보인다.

## 규칙 (시안)

### 판 (스킬 지도)
- 왼쪽 가운데 **메인 스킬(1차 스킬)** — 1차 전직하면 1Lv 이 공짜로 찍혀 있다 ("시작" 표시). 0 으로 못 내린다.
- 오른쪽으로 **줄 3개** (= 지금 갈래: 검성은 ⚡ 연타 · 🗡️ 발도 · 🌙 검기). 줄마다 첫 스킬 → 둘째 스킬 → 키스톤 → 3차 키스톤.
- 스킬과 스킬 사이 길 위에 **스탯 점**: 메인 → 첫 스킬 길에 3개씩(1차부터 찍을 수 있음), 첫 스킬 → 둘째 스킬 길에 2개씩(2차부터). 점을 앞에서부터 찍어야 다음 스킬이 열린다.
  - 검성 배치: 연타 길 공격·공격·공속 / 공속·공속, 발도 길 치명·치명·공격 / 치명·방어, 검기 길 체력·체력·방어 / 체력·방어. 합계 = 지금 스탯 15칸과 같음 (공격 +2% ×3 · 체력 +3% ×3 · 공속 +2% ×3 · 치명 +1.5% ×3 · 받는 피해 −2% ×3).
  - 그림: 아이콘 없는 작은 도트 점(화면 20px), 빛·맥동 없음. 누르면 바로 찍힌다 (상세 없음, 마우스 올리면 "공격 +2%").
- **검의 길**(줄기 키스톤)은 메인 스킬 바로 옆 (1차부터).
- **키스톤**: 줄의 둘째 스킬 다음 → 3차 키스톤 (3차 전직). 🌟7, 대가는 지금과 같다.
- **융합 스킬**: 두 줄 사이. 그 두 줄의 **둘째 스킬을 둘 다 배우면** 열린다 (점선으로 이어짐).
- **궁극기**: 판 오른쪽 끝. **3차 전직하면 1Lv 공짜** (메인 스킬과 같은 방식, "3차" 표시).
- 판 스킬 노드: 이름은 지금 모습 이름(예: "강철 검풍"), 아래 작은 글로 "Lv2 ★". 오른쪽 위 숫자 배지 = 그 스킬 안에서 지금 찍을 수 있는 것 수 (레드닷 대신).

### 옮기기 (지금 세이브)
- 시즌 중 바꾸므로 1회 옮긴다 (`S.t7.ver` 없으면):
  - 스킬 n칸 → 위력 Lv n + 그 칸에서 열려 있던 모습(2칸↑ ★ · 4칸↑ ★★ · 5칸 ★★★, 융합 2칸↑ ★★ · 3칸 ★★★). 변형·키스톤은 그대로.
  - 스탯 `c_x` n칸 → 그 종류 점 n개 (길 앞에서부터).
  - 새 규칙에 안 맞으면(길 점을 안 찍고 2차 스킬만 찍은 경우 등) 또는 쓴 포인트가 넘치면 **전부 초기화 + 포인트 환급 + 무료 초기화 1회 + 자동 찍기 다시 켬**. 한 줄 알림 "스킬 트리 구조가 바뀌어 포인트를 돌려드렸어요".
- 결투·레이드 프로필은 스킬 위력·단계만 보내므로 서버 수정 없음 (단계 값의 출처만 바뀜).

## 수용 기준
- [ ] 판에 스킬·키스톤·스탯 점 + 배운 스킬 위의 위성(◆ 모습 · ● 변형)이 있고, 위성을 눌러 바로 찍는다.
- [ ] 모든 스킬의 상세가 위력 / 모습 / 변형 3줄로 같다 (융합은 변형 줄 없음).
- [ ] 위력 Lv 을 올려도 시전 그림이 안 바뀌고 위력·쿨 숫자만 바뀐다.
- [ ] 모습 카드를 찍으면 시전 그림·타격 범위가 바뀐다 (▶ 비주얼 확인). 마지막 모습은 위력 최대 Lv 전엔 잠겨 있고 이유가 보인다.
- [ ] 스탯 점은 아이콘 없는 작은 점이고 빛나지 않는다. 15개 합계가 지금 스탯 15칸과 같다.
