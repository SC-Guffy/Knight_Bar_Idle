## 목표
"제대로 하면 손해", "어려운 걸 하면 덜 받음", "강해지면 약해짐" 같은 역전을 없앤다. 탑 입장이 소탕보다 비전서를 덜 주던 문제에서 시작해 콘텐츠 전체를 훑었다.

## 규칙 (고친 것)
- **도전의 탑**: 입장하면 소탕분(입장 전 최고 층 수 📖)을 먼저 받고, 깬 층마다 +1, 10층 단위 첫 돌파 묶음은 따로. 정산에 "(기본 N)" 표시.
- **원정 보스 진행**: 보스를 잡은 뒤 바퀴 끝에 닿기 전에 원정이 끝나도(가방 가득·지침·귀환·오프라인) 스테이지가 오른다. `endExpedition`·`layoutLap`·`startExpedition` 이 `S.run.cleared` 면 `finishLap()` 부터.
- **오프라인 바퀴**: 몬스터 `SIM_LAP`=8 마리(마지막 보스)로 센다. 보스 자리를 지나쳐 깐 바퀴(`S.run.boss=false`)는 보스로 치지 않는다.
- **진화 ★**: 진화 모습이 0단계보다 오래 시전하면 못 친 평타 피해만큼 스킬 피해를 얹는다 (`stageComp`) → 같은 투자에서 별 0 ↔ 별 3 DPS 비 1.000. 원정·결투·레이드 모두.
- **1차 스킬 계승**: 2·3차에서도 1차 스킬 위력·쿨타임이 그대로 (INHERIT_DMG·inheritBoost 삭제). 대신 2·3차 24직업 `mods.atk` 를 직업별로 낮춰 직업 전체 DPS 는 그대로 (HEAD 대비 ±0.2%).
- **골고루 올리기**: 공격력·체력은 맨몸 수치가 포화되면(다음 단계가 맨몸 수치 +1% 미만, 약 Lv 32) 건너뛴다. 손으로는 계속 올릴 수 있다.
- **레이드·월드 보스·시즌 보상 눈금**: `bossLoot(stage, f)` — 필드 보스 ×1.5 를 쓰지 않는다. 레이드는 f=1.5 고정(사람 3~4인이 받던 값), 월드 보스·시즌은 f=1. 더 센 보스(AI 섞인 파티)가 덜 받거나, 최고 스테이지가 40→41 로 오르면 골드가 줄던 역전 제거.
- **레이드 고유 장비**: 상자에서 가장 낮은 등급 칸을 대신한다 (전설·신화가 덮여 사라지지 않게).
- **레이드 세트 서열**: 뒤 보스 세트일수록 강하게 (대략 공격×생존 지표: 심연 3.74 < 그리폰 3.95 < 대왕충 4.06 < 크라켄 4.40 < 요정 4.66 < 콜로서스 5.29 < 수정 거미 5.50 < 폭풍 5.93 < 종언 9.41). 그리폰·대왕충·크라켄·요정·수정 거미 세트 효과 상향, 대왕충 개미지옥 6번째 ×150% → 5번째 ×200%.
- **입장권과 서버 시각**: 미궁·탑 입장, 탑 소탕·입장권 구매는 서버 시각을 안 뒤에만 (모르는 채 어제 남은 장수로 쓰고 다시 채워지던 구멍).
- **자동 장착**: `gearScore` 에 고유 발동 효과(ev·hv) 반영.
- **레이드 결과**: 방장이 "다시 도전"으로 방을 다시 열어도 직전 결과를 `last` 로 남긴다 — 못 받아 간 파티원도 정산 (claimed 로 중복 방지).
- **문구**: 스킬 레벨업 안내(⭐ → 트리), 미궁 슬롯 "+25%씩", 보호 주문서 출처(원정·레이드·월드 보스), 가방 무게 소수 표시(올림), 탑 다음 첫 돌파 층(옛 곡선 기록은 paid 기준).
