## 목표
- 시즌 7~10일 동안 **"다음 진화까지"** 라는 긴 목표가 늘 보인다. 숙련(원정마다)·룬(하루 몇 번)보다 긴 호흡 — 시즌 중반(4~6일)에 첫 진화, 후반에 둘째·셋째.
- 진화는 **3차급 연출**의 새 스킬이 생기는 큰 순간 — 연출 등급표에서 1·2차 스킬이 절제한 만큼 여기서 화려해진다.
- 조건은 "키우고(숙련) + 함께 쓰는(연계)" 것 — 정해진 보스를 깨야 열리는 문이 아니다 (원칙 ③ 정답 강요 금지).
- 0.28 트리에서 버려 둔 **융합 스킬 45종 · 궁극기 변형 45종**(이미 데이터·연출이 있다)을 되살린다.

## 규칙

### 1. 스킬 진화 (융합 스킬 — 줄기마다 3개)
| 진화 | 재료 (두 스킬) | 검신 예 |
|---|---|---|
| `f_ab` | 새 스킬 whirl + flash | 질풍 일섬 = 검무 회오리 + 섬광 베기 |
| `f_bk` | flash + storm | 섬광 검기 = 섬광 베기 + 검기 폭풍 |
| `f_ak` | whirl + storm | 칼날 폭풍 = 검무 회오리 + 검기 폭풍 |

- **조건 (시안)**: 두 재료 모두 **숙련 ★★ (Lv20)** + 두 재료를 **연계로 이은 횟수 1,500번** (방향 상관없이 `S.combo.p['A>B'] + p['B>A']`).
  - ★★★ 가 아니라 ★★ 인 이유 (검토 페이지 계산기, 검성·열심 유저): ★★ + 1,500 → 진화 셋 모두 **5일차** · 궁극기 변형 5일차. ★★★ + 2,500 → **10일 안에 못 연다** (새 스킬 ★★★ 가 11,000번 시전). 병목은 숙련(섬광 베기 쿨 18초)이라 연계 수 N 은 1,000~2,000 사이에서 하루 안팎만 움직인다.
  - 계산기는 셋을 동시에 키운다고 봤다 — 장착 칸 4개라 실제로는 첫 진화 5일차, 둘째·셋째는 더 늦다(시즌 후반 목표로 자연스럽게).
  - 1,500 = 싸우는 1분에 짝 하나 2~5번(연계 스펙 시뮬) × 4~5일차 하루 전투 약 300분 → 둘을 붙여 장착하면 1~2일.
- **해금은 영구** — 조건을 채우면 진화 스킬 카드가 생긴다 (귀환 보고 강조 줄 "✨ 진화: 질풍 일섬"). 큰 배너 없음.
- **장착은 선택**: 진화 스킬을 장착하면 **재료 둘이 장착에서 빠진다** (두 칸 → 한 칸, 남는 칸에 다른 스킬). 진화를 빼면 재료를 다시 끼울 수 있다 (숙련·룬은 재료에 그대로 남아 있다). 진화 스킬과 재료는 함께 장착할 수 없다.
- **위력 (시안)**: 진화 스킬 하나의 DPS ≈ **두 재료 DPS 합 × 0.9** (같은 숙련 기준). 빈 칸에 다른 스킬을 하나 더 넣을 수 있으니 전체로는 +10% 안팎 이득 — 봇으로 맞춘다. 지금 `t7mul` (1.3~1.5)은 바탕 스킬 하나 기준이라 다시 정한다.
- **숙련**: 진화 스킬은 **★★ (숙련 Lv20) 로 태어나** 써서 ★★★ (Lv30) 까지 간다 (2차 등급 표, 경험치 1,500 에서 시작). 📖 바치기는 Lv20 까지라 진화 스킬엔 못 쓴다 → ★★★ 는 꼭 써야 온다.
- **모습**: 융합 스킬의 모습 단계 그대로 (★★ · ★★★, `stageName`). 연출은 3차급 (연출 등급표의 "3차·융합/진화" 칸 — ★★ 부터 이름 띠, 금빛).
- **룬**: 장착할 때 두 재료의 룬 중 높은 등급부터 2개를 진화 스킬 칸으로 옮겨 보여 준다 (재료에서 빼지는 않는다 — 진화를 빼면 재료로 돌아감). 같은 전설이 둘이면 하나.
- **연계 꼬리표**: 바탕 스킬(`t7base`)의 꼬리표.

### 2. 궁극기 진화 (궁극기 변형 — 셋 중 하나)
| 변형 | 줄 (연계 상대) | 검신 예 |
|---|---|---|
| `uv_a` | a 줄: 2차 ① + whirl | 천검: 만검 (질풍난무·검무 회오리) |
| `uv_b` | b 줄: 2차 ② + flash | 천검: 일도양단 (일섬·섬광 베기) |
| `uv_k` | k 줄: wave + storm | 천검: 검우 (비검·검기 폭풍) |

- **조건 (시안)**: 궁극기 **숙련 ★★** + 궁극기와 그 줄 스킬을 연계로 이은 횟수 **300번** (궁극기 앞·뒤 모두, 연계 스펙의 "궁극기 앞·뒤는 어느 칸과도 연계").
- 해금은 영구, 줄마다 따로 열린다. **쓰는 건 하나** — 캠프 궁극기 카드에서 고른다 (모습 고르기처럼, 무료로 바꿈). 셋 다 열 수 있다.
- 효과는 0.28 의 궁극기 변형 그대로 (`t7Shape` uvA 타수 2배 · uvB 마지막 한 타에 몰아줌 + 위력 +20% · uvK 범위 +30%) + 연출(tree7-fx-* 의 변형 덧그림).
- 결투 배율은 줄기별 `T7_DUEL_LINE` 하나 그대로 (변형별 보정은 리그로 확인 뒤).

### 3. 진행이 보이게
- 스킬 탭 위: **"다음 진화"** 한 줄 칩 — 가장 가까운 진화 하나: `✨ 질풍 일섬 — 검무 회오리 ★★ ✓ · 섬광 베기 Lv17/20 · 연계 640/1,500`. 누르면 진화 카드로.
- 아직 안 열린 진화 카드: 흐리게, 조건 세 줄 (재료 ★★ 둘 · 연계 수) 진행 막대.
- 귀환 보고: 진화 조건이 많이 오른 원정은 `✨ 질풍 일섬까지 연계 +210 (850/1,500)` 한 줄 (숙련 줄 아래).
- 연계 칩(장착 칸 사이)에 진화 짝이면 작은 ✨ 표시 — "이 둘을 붙여 두면 진화가 가까워진다"가 보이게 (정답 강요 아님: 안 붙여도 됨).

### 4. 오프라인 · 결투 · 레이드
- 진화 스킬은 그냥 스킬 하나 (숙련·룬·`comboEv`·프로필 그대로). 서버 변경 없음.
- 오프라인 원정의 연계 수는 연계 스펙의 근사(`S.combo.p` 에 분당 연계 수 × 싸운 시간) 그대로 쌓이므로 진화 진행도 오른다.

### 5. 세이브
- `S.evo = { got: ['f_ab', 'uv_b'], uv: 'uv_b' }` — 열린 진화(칸 이름) · 쓰는 궁극기 변형. 진화 스킬 숙련은 `S.skm[진화 스킬 id]`.
- 0.28 트리에서 융합·궁극기 변형을 찍어 둔 세이브: 0.29.0 숙련 옮기기(`skmMigrate`)에서 버렸다. 진화가 나올 때 **옛 `S.t7.got`/옛 기록이 남아 있으면 그 진화를 열어 준다**(있을 때만; 0.29.0 세이브엔 rk 가 지워져 거의 없다 — 가능하면 0.29.x 에서 융합·변형 찍음 기록을 `S.t7.oldEvo` 로 남겨 두는 작은 패치를 먼저).

## 수용 기준
- [ ] 줄기마다 진화 3개 · 궁극기 변형 3개의 조건·진행이 스킬 탭에 보인다.
- [ ] 재료 둘 ★★ + 짝 연계 1,500번 → 진화 스킬 카드가 열리고 귀환 보고 강조 줄 (큰 배너 없음).
- [ ] 진화 스킬을 장착하면 재료 둘이 빠지고, 빼면 재료를 다시 끼울 수 있다. 함께 장착 불가.
- [ ] 진화 스킬은 ★★ 로 태어나 써서 ★★★. 📖 바치기 안 됨.
- [ ] 진화 스킬 DPS ≈ 재료 합 × 0.9 (봇으로 확인), 전체 진행은 진화 전보다 조금 빠름.
- [ ] 궁극기 ★★ + 줄 연계 300 → 변형 해금, 셋 중 하나를 캠프에서 고른다.
- [ ] 연출: 진화 스킬은 3차급 (★★ 부터 이름 띠), 1·2차 스킬은 그대로 절제.
- [ ] 봇: 첫 진화가 열심 유저 4~6일차, 가벼운 유저 6~8일차. 0.29 대비 진행 ±5%~+8%.
- [ ] 결투 리그 다시 맞춤 뒤 줄기별 47~53%.

## 사용자 결정 (2026-10-21) — 모두 시안대로
1. 장착: **두 칸 → 한 칸** (진화 스킬을 장착하면 재료 둘이 빠짐, 빼면 재료로 되돌아감).
2. 조건: 재료 **숙련 ★★ + 짝 연계 1,500** (첫 진화 약 5일차).

4. 궁극기 변형: 궁극기 ★★ + 줄 연계 300 → **셋 다 열 수 있고 하나 골라 씀**.
5. 연계 스펙도 시안대로 확정 (바로 다음 칸만 연계).
