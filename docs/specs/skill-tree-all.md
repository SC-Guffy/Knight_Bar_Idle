## 틀 (모든 줄기 공통)

줄기 15개가 모두 같은 모양이다: 1차 스킬 1 · 2차 스킬 2 · 3차 궁극기 1. 그래서 검성 트리의 노드 표(배치·비용·효과·택1·키스톤 대가·보스 벽 대응)를 그대로 쓰고,
**노드 id 는 "칸" 이름**(검성 시제품 이름)으로 두고 줄기마다 칸 → 실제 스킬을 정한다.

| 칸 (노드 id) | 무엇 | 검성 |
|---|---|---|
| `slash` | 1차 스킬 (같은 1차 직업 줄기 공용) | 강철 베기 |
| `gale` | 2차 스킬 하나 → **a 갈래** (연타·여러 번 때림 — 🛡️ 보호막에 강함) | 질풍난무 |
| `iaido` | 2차 스킬 다른 하나 → **b 갈래** (한 방·폭딜 — 🔥 광폭화에 강함) | 일섬 |
| `whirl` | 새 스킬 (a 갈래 둘째 액티브, 주위 광역 연타) | 검무 회오리 |
| `flash` | 새 스킬 (b 갈래 둘째 액티브, 긴 줄 한 방) | 섬광 베기 |
| `wave` | 새 스킬 (**k 갈래** 첫 액티브, 투사체 — 관통 전엔 앞의 한 적) | 비검 |
| `storm` | 새 스킬 (k 갈래 둘째 액티브, 사방 광역 — 👥 졸개에 강함) | 검기 폭풍 |
| `f_ab`·`f_bk`·`f_ak` | 융합 (두 갈래 6포인트씩) | 질풍 일섬·섬광 검기·칼날 폭풍 |
| `ult` | 3차 궁극기 | 천검 |

- 새 스킬·융합은 그 줄기의 지금 스킬 하나를 바탕(`base`)으로 복제해 이름·아이콘·쿨·범위·위력 배율(`t7mul`)만 바꾼다. 연출은 바탕 스킬 연출(VFX 시트 재사용, 칸마다 바탕 스킬의 ★ 모습). 검성만 따로 짠 연출이 있다 (src/tree7-fx.js).
- 변형·키스톤 효과는 칸 기준이라 줄기와 상관없이 같다 (아래 표). 글(이름·설명)만 줄기 맛으로 쓴다.
- 1차 직업은 갈래가 없다: 줄기 노드(스탯·1차 스킬·2연참·검의 길)만 보이고, 2차 전직하면 그 직업의 갈래 3개가 열린다.

## 줄기 데이터 (src/tree7-l-<3차 id>.js)

```js
t7DefStem('<1차 id>', { ui: { slash: {…}, s_twin: {…}, k_blade: {…} } });   // 1차 직업 첫 줄기 파일에만 (검사는 검성 파일)
t7DefLine({
  id: '<3차 id>', cls: ['<1차>', '<2차>', '<3차>'],
  sk: { slash: '<1차 스킬>', gale: '<2차 스킬 a>', iaido: '<2차 스킬 b>', ult: '<궁극기>' },
  newSkills: { whirl|flash|wave|storm|f_ab|f_bk|f_ak: { id: '<새 id>', base: '<이 줄기 지금 스킬>', name, icon(이모지), cd, radius?, area?, t7mul, stageName: [4], desc } },
  lanes: { a|b|k: { name: '<이모지> ○○ 갈래', short: '○○', sub: '🛡️ 보호막에 강함 | 🔥 광폭화에 강함 | 👥 졸개에 강함', tip: '대응 노드 이름들' } },
  ui: { <노드 id>: { n 이름, d 설명, looks: [5] (액티브·궁극기 칸마다 모습), cost 키스톤 대가, ic: 'sk-<스킬 id>' (액티브·융합·궁극기 아이콘 — 새 스킬은 바탕 스킬) } },
  duel: { a, b, k }, tune: { pow }, fx: { 노드 id: 효과 덮어쓰기 },   // 봇·결투 측정으로 맞춘 값 (없으면 검성 값)

```

## 바뀐 규칙 (검성 시제품 대비)

- 모든 줄기 캐릭터가 트리를 쓴다 (`?t7=1`·`S.t7.pick` 없앰). 배포 스위치 src/data.js `T7_OPEN`, 로컬 주소는 늘 켜짐.
- **자동 찍기**: 한 칸도 직접 찍지 않은 캐릭터는 캠프 도착·불러오기 때 남은 포인트를 추천 순서(a)로 찍고 장착한다 (재화는 안 씀 — 장착 칸은 직접 산다). 스킬 탭에서 한 칸이라도 찍으면 꺼진다. 첫 초기화는 무료.
  → 시즌7 공개 때 기존 캐릭터가 스킬 없이 원정 가지 않게.
- 파이터 계열: 새 스킬은 바탕 스킬의 기 규칙(소모·문턱)을 쓴다 (src/fighter-data.js `qiBaseId`).
- 원거리 평타에도 키스톤 평타 효과(광란·심검의 평타 피해, 검의 길), 심검 사거리는 330 까지.
- 결투: 새 스킬 돌진 거리는 프로필에 실어 보낸다 (server/index.js t7 만 `gap`), 결투 배율은 줄기별 (src/tree7.js `T7_DUEL_TUNE`, 궁극기 변형을 찍은 갈래 기준).
- 무념(b_k3): 갈래 b 스킬이 확정 치명이 아닌 12줄기는 ×1.9 (검성·신궁·빙결의 군주만 ×2.6 — 확정 치명 3.3배를 잃는 값).
- 파이터 계열: 장착한 주 기술이 여럿이면 한 게이지를 오래 안 쓴 것부터 나눠 쓴다 (게임 src/jobs/fighter.js `qiOrder`·`qiDashOk`, 결투 server/duel.js `qiReady`). 아니면 첫 기술·돌진기만 계속 나갔다.
- 장착 2칸: 2차 전직 + 골드 잡몹 ×30 (×300 이면 가벼운 유저가 2차 전직 하루 동안 스킬 1개로 싸웠다).
