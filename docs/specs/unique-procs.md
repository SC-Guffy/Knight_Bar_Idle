# 이름 있는 장비 고유 발동 효과 (시즌6)

- 상태: 초안 (장비별 매칭표 사용자 확인 대기)
- 브랜치: `season6`
- 관련 코드: src/data.js (GEAR_ITEMS.proc, RAID_BOSSES.set[3].proc, PROC_TYPES), src/world.js (hitMonster, 피격), src/skills.js (연출), src/core.js (dpsOf·profile 평균 환산), src/gear.js (gearBonus·표시)
- 최종 갱신: 2026-10-13

## 목표
궁니르·묠니르 같은 이름이 붙은 장비가 이름값을 한다. 끼는 순간 "아 이게 궁니르구나" 하고 눈으로 알 수 있어야 한다.
수치(공격력 % 등)는 옵션 줄이 맡고, 고유 장비는 **행동**을 바꾼다.

## 규칙
- 발동 유형(PROC_TYPES)을 12개 만들고, 장비마다 유형 + 수치 + 연출 색·말풍선을 붙인다 (유형 재사용, 장비마다 코드 새로 짜지 않음).
- 대상: 일반 드랍 전설 이상 이름 있는 장비 20종 + 레이드 세트 16종의 3세트 효과.
  레이드 고유 장비 각각의 기존 `sp`(공격력 % 등)는 그대로 둔다.
- 고유 효과는 강화 +0부터 켜진 "고유 줄"로 옵션 줄 맨 위에 보인다. 등급이 높을수록 수치가 크다.
- 발동하면 전용 연출 + 기사 머리 위 이름 말풍선 (예: `⚡묠니르!`) — 같은 효과는 2초에 한 번만 말풍선.
- 서버 전투(레이드·월보·결투)는 상황을 모르므로, 평균 피해 배율로 환산해 프로필에 녹인다 (스킬 고유 특수 specEv 와 같은 방식).

### 발동 유형
| id | 이름 | 동작 |
|---|---|---|
| throw | 투척 | N타마다 무기를 던져 일직선 관통 피해 ×M, 되돌아오며 한 번 더 |
| chain | 연쇄 번개 | 치명타 때 근처 적 K마리에 ×M 번개 |
| burn | 화상 | 타격마다 화상 1중첩(최대 5), 중첩당 초당 공격력 ×v |
| nova | 처치 폭발 | 적을 쓰러뜨리면 주변에 공격력 ×M 폭발 |
| meteor | 별똥별 | T초마다 화면 앞쪽에 광역 ×M |
| reap | 수확 | 체력 v% 이하 일반 적 즉사, 보스에겐 처형 피해 +x% |
| stack | 누적 | 처치마다 공속 +v% (최대 N중첩, 6초 동안 처치 없으면 초기화) |
| rebirth | 불사 | 원정마다 1번, 쓰러질 때 체력 50%로 되살아남 |
| aegis | 보호막 | 체력 50% 아래로 떨어지면 최대 체력 v% 보호막 (쿨 30초) |
| thorns | 반격 | 받은 피해의 v% 를 되돌려 줌 |
| dodge | 회피 | v% 확률로 피해 무시 (무시하면 반짝임) |
| fortune | 황금손 | 처치마다 v% 확률로 골드 ×5 (또는 N번째 처치마다) |

## UI
- 장비 상세: 옵션 줄 맨 위에 `✦ 궁니르의 귀환 — 5타마다 창 투척 …` 금빛 한 줄.
- 발동 시 필드: 유형별 연출(투척 궤적, 번개 줄기, 불기둥, 보호막 원 등) + 머리 위 이름 말풍선.
- 상태창 툴팁에 고유 효과 한 줄.

## 수용 기준
- [ ] 20종 + 세트 14종이 필드에서 실제로 발동하고 연출·말풍선이 보인다 — 장비별로 껴서 원정 스크린샷
- [ ] 결투·레이드 프로필에 평균 환산 배율이 실린다 — profile() 확인, 레이드 로컬 서버로 1회
- [ ] 진행 봇으로 전투력 변화 확인 — 등급 서열(같은 부위 위 등급이 항상 더 강함)이 깨지지 않음
- [ ] 연출이 화면 전체를 번쩍이지 않는다 (바탕화면 게임 원칙)
