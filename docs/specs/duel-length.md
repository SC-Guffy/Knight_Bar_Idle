# 결투 길이 (스킬 한두 방에 끝나지 않게)

- 상태: 완료
- 관련 코드: server/duel.js (`DUEL_HP` · `healBase`), src/classes.js (CLASSES 의 paladin·archon·skyGeneral `mods`), server/bot-curve.json, dev/duel-balance.js (`CURVES`), dev/bot-curve.js (`--seed`·`--out`)
- 최종 갱신: 2026-10-13

## 목표
결투가 "스킬 찍 쓰면 끝나는" 싸움이 되지 않게 한다 (사용자 요청). 평타를 주고받다가 스킬이 흐름을 바꾸는 정도여야 한다.

원인: 결투 체력 배수(`DUEL_SEC` 12초)는 평타만 보고 정했다. 3차 직업은 치명 배율 ×8~10, 스킬 배율 ×8~21이라 치명 터진 궁극기 한 방이 평타 약 200대 분량이다.
그래서 결투가 평균 3.6초였고, 58%가 3초 안에 끝났으며, 97%의 판에 최대 체력 30% 이상을 한 방에 깎는 타격이 있었다.

## 규칙
- 결투 체력 = 프로필 최대 체력 × `hpMult`. `hpMult = DUEL_HP(2) × max(4, 평타만으로 12초 버티는 배수)` — 앞의 2배가 이번에 추가한 몫.
- 최대 체력 % 로 차는 회복(타격 회복 `heal`·보호막 회복 `ward.heal`)은 `DUEL_HP` 를 곱하기 전 체력(`healBase`) 기준이다.
  체력을 2배로 늘렸다고 회복까지 2배가 되면 성기사 계열이 튄다. 흡혈(`lc`, 준 피해 비율)은 원래대로.
- 직업 특성 조정 (`CLASSES[*].mods`, 모든 콘텐츠에 적용 — 결투 전용 보정 금지 원칙):
  - 성기사 타격 회복 0.02 → 0.012
  - 성좌기사 받는 피해 감소 0.3 → 0.15, 타격 회복 0.025 → 0.012
  - 천마장군 받는 피해 감소 0.25 → 0.18
- 봇 성장 곡선(server/bot-curve.json)을 새 직업 값으로 다시 구웠다.
- 레이드·원정의 체력 규칙은 그대로다 (직업 수치 변경만 같이 적용).

## UI
- 바뀌는 화면 없음. 결투 재생이 평균 약 10초로 길어진다 (재생은 서버 기록 그대로라 클라이언트 수정 없음).

## 밸런스 근거
점검: 봇 곡선을 시드 4벌로 구워(`node dev/bot-curve.js --seed k --out 파일`, k=0~3)
`CURVES=c0.json,c1.json,c2.json,c3.json node dev/duel-balance.js 40,80,120,150 15 [raw]` 로 평균을 낸다.
곡선 하나만 쓰면 계열 승률이 ±15%p 흔들린다 (검신이 곡선에 따라 30% 또는 45%).

| | 지금 (0.19.29) | 체력 ×2 그대로 | **적용 (×2 + %회복 보정 + 직업 조정)** |
|---|---|---|---|
| 결투 평균 | 3.6초 | 10.1초 | **10.8초** |
| 3초 안에 끝 | 58% | 16% | **11%** |
| 같은 전투력 근접 승률 | 49% | 58% | **54%** |
| 같은 전투력 계열 승률 | 44~58% | 39~78% (성좌기사 78) | **40~63%** (성좌기사 63) |
| 같은 진행도 근접 승률 | 74% | 82% | 84% |

- 배수 비교 (같은 전투력, 직업 조정 전): ×1.25 4.7초·3초 안 49% / ×1.5 6.3초·32% / ×2 10.1초·16% / ×3 19.8초·2% (×3은 성좌기사 88%).
  한 방 상한(최대 체력 25%)도 시험했다 — 9.2초, 성좌기사 85%로 같은 문제라 체력 배수를 골랐다 (사용자 선택).
- 결투가 길어지면 성좌기사 계열이 튄다. 전투력(√(DPS×체력))이 받는 피해 감소·회복·보호막을 셈하지 않기 때문이다. 짧은 결투에서는 한 방 싸움에 가려 있던 차이다.
  회복·보호막을 다 빼도 64~81%였으므로 받는 피해 감소도 같이 깎았다.
- 원거리 보강(사용자 선택 '같은 전투력 기준만 맞춤')은 넣지 않았다. 원거리 직업 체력 ×1.07·×1.12로 곡선을 다시 구워도 같은 전투력 근접 승률이 54→54~55%로 그대로였다.
  체력은 전투력 숫자에 들어가서 같은 전투력으로 맞추면 상쇄된다. 같은 전투력 근접 54%는 예전 허용 범위(41~57%) 안이다.
- 원정: 봇 곡선 12일 최고 스테이지 (시드 4벌 평균) 성좌기사 158→160, 천마장군 173→173. 나머지 계열은 바뀌지 않음.

## 수용 기준
- [x] 결투 평균 길이가 3.6초 → 10초 안팎, 3초 안에 끝나는 판이 58% → 11% (위 표, 시드 4벌 × 4스테이지 × 조합당 15판).
- [x] 같은 전투력 근접 승률 50% 근처 (54%), 계열 승률 40~63%.
- [x] 직업 조정이 원정 진행을 흔들지 않는다 (봇 곡선 12일 최고 스테이지, 위).
- [x] 결투 재생: 길어진 기록(약 10초)이 끝까지 재생되고 결과가 맞다 — 내장 브라우저 로컬 서버에서 확인.

## 진행 기록
- 2026-10-13: 사용자 요청 "pvp 시 스킬 찍 쓰면 끝나는 상황이 많으니 결투 시엔 체력 배율을 먹이자". 배수·한 방 상한 비교 뒤 사용자 선택으로 체력 ×2 + 직업 조정.
  같은 진행도 원거리 약세(근접 74→84%)는 사용자 선택으로 원거리 보강을 시험했지만 직업 체력으로는 메워지지 않았다. 사용자 선택으로 같은 전투력 기준만 맞췄다.

## 남은 일 / 미정
- 성기사 구간(St80) 성좌기사 계열 83%, St150 76%. 원인은 성역(sanctuary)이다. 첫 스킬이라 개전 0.3초에 받는 피해 −50%를 3~4초 깔아서,
  상대가 처음 쓰는 스킬 세 개(0.3·1.8·3.3초)가 거의 다 그 안에 들어간다. 성역을 빼면 55%. 보호막 감소량·회복만 줄여서는 72~74%에 머문다.
  스킬 순서·첫 준비 시간(성역을 뒤로) 같은 규칙으로 다뤄야 한다.
- 같은 진행도 근접 승률 84% (지금도 74%). 원거리는 원정에서 몬스터가 붙기 전에 쏘므로 같은 스테이지를 전투력 0.66~0.9배(근접 1.0~1.45배)로 깬다.
  결투가 길수록 이 전투력 차이가 그대로 승패에 반영된다. 원정 진행 속도나 결투 상대 고르기(진행도가 아니라 점수·전투력)로 다뤄야 한다.
