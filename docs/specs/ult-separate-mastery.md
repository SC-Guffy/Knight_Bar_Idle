# 3차 궁극기를 별도 스킬로 (1차 스킬 유지)

- 상태: 완료 (0.20.7 배포)
- 관련 코드: src/classes.js (`skillsOf`, `mastKey`, SKILLS 궁극기의 `mastOf`, `INHERIT_DMG`·`inheritBoost`·`skillPowAt`·`skillCdOf`), src/core.js (세이브 이전 mastV 12), src/ui.js (스킬 탭 문구), dev/bot-curve.js · server/bot-curve.json (AI 기사)
- 최종 갱신: 2026-10-13

## 목표
3차 전직 때 궁극기가 1차 스킬 자리를 대신하며 숙련도(비전서 권수·트리)를 이어받던 구조를 없앤다.
궁극기는 곡선(최대 12권)이 1차(6권)보다 비싸서 전직 직후 레벨이 내려가고, 트리에 찍은 포인트가 레벨보다 많아지거나
레벨에 안 맞는 진화 별이 남는 버그가 났다. 이어받기를 없애서 이런 복잡함을 원천적으로 없앤다.

## 규칙
- 3차 직업은 1차 스킬을 **그대로 유지**한다 (2차 때와 같은 숙련도·트리). 궁극기는 **새 스킬로 추가**되고 숙련도·트리를 따로 키운다 (Lv1 부터, 궁극기 곡선 최대 12권/레벨, 만렙 197권).
  - 3차 스킬 구성: 2차 고유 스킬(Lv0) · 1차 스킬(Lv25) · 2차 고유 스킬(Lv70) · 궁극기(Lv100) — 4개.
- 3차 직업이 쓰는 1차 스킬의 위력·쿨타임은 **2차 때와 같다** (그 계열 2차 직업의 계승 배수 `INHERIT_DMG` 를 그대로 쓴다). 그래서 3차 전체 DPS 는 1차 스킬 몫(2차 때 기준 +5~10%)만큼 오른다.
- `mastOf` 를 없앤다. 모든 스킬의 숙련도 키는 자기 id.

### 기존 세이브 (mastV < 12, 지금 3차 직업인 기사만)
지금은 궁극기와 1차 스킬이 같은 키(1차 스킬 id)에 권수 T 와 트리를 같이 쓰고 있다.
- 권수 T 와 트리는 **1차 스킬 것으로 남는다** (원래 키가 1차 스킬 id 라 데이터는 그대로). 1차 만렙 113권을 넘는 권수는 비전서로 돌려준다.
  1차 곡선이 궁극기 곡선보다 싸서 레벨이 같거나 오르니 트리 포인트가 모자라지 않는다.
- 궁극기는 Lv1·빈 트리에서 새로 키운다 (돌려받은 비전서로 바로 키울 수 있다).
- 알림 한 줄: 궁극기가 별도 스킬이 됐고 1차 스킬이 돌아왔다는 것 + 돌려준 비전서 권수.
- 1·2차 기사는 바뀌는 것이 없다.

## UI
- 스킬 탭에서 궁극기 설명의 "○○ 숙련도 이어받음" 문구를 뺀다. 3차 스킬 목록에 1차 스킬이 "계승"으로 다시 보인다.
- 스킬 4개가 좁은 창에서 잘리지 않는지 확인.
