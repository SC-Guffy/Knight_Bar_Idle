# 훈련 1차 만렙 50 · 2차 훈련 🎓 교관 수련 (시즌6)

- 상태: 초안
- 브랜치: `season6` (worktree `../knight-bar-season6`) — main 은 라이브 패치, 시즌6 시작 때 머지
- 관련 코드: src/data.js (`trainCapAt`, `TRAINING`, `BUILDINGS.training`, 새 `MENTORS`), src/core.js (`trainMax`, `stats`, migrate), src/gear.js (`gearBonus` — 교관 보너스 합산 지점), src/ui.js (`viewTraining`, 레드닷), src/town.js (`townTodo`), 새 src/mentor.js (수련 규칙·연출), server/index.js (승부 API), server/bots.js (`curveAt` — 교관 능력치), server/duel.js (`simulateDuel`), dev/bggen (새 배경)
- 최종 갱신: 2026-10-13

## 목표

- 1차 훈련(맨몸 공격력·체력·방어·수완)은 Lv 40 언저리에서 포화해 그 뒤가 무의미하다 → **Lv 50 에서 끝낸다.**
- 다 찍은 기사는 **2차 훈련: 교관 수련**으로 넘어간다. 교관 다섯 명을 차례로 찾아가 별 5개씩 받는다. 고르는 구조가 아니라 **결국 전부 올릴 수 있는 구조**.
- 별 1~4개는 골드를 내고 확률로 받는다 — 교관 앞에서 시범을 보이고 합격·탈락을 듣는 손맛. 골드가 남아도는 후반의 **골드 하수구**.
- 마지막 별은 **교관과의 승부**. 교관은 내 레벨에 맞춰 세지므로, 레벨만 높고 장비·강화·숙련도가 덜 갖춰진 기사는 못 이긴다 → "골고루 키웠는가"의 시험.
- 원칙 유지: 골드만으로 사는 힘은 장비보다 작다. 교관 보너스 전부(별 25개)가 장비 옵션 줄 몇 줄 수준이고, 마지막 별은 골드로 못 산다.

## 규칙

### 1차 훈련 (기존 훈련) — 만렙 50

- 훈련 최대 Lv = `10 × min(훈련장 Lv, 5)` → 훈련장 Lv5 에서 50, 그 뒤로는 늘지 않는다. `TRAINING[].max = 50`.
- Lv 50 에서: 공격력 약 1,086 · 체력 약 6,640 (포화값) · 방어 피해 감소 38.5% · 수완 골드·경험치 +150%.
- 비용 곡선 그대로. Lv 49→50 은 공격·체력 약 810만, 방어·수완 약 575만 골드.
- 네 항목이 모두 50 = "1차 훈련 수료".

### 2차 훈련 — 교관 다섯 명

교관은 순서대로만 만난다. 다음 교관이 열리는 조건 = **앞 교관 별 5개 + 훈련장 Lv**. 첫 교관은 1차 수료 + 훈련장 Lv6.

| # | 교관 (가칭) | 장소 · 배경 | 열림 | 별 하나 (★1~4) | ★5 (승부) | 별 5개 합계 | 승부 때 쓰는 기술 계열 |
|---|---|---|---|---|---|---|---|
| 1 | 🗡️ 검술 사범 | 도장 (새 배경) | 1차 수료 + 훈련장 Lv6 | 공격력 +2.5% | +5% | 공격력 +15% | 검성(swordsaint) |
| 2 | 🛡️ 방패 교관 | 성채 연병장 (castle) | 훈련장 Lv10 | 체력 +2.5% · 받는 피해 −1% | ×2 | 체력 +15% · 받는 피해 −6% | 대천사(archon) |
| 3 | 🏹 숲의 사냥꾼 | 숲 (fairy) | 훈련장 Lv14 | 공격 속도 +1.5% · 치명 +1%p | ×2 | 공속 +9% · 치명 +6%p | 명사수(deadeye) |
| 4 | 🔥 화산 투사 | 화산 (volcano) | 훈련장 Lv17 | 치명 피해 +5% · 보스 피해 +3% | ×2 | 치명 피해 +30% · 보스 피해 +18% | 폭군(tyrant) |
| 5 | 🌌 성좌의 은자 | 하늘 (sky) | 훈련장 Lv20 | 스킬 피해 +3% | +6% | 스킬 피해 +18% | 대마법사(archmage) |

- ★5 는 별 하나 몫의 2배 (마지막 별이 가장 값지다).
- 효과는 장비 옵션 줄과 같은 키(`atkPct`·`hpPct`·`guard`·`aspdPct`·`crit`·`critMult`·`bossDmg`·`skillDmg`)로 `gearBonus()` 에 더한다 → `stats()`·`profile()`·결투·레이드·월드 보스가 그대로 받는다. 서버 결투·레이드 계산은 수정 없음.
- 받는 피해 감소는 장비 guard 와 합쳐 기존 상한(60%) 안.
- 비교: 장비 옵션 한 줄 최대가 공격력 +17.5%(신화 S). 교관 다섯 명 전부가 옵션 줄 5~6줄쯤.

### ★1~4 — 수련 (골드 · 확률)

- 1회 비용 = `최고 스테이지 몬스터 골드 × MENTOR_GOLD × MENTOR_GROW^(별−1)`, 시작값 `MENTOR_GOLD = 500`, `MENTOR_GROW = 1.5` (★1 500 · ★2 750 · ★3 1,125 · ★4 1,688 마리 몫). 교관이 뒤로 갈수록 스테이지가 높아 저절로 비싸진다.
- 기본 성공 확률: ★1 60% · ★2 45% · ★3 35% · ★4 25%.
- 실패: 골드만 잃고 별은 그대로 (떨어지지 않는다). 대신 **교관의 눈도장** — 그 별에서 실패할 때마다 다음 확률 +5%p, 별을 받으면 0 으로.
- 기대값 (눈도장 포함): 시도 ★1 1.6 · ★2 2.0 · ★3 2.4 · ★4 3.0회, 교관 한 명 ★1~4 ≈ 몬스터 10,200 마리 몫 골드 ≈ 사냥 17시간 (수완 +150% 면 약 7시간). 다섯 명 ≈ 35시간+.
- 확률 굴림은 클라이언트에서 (강화와 같은 방식). 결과를 먼저 정하고 연출을 튼다.

### ★5 — 교관과의 승부

- 도전비 = ★5 시도 비용 (몬스터 2,531 마리 몫 골드). 지면 골드만 잃는다. 횟수 제한 없음.
- **서버에서 계산**한다 (결투와 같은 `simulateDuel`, 조작 방지): `POST /api/mentor/duel { mentor }` → 서버에 저장된 내 profile vs 교관 profile → 결과 events 를 돌려주고 클라이언트가 재생. 이기면 서버가 낸 승리 표시(id)를 세이브에 남긴다.
- **교관 능력치 = 내 레벨의 '기준 기사' × 교관 배수**
  - 기준 기사 = `server/bot-curve.json` (진행 봇이 원정·레이드·강화·건설·훈련·전직·숙련도를 골고루 한 기사) 에서 그 교관 계열 줄을 **레벨**로 찾은 profile (줄 사이 로그 보간, 끝 너머는 마지막 두 줄 기울기로 외삽).
  - 교관 배수 k 는 "기준 기사 본인이 교관과 싸웠을 때 승률" 목표로 맞춘다: 교관1 55% · 2 50% · 3 45% · 4 40% · 5 35%. 즉 내 레벨에서 장비·강화·숙련도·교관 보너스를 평균보다 잘 갖췄으면 이기고, 레벨만 앞서 있으면 진다.
  - 보정 방법: dev 스크립트로 계열 12개 × 레벨 구간마다 기준 기사 vs 교관 결투를 수백 번 돌려 k 를 정한다 (k 하나를 교관마다 공통으로, 레벨에 따라 흔들리면 레벨 구간별 표).
  - 교관은 자기 계열의 직업·사거리·스킬을 쓴다 (승부 연출에서 교관다운 기술이 나오게).
- 승부 전 화면에 `교관 전투력 n · 내 전투력 m` 과 대략의 판정(여유 / 비슷함 / 버거움)을 보여 준다. 교관 전투력은 서버 `GET /api/mentor/preview?mentor=` (또는 같은 표를 클라이언트에 복사).

### 훈련장 건물

- 효과 문구: Lv1~5 `훈련 최대 Lv {10×Lv}`, Lv6~20 `교관: {열린 교관 이름}` · 다음 교관 열리는 Lv 안내.
- 건설 비용·시간 곡선은 그대로.

### 상태

- `S.mentor = { at: 지금 교관 번호(0~4), stars: [0,0,0,0,0], eye: 지금 별의 눈도장 실패 수, wins: 서버 승부 승리 id[] }`.
- 이전 세이브: 시즌6 리셋으로 대부분 새로 시작. 리셋되지 않은 세이브에서 1차 단계가 50 을 넘으면 50 으로 내리고 넘겨 쓴 골드를 돌려준다 (core.js migrate, trainV 1).

## UI · 연출

### 훈련장 화면

- 마을 탭 → 훈련장 카드 아래:
  - **1차 미수료**: 지금 훈련 칸 그대로, 제목 `훈련 · 최대 Lv {cap} / 50`.
  - **1차 수료**: 한 줄 칩 `✅ 1차 훈련 수료 · 공격 1,086 · 체력 6,640 · 방어 38.5% · 수완 +150%` (눌러 펼치기).
  - **수련장 무대** (1차 수료 + 훈련장 Lv6 부터): 가로로 긴 도트 무대 하나.
    - 왼쪽 = 내 기사 (지금 직업 외형), 오른쪽 = 교관. 배경 = 교관 장소 (도장·성채 연병장·숲·화산·하늘).
    - 무대 위: 교관 이름 + 별 5칸 (받은 별은 금빛, 다음 별은 깜빡이는 빈 칸).
    - 무대 아래 한 줄: `★3 수련 · 성공 35% (+10%p 눈도장) · 💰 n` + 버튼 `수련하기`. ★5 차례면 `⚔️ 승부 · 교관 전투력 n / 내 m · 💰 n` + `승부하기`.
    - 교관 다섯 명은 무대 위쪽 작은 칩 줄로 (열린 교관만 누를 수 있고, 수료한 교관은 별 5개 표시, 잠긴 교관은 `🔒 훈련장 Lv n`).
  - 1차 미수료면 무대 대신 잠금 칩 `🔒 교관 수련 — 1차 훈련 네 가지를 Lv 50 까지`, 훈련장 Lv5 이하면 `🔒 훈련장 Lv 6`.
  - 큰 박스 금지 — 칩·한 줄 요약. 좁은 창(폭 360px)에서 무대는 비율 유지로 줄어든다.

### 수련 연출 (★1~4, 약 2.5초, 누르면 건너뜀)

1. 기사가 교관 쪽으로 반 걸음 → 자기 무기 공격 모션 1~2회 (교관은 막거나 흘린다).
2. 결과
   - **실패**: 교관이 한 대 친다 (기사 뒤로 밀림·흔들림) + 말풍선 `이놈, 탈락이다!` (교관마다 말투 다르게, 대사 3~4개 중 무작위). 아래에 `실패… 눈도장 +5%p`.
   - **성공**: 교관이 고개를 끄덕 + 말풍선 `음. 다음 단계로 넘어가도 되겠군.` → `성공!` 글자 + 별이 위에서 날아와 별 칸에 **쾅 박히는** 연출 (빛 번짐·작은 흔들림).
3. 연출 중엔 버튼 잠금. 연타 방지.

### 승부 연출 (★5)

- 같은 무대에서 결투 재생 (서버 events, 하단바 결투 재생 `playDuel` 의 그리기를 무대용으로 재사용). 체력 바 두 개.
- **승리**: 교관이 무릎 꿇거나 무기를 거두며 `훌륭하다… 더 가르칠 것이 없구나.` → 다섯 번째 별이 가장 크게 박히고 `수료!` 도장 → 다음 교관 칩이 열리는 연출 (조건이 되면).
- **패배**: 기사가 쓰러지고 `아직 멀었다. 더 단련하고 오너라.` + `교관 전투력 n · 내 m` 다시 보여 주기.

### 아트

- 교관 다섯 명은 **실루엣부터 다르게** (색깔놀이 금지): 검술 사범 = 상투·도복·목검, 방패 교관 = 투구 깃털·대형 방패·두꺼운 어깨, 숲의 사냥꾼 = 후드·망토·장궁, 화산 투사 = 맨 상체 문신·쌍도끼·뿔 투구, 성좌의 은자 = 긴 수염·삿갓·별무늬 로브·지팡이. `cutShot` 으로 나란히 찍어 확인.
- 배경: 도장은 새로 만든다 (dev/bggen 파이프라인, 저해상도 고퀄 도트). 나머지는 기존 src/bg 재사용.
- 별 박힘·말풍선·도장은 픽셀 스킨(src/skin/pixel.css 톤)에 맞춘다.

## 수용 기준

- [ ] 훈련장 Lv5 → 훈련 최대 50, Lv6·Lv20 에서도 50 — 콘솔 `trainMax(TRAINING[0])`.
- [ ] 1차 네 항목을 50 으로 맞추면 수료 칩으로 바뀌고, 훈련장 Lv6 이상이면 첫 교관 무대가 열린다 — 마을 탭 스크린샷.
- [ ] 교관은 순서대로만 열린다 (앞 교관 별 5 + 훈련장 Lv 6·10·14·17·20).
- [ ] 수련 비용 = 최고 스테이지 몬스터 골드 × 500 × 1.5^(별−1) — 콘솔로 S.best 를 바꿔 확인.
- [ ] 성공 확률·눈도장: 10만 회 콘솔 시뮬로 별마다 기대 시도 수가 표(1.6·2.0·2.4·3.0)와 ±0.05 안.
- [ ] 실패해도 별이 떨어지지 않는다.
- [ ] 별 보너스가 표대로 `stats()`·`profile()` 에 반영 (검술 사범 별 5 → atk ×1.15 등).
- [ ] 수련 연출: 공격 1~2회 → 실패(맞고 대사) / 성공(끄덕·대사·별 박힘)이 보인다 — 스크린샷 두 장, 건너뛰기 동작.
- [ ] 승부: 서버 API 로 계산되고, 이기면 별 5 + 다음 교관 열림, 지면 골드만 차감.
- [ ] 교관 난이도: 기준 기사 vs 교관 승률이 교관마다 목표(55·50·45·40·35%) ±5%p, 레벨 50·100·150 구간 모두 — dev 시뮬 출력.
- [ ] "레벨만 높은 기사"(같은 레벨, 강화·숙련도 0) 는 교관1 에게 승률 20% 아래 — dev 시뮬.
- [ ] 교관 다섯 실루엣이 서로·기존 직업과 구분된다 — cutShot 나란히.
- [ ] 진행 봇 비교 (season6 기준 → 교관 추가, 14일·8시드 중앙값): 스테이지 진행 변화 +10% 안, 7일 이후 남는 골드가 눈에 띄게 줄어든다.
- [ ] 좁은 창(360px)에서 무대·버튼이 잘리지 않음 — 스크린샷.
