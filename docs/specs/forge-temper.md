# 대장간 담금질대 (강화 확률 보조)

- 상태: 완료
- 관련 코드: src/data.js (`FORGE_FAC.temper`, `TEMPER_*`, `enhanceOddsAt`), src/gear.js (`enhance`), src/ui.js (`enhOdds`, `forgeFacRow`)
- 최종 갱신: 2026-10-13

## 목표
강화 하락률이 높아 +20까지 올리기 버겁다는 피드백 → 대장간 시설로 +20까지의 길을 완화한다. 단 **+20 이상은 계속 어렵게** 둔다 (사용자 요구).

## 규칙
- 대장간 시설 3번째 `temper` (🔥 담금질대). 다른 시설과 같이 최대 Lv = 대장간 건물 Lv(≤20), 비용 `forgeFacCost`.
- 효과는 **+0 ~ +19 에서 시도하는 강화**(= +20 도달까지)에만 적용. +20 이상에서 시도하면 원래 확률 그대로.
  - 성공 확률 +0.5%p × Lv (Lv20 +10%p, 상한 95%)
  - 실패 시 하락 비율 × (1 − 0.015 × Lv) (Lv20 −30%)
  - 초기화 비율은 그대로.
- id 를 `anvil` 로 쓰지 않는다: 0.12.2 연마대(`anvil`)를 core.js migrate 가 매 로드마다 환급·삭제한다.

| 담금질대 | 0→+10 | 0→+15 | 0→+20 (시도/강화석) | +12 시도 성공/하락 |
|---|---|---|---|---|
| 없음 | 15회 | 35회 | 112회 / 1,809개 | 40% / 15.6% |
| Lv20 | 13회 | 25회 | 54회 / 844개 | 50% / 9.1% |

(보호 주문서 없이 기대값. +20→+25 구간 확률은 그대로지만 떨어진 뒤 복구가 쉬워 0→+25 총 기대 1,217회 → Lv20 약 605회)

## UI
마을 → 대장간 → 시설 목록에 한 줄: `🔥 담금질대 Lv n/대장간Lv · 성공 +x%p · 하락 −y% → 다음`. 부위 강화 칸의 확률 표기(`enhOdds`)는 보정된 확률을 보여준다.
