## 규칙

### 숙련 Lv
- 스킬마다 숙련 경험치 `S.skm[스킬 id]` → 숙련 Lv 1~30.
- **경험치 = 시전 1번에 +1.** 장착된 스킬만 시전되니 장착 = 성장. 궁극기도 같다.
  - 실제 전투(원정 화면·미궁·탑·성벽): `startCast` 에서 내 기사(owner 'hero')일 때 +1.
  - 오프라인 원정 계산(`simulate`): 싸운 시간 `fight` 를 원정 기록 `S.trip.fightSec` 에 쌓고, 귀환할 때 장착 스킬마다 `fightSec × 0.85 ÷ 쿨` 만큼 (0.85 = 시전 중이라 다른 스킬을 못 쓰는 몫, 봇으로 실제 전투와 맞춘다).
  - 레이드(서버 전투)·결투는 오르지 않는다.
- Lv 문턱 (누적 경험치, 시안 — skill-redesign 검토 페이지 계산기):

  | 스킬 | Lv10 ★ | Lv20 ★★ | Lv30 ★★★ |
  |---|---|---|---|
  | 1차 스킬 | 60 | 800 | 6,000 |
  | 2차 스킬 · 새 스킬 | 100 | 1,500 | 11,000 |
  | 궁극기 | 60 | 800 | 5,000 |

  Lv1~10 은 문턱까지 (Lv−1)/9 의 1.6제곱, Lv10~30 은 두 문턱 사이를 등비로 나눈다. → 1차 스킬 첫날 ★, 2일 ★★, 5일 ★★★ / 주력 2차 스킬 전직 다음 날 ★, 4일 ★★, 9일 ★★★ / 궁극기 3차 전직(약 3일) 다음 날 ★, 9일 ★★★ (검토 페이지 계산, 시전 비율 0.51).
  - 처음 시안(60/600/3,000 · 100/1,000/4,500 · 60/400/1,500)은 7일차에 다 Lv30 이 되어 8~10일 성장이 0 이라 올렸다.
  - 후반엔 Lv 한 칸이 커서 "원정마다 +Lv" 가 15~30% 로 떨어진다 → 귀환 보고에 "다음 Lv 까지 %" 를 같이 보여 주고, 후반의 잦은 변화는 룬(드랍)·진화가 맡는다.
- 효과: **Lv 마다 위력 +2% · 쿨 −0.8%** (Lv30 = 위력 ×1.58 · 쿨 ×0.77 — 0.28 의 스킬 Lv5 와 같은 크기). `T7_TUNE.pow` 눈금은 그대로 쓰고 봇으로 다시 맞춘다.
- 모습: **Lv 10·20·30 에 ★·★★·★★★**. 캠프에서 낮은 모습을 골라 쓸 수 있다(지금 `use` 그대로). 연출 세기는 연출 등급표(1차는 절제)를 따른다.

### 📖 비전서 바치기
- 스킬 탭에서 스킬마다 "📖 바치기": **1권 = 숙련 경험치 +20** (시안). 한 번에 1·10·전부.
- 비전서 수급(봇 0.28.5 heavy 중앙값): 1일 22 · 3일 57 · 5일 96 · 10일 173권 누적 (= 경험치 약 3,500) → 늦게 얻은 새 스킬 하나를 ★★ 까지 끌어올리는 정도. 따라잡기용.
- 상한: 바치기로는 그 스킬을 **Lv20(★★)까지만** (★★★ 는 써야 온다 — "쓰면 자란다" 유지). 시안.

### 스킬 얻기 (트리 없이)
| 스킬 (칸 이름) | 얻는 때 |
|---|---|
| 1차 스킬 (`slash`) | 1차 전직 |
| 2차 스킬 둘 (`gale`·`iaido`) | 2차 전직 |
| 새 스킬 넷 | 부모 스킬 **★ (숙련 Lv10)** + 2차 전직: `gale` ★ → `whirl` · `iaido` ★ → `flash` · `slash` ★ → `wave` · `wave` ★ → `storm` |
| 궁극기 (`ult`) | 3차 전직 |
| 융합 셋 · 궁극기 변형 | 진화(4단계)에서. 그때까지 없다 |

- 새로 얻은 스킬은 빈 장착 칸이 있으면 바로 장착. 귀환 보고에 "✨ 새 스킬: 검무 회오리 (질풍난무 ★)".

### 트리에서 빠지는 것 → 갈 곳
| 0.28 트리 | 이번 단계 | 나중 |
|---|---|---|
| 🌟 레벨업 포인트 · 트리 판 · 되돌리기 · 초기화 | **없앰** | — |
| 스탯 5 (공격 +6% · 치명 +4.5% · 체력 +9% · 공속 +6% · 받는 피해 −6%) | **전직하면 자동**: 1차 전직 = 공격·치명·체력 · 2차 전직 = 공속·받는 피해 | — |
| 스킬 위력 Lv · 모습(★) | 숙련 | — |
| 변형 13 · 키스톤 7 | 없음 | 2단계 룬 (변형 = 일반~영웅 룬, 키스톤 = 전설 룬) |
| 융합 3 · 궁극기 변형 3 | 없음 | 4단계 진화 |
| 장착 칸 1~4 · 궁극기 칸 (`T7_SLOTS`) | **그대로** | — |

- ⚠️ 변형·키스톤이 룬 전까지 사라지므로 **숙련만 따로 배포하지 않는다.** 숙련 + 룬을 한 릴리스로 낸다 (작업은 숙련 → 룬 순서, 브랜치 `skill-redesign`). 연계·진화는 그다음 릴리스.

### 보스 벽 기믹 약화 (같은 릴리스, 원칙 ③ "정답 강요 금지")
- 지금 `T7_GIM` 의 `pen`(대응 없으면 DPS 손실 35~45%)은 트리 노드(`cnt`)로 막는다 → 트리가 없어지면 모두 대응 0 이 되어 최대 손실.
- 바꿈: `pen` 을 **0.10** 안팎으로 (모든 기믹). 대응(`cnt`)은 룬 단계에서 룬 꼬리표로 다시 붙이되 "맞는 빌드면 조금 더 빨리" 정도 (보너스 쪽). 벽 체력 배율(`T7_WALL_MUL`)은 봇으로 다시 맞춘다 (벽이 "막힘 → 성장으로 돌파" 로 느껴지게: 지금처럼 원정 2~3번).
- 귀환 보고는 "몇 % 까지 깎았나"만. "추천 갈래" 줄은 뺀다.

### 세이브 옮기기 (0.28.x → 숙련)
- `S.t7.rk` 의 스킬 칸 r · 모습 노드 칸 → 시작 숙련 Lv = max(2·(r−1)+1, 모습 단계 × 10) 에 해당하는 경험치. 나머지 노드·포인트는 버린다(돌려줄 포인트가 없다 — 대신 스탯은 자동).
- `S.t7.eq`(장착)·`slots`(산 칸)·`use`(고른 모습)는 그대로.
- 옛 시즌 숙련(`S.mast`, 📖 Lv)은 쓰지 않는다 (시즌7 리셋 뒤라 0).

- **귀환 보고**: "⚔️ 숙련" 한 덩어리 — 장착 스킬마다 `질풍난무 Lv13 → 14` 또는 `질풍난무 Lv27 (다음까지 62% → 81%)` 한 줄, ★ 해금·새 스킬은 강조 줄. 길면 접는다.
- 연출: ★ 해금 순간 큰 배너 없음 (원칙 ④). 보고 줄과 다음 시전의 작은 글자로.
