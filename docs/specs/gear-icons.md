# 장비 아이콘 개성화 (16×16 고유 도트)

- 상태: 완료
- 브랜치: `season6`
- 관련 코드: src/gear-art.js (GEAR_ART, 새 그림), src/ui.js (gearSprite·paintGearIcons), index.html (.gicon 크기), dev/gear-preview.py (옛/새 비교 PNG)
- 최종 갱신: 2026-10-13

## 목표
장비 100종이 12×12 모양 21개를 색만 바꿔 나눠 쓰고 있다 (판금 13종, 반지 보석 11종, 로브 9종이 같은 실루엣). 이름이 궁니르든 녹슨 장검이든 같은 그림이라 개성이 없다.
장비마다 이름·설명에 맞는 고유 그림을 그려, 실루엣만 봐도 무슨 장비인지 알게 한다. [색깔놀이 금지](../../CLAUDE.md).

## 규칙
- 크기 16×16 (+ 잉크 외곽선 1px = 18×18). 12×12 보다 디테일 칸이 1.8배 — 코등이·문장·보석·불꽃 결 같은 특징을 넣을 수 있다.
- 직접 픽셀을 찍는다 (AI 생성 안 씀). 큰 색 덩어리, 재질마다 밝음/보통/그늘 3단계까지, 잔점 노이즈 금지. 외곽선은 자동.
- 무기는 칼끝·날이 오른쪽 위, 손잡이가 왼쪽 아래 (지금과 같은 방향). 갑옷은 정면, 장신구는 정면 또는 살짝 비스듬히.
- 같은 계열끼리는 **실루엣부터 다르게**: 날 모양(곧은·톱니·굽은·넓은), 코등이 모양, 길이·굵기, 어깨받이 유무·모양, 망토·후드·목깃, 보석 수·위치.
- 등급이 오를수록 장식이 늘어난다:
  - 일반: 수수하고 낡음 (이 빠짐·녹·헝겊), 장식 없음
  - 고급·희귀: 깔끔한 제작품, 색 포인트 하나
  - 영웅: 보석·문양 테두리
  - 전설 이상: 이름·설명의 모티프가 그대로 보임 (솔라리스 = 햇살 원반 코등이, 라그나로크 = 용암이 흐르는 톱니 칼날, 아스트라 = 칼끝의 별)
  - 레이드 세트: 그 보스의 모티프 (슬라임 왕관 = 슬라임 방울, 크라켄 = 촉수·먹물 진주)
- 등급 빛 효과(.gicon.g2~g7 CSS 그림자·애니메이션)는 그대로.
- 화면 크기: 18px 그림을 정수배로 — 목록 36px(2배), 상세·장착 칸 54px(3배). 지금(34·42·48px)과 비슷한 크기.
- 전리품 상자 아이콘·필드 드롭 상자는 그대로 12×12 (이번 범위 아님).
