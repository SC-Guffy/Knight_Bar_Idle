## 왜 다시 기획하나
2026-10-20 사용자: "스킬이 우리 게임에 맞게 기획부터 다시 가면 좋겠는데, 내가 너무 안일하게 딸깍으로 끝내려고 했나 봐."
- 0.28.x 트리(1안 → 4안)는 디아블로·로아처럼 **직접 조작하는 게임의 틀**을 가져와 모양만 바꿔 왔다. 루프는 여전히 "포인트 찍고 → 원정 → 딸깍".
- 우리 게임에서 플레이어가 겪는 건 **캠프에서의 선택**과 **돌아왔을 때의 결과**, 그리고 원정 중 **화면 구석에서 기사가 싸우는 걸 보는 것**뿐이다.
- 시즌7 목표(skill-build-tree.md)는 그대로: 원정 1~2번마다 변화 · 스탯을 올려 못 뚫던 벽을 뚫는 재미 · 7~10일 동안 계속 자라는 느낌.

## 원칙 (사용자와 합의한 것)
1. **성장은 원정이 만든다** — 포인트를 찍는 딸깍이 아니라, 원정에서 쓰고·주운 것이 쌓여 돌아온다.
2. **선택은 캠프에서 한다** — 무엇을 데려갈지(장착 칸)·무엇을 끼울지(룬)·어떤 순서로(연계).
3. **정답 강요 금지** (2026-10-20 사용자): "벽의 답을 강제해 그걸 노려야만 보스를 깨는 구조는 피하고 싶다."
   - 보스 기믹(보호막·졸개·광폭화·장판)은 **잘 맞는 빌드가 조금 유리한 맛**이지, 그 빌드가 없으면 못 깨는 벽이 아니다. 전반적인 성장(숙련·장비·훈련)으로 언제든 뚫린다.
   - ⚠️ 지금 시즌7 보스 벽(src/tree7.js `T7_GIM`)은 대응 갈래가 없으면 DPS −35~45% 라 사실상 정답 강요다 → 재기획 때 약하게(예: 대응 없음 −10% 안팎, 대응 있으면 +보너스)로 바꾼다.
   - 귀환 보고에는 "얼마나 깎았나"만 (답 안내는 하지 않는다).
4. **연출 등급은 전직 차수를 따라간다** (2026-10-20 사용자): "초반부 스킬은 절제된 멋. 1차 스킬부터 ★★★ 달았다고 화면에 대문짝만하게 텍스트가 뜨는 연출은 후반부 스킬과 차이를 벌리지 못해 매력을 떨어뜨린다."
   - 1차 스킬의 ★★★ 는 **같은 스킬이 더 정교·묵직해지는 것**(궤적이 또렷해짐·잔상·타격감)이지 화면을 덮는 것이 아니다.
   - 화면 전체 연출(어두워짐·화면 정지·큰 글자·화면 흔들림 강하게)은 **3차·궁극기 전용**.
   - 아래 "연출 등급표" 참고.

## 규칙 시안

### 1. 숙련 (쓰면 자람)
- 스킬마다 숙련 Lv 1~30. **장착해서 데려간 스킬만** 시전할 때마다 숙련 경험치 +1 (궁극기도). 원정이 끝나면 귀환 보고에 오른 Lv.
- Lv 마다 위력 +2% (Lv30 = +58%). **Lv 10·20·30 에 ★·★★·★★★ 모습** (연출은 아래 등급표 안에서).
- 필요 경험치(시안, 검토 페이지 계산기): 1차 ★ 60 · ★★ 600 · ★★★ 3,000 / 2차 100 · 1,000 · 4,500 / 궁극기 60 · 400 · 1,500 → 1차는 첫날 ★·★★, 2차는 전직 다음 날 ★·4~5일 ★★★, 궁극기는 3차 전직 하루 뒤 ★★★.
- 📖 **비전서를 바치면 숙련 경험치**(1권 = 시안 +20): 막 배운 스킬·안 쓰던 스킬 따라잡기 + 옛 "갖다 바쳐서 렙업" 손맛. 비전서는 지금도 탑·레이드·던전에서 쌓이고 있다.
- 옛 숙련(📖 Lv·스킬별 트리 V2)과 0.28 트리는 이걸로 바뀐다.

### 2. 룬 (줍는 변형)
- 룬 = **효과 하나 + 색**. 어느 스킬에나 끼울 수 있는 범용 룬이 기본 — 효과는 지금 고유 특수 `SPEC_TYPES`(처형·보스·출혈·연속·약점·환급·광역·관통…) 와 모양 변형(한 번 더 · 잔상 · 갈라짐)을 그대로 쓴다.
- 등급 일반 ~ 전설 (값 폭이 커진다). **전설 = 키스톤급**(큰 규칙 + 대가, 지금 키스톤 7개).
- 룬 칸: 스킬마다 ★ 에 1칸, ★★★ 에 2칸 (숙련이 커스터마이즈를 연다). 캠프에서 무료로 바꿔 끼움.
- 얻는 곳: 원정 상자(보스 상자에서 더 자주) · 레이드 · 탑. 같은 룬 3개 → 한 등급 위 (가방 정리).
- **룬 색이 스킬 색을 바꾼다**: 지금 VFX 시트를 색 램프로 다시 칠함 (새 그림 없이 "보이는 변화").

### 4. 연계 (시전 순서 퍼즐)
- 장착 순서 = 시전 순서 (지금 그대로). **앞 스킬이 끝나고 2초 안에 다음 스킬이 나가면 연계** → 다음 스킬 피해 +20% + 연계 이름 작은 글자.
- 스킬마다 꼬리표 하나: ⚔️ 돌진 · 🎯 단일 · 🌀 광역 · ➶ 투사체 · 🔥 장판 · ✨ 강화. 꼬리표 짝마다 이름 붙은 합동기 효과 (시안 6가지):
  돌진 → 단일 = **추격**(대상에게 순간이동, 확정 치명) · 광역 → 광역 = **연쇄**(범위 +30%) · 투사체 → 투사체 = **집중**(같은 적 노림, +30%) · 장판 → 돌진 = **폭발 돌파** · 강화 → 아무거나 = **충전**(+40%) · 단일 → 광역 = **파편**(맞은 적이 터짐).
- 자동 전투 규칙: 다음 차례 스킬이 1초 안에 쿨이 끝나면 기다렸다 쓴다 (연계를 잇기 위해). 쿨이 맞물리게 고르는 게 퍼즐.
- 연출은 등급표 안에서 (1·2차 연계 = 작은 글자 + 국소 효과).

### 5. 진화 (시즌 목표)
- 스킬 ★★★ + 조건 → **진화 스킬**(새 이름·새 그림, 3차급 연출). 지금 융합 스킬 45종(15줄기 × 3)과 궁극기 변형을 진화 결과로 재사용.
- 조건 시안: 두 스킬 모두 ★★★ + 둘을 연계로 이은 횟수 N (예: 질풍난무 ★★★ + 일섬 ★★★ + 질풍난무 → 일섬 연계 200번 → **질풍 일섬**). 진화하면 두 스킬 대신 장착 칸 하나에.
- 궁극기 진화: 궁극기 ★★★ + 전설 룬 하나 → 그 룬 계열의 궁극기 변형(만검·일도양단·검우).
- 시즌 내내 "다음 진화까지" 진행도가 보인다 (캠프 스킬 탭 상단).

### 레벨업 보상 · 트리 포인트
- 시안: 트리 포인트를 **없앤다**. 레벨업은 스탯 자동 상승(지금 스탯 노드 몫) + 장착 칸(Lv) 해금. 키스톤은 전설 룬으로.
- (대안) 작은 패시브 판(스탯 5 · 키스톤 몇 개)만 남긴다.

제안 — **연출 예산은 전직 차수가 정하고, ★ 는 그 안에서 채운다**:

|---|---|---|---|---|
| ★ 가 바꾸는 것 | 정교·묵직 (궤적·잔상·검풍 한 줄), 크기는 기사 주변 | 범위·갈래 (여러 겹·분신·마법진) | 새 그림 더하기 | 화면 전체 장면 |

| 막타 정지·흔들림 | ≤0.1 · ≤0.3 | ≤0.16 · ≤0.45 (★★★ ≤0.22 · 0.6) | 그 사이 | ≤0.32 · ≤0.95 |
| 금빛 | 없음 (★★★ 는 날·궤적 가장자리만 흰빛) | ★★★ | ★★ 부터 | 자유 |
| 오라·마무리 섬광 | 없음 | ★★ 오라 · ★★★ 섬광 | 있음 | 있음 |
