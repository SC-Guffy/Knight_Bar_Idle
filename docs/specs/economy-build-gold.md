## 문제 (0.30.7 작업 트리, 봇 측정)

1. **건설 시간이 10일차부터 마을을 멈춘다.** 건설 줄 1개 × `buildTimeAt = 60·1.8^(Lv−1)`초: Lv12→13 19.3시간 · Lv14→15 34.7시간 · Lv16→17 4.7일 · Lv19→20 27.3일, 4건물 만렙 대기 합 246일.
   - 수명 봇(heavy 21일 8시드): 건물 합 10일 45 → 14일 47 → 21일 **48** (80 만렙). 훈련장 Lv16 에서 멈춰 훈련 합이 상한(640)에 붙은 채로 21일까지 간다 — 훈련 : 장비 4:6 목표가 장비 쪽으로 쏠린다.
2. **건물·시설·전직 골드는 '죽은 비용'.** `buildCost.gold = 40·1.9^(Lv−1)`, `forgeFacCost.gold = 150·1.75^Lv`, 전직 2차 5만·3차 5e10 은 스테이지를 안 따라간다. 장부 봇 7일: 골드 지출의 **100% 가 창고 교역**, 건물 14만·시설 16만 골드(수입 2e28 의 0%).
3. 그런데 **골드가 '무한 잉여'는 아니다** (이번에 새로 잰 것). 21일 보유 골드 10^32 는 잡몹 골드(2·1.2^(스테이지−1))가 커서 생긴 눈금일 뿐, 보유 골드 ÷ 최고 스테이지 잡몹 골드 = 10^3.3 ≈ **2,000마리분 (원정 약 8시간)** 으로 7~21일 내내 같다. 24시간 봇(장부 봇 21일)은 수입의 96% 를 교역에 쓴다. 교역(값 ×1.3/회)이 남는 골드를 다 받아 목재·철광석으로 바꾸는 구조다.
4. 즉시 완료(골드로 시간 사기)를 쓰면 건물 합 58 까지 가고 다음 벽은 목재(Lv17 훈련장 목재 9.8만, 창고 14.8만).

## 목표

- 건설 시간이 10~21일 구간에서 마을·훈련을 멈추지 않는다. 열심 유저 기준 21일에 훈련장 Lv19~20(훈련 상한 190~200).
- 4건물 만렙은 장기 목표로 남긴다(한 줄 대기 약 24일, 즉시 완료를 쓰면 더 빠름).
- 골드는 역할(공용 화폐: 재료·시간·소모품·입장권을 산다) 그대로. 소모처를 새로 끼우지 않고, 이미 있는 건물·시설·전직 골드를 **양만 스테이지에 맞춘다** (currency-roles 원칙).
- 7일 시즌 체감(초반)은 거의 그대로, 10일 뒤만 풀린다.

### 2. 건물 목재·철광석 — Lv8 위 증가율 1.5 → 1.35 (`BUILD_MAT_LATE`)
- `buildMatGrow` 식 그대로, `BUILD_MAT_LATE = 1.35`. 교역 양(`tradeAmount` = 다음 건물 비용의 10%)·미궁 🪵🪨(`dgNextBuildCost`)·가방 비용(`bagUpCost` = 여관 목재 ÷ 4)이 같이 따라 내려간다.
- 훈련장 목재: Lv14 2.92만 → 1.55만 · Lv17 9.84만 → 3.81만 · Lv19 22.1만 → 6.95만. 4건물 1→20 목재 합 278만 → 111만.
- 대장간 시설(`forgeFacCost` 🪨 `10·1.7^Lv`)은 그대로.

### 3. 골드 비용 — 스테이지에 묶되 작게 (b 약)
기준 = `priceBest()` 잡몹 골드 `G = monsterStats(priceBest(), false).gold` (기사단이면 기사단 최고 스테이지 — guild-price-base 규칙 그대로). 진행 봇 원정 1시간 ≈ 잡몹 250~263마리.
- 건물 Lv L → L+1: `ceil(G × BUILD_GOLD_MOBS × BUILD_GOLD_GROW^(L−1) × mul.gold)`, `BUILD_GOLD_MOBS = 10`, `BUILD_GOLD_GROW = 1.3` → Lv5 29마리(약 7분) · Lv10 106마리(약 25분) · Lv14 303마리(약 1.2시간) · Lv19 1,125마리(약 4.4시간). 교역 첫 회(200마리)와 같은 눈금.
- 대장간 시설 Lv L → L+1: `ceil(G × 5 × 1.3^L)` (`FORGE_GOLD_MOBS = 5`).
- 전직: 1차 500 골드 그대로, 2차 `G × 5`, 3차 `G × 400` (`CLASS_GOLD_MOBS = { 2: 5, 3: 400 }`). 3차는 스테이지 100 근처에서 지금 5e10 과 같은 값(잡몹 1.4e8 × 400 ≈ 5.6e10)이 되게 맞춤. `CLASS_REQ[t].gold` 를 쓰는 곳(`classBlocker`·`changeClass`·ui.js 전직 칩)을 함수 `classGold(tier)` 로 바꾼다.
- 훈련 골드(`trainCost = base·grow^Lv`)는 이번엔 그대로 둔다(훈련은 훈련장 Lv 상한에 묶이는 구조라, 골드까지 묶으면 벽이 둘이 된다 — 남은 일).
- 측정: 골드 지출 중 건물 0% → 1.4%(7일), 7일 스테이지 영향 −4% 안쪽(장부 봇 337 → 322, 수명 봇 21일 397 → 388 은 시드 흔들림 수준).

### 4. 그대로 두는 것
- 즉시 완료 `rushPrice`(남은 1분 × G × 2.2), 교역 값·횟수, 창고 비축, 건설 줄 1칸, 훈련 상한 `trainCapAt = 10 × 훈련장 Lv`.
