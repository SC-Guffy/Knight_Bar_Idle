요지

  • 한 번 시도 = 📕 c권. 성공하면 별 하나, 실패하면 📕 만 쓰고 별은 그대로.
  • 성공 확률은 버튼 옆에 숫자로 보인다. 숨은 보정(0.20.0 판 눈도장)은 없다.
  • 천장: 같은 별에서 N번 실패하면 다음은 확정 → 최악이 정해져 있다.
  • 기대 📕 합은 지금 확정 표(110권)와 비슷하게, 페이스(★1~4 약 10일) 유지.

화면 미리보기 (무대 아래 한 줄)

버튼을 눌러 시도해 볼 수 있어요 (교관 2 ★3 기준, 이 페이지 안에서만).

확률 · 한 번 비용 (바꿔 보기)

칸마다 왼쪽 = 성공 확률 %, 오른쪽 = 한 번 비용 📕. 괄호 안은 지금 확정 표 권수.

시뮬레이션 (10만 번)

다섯 명 ★1~4 전부에 드는 📕 분포 (노란 막대 = 지금 확정 표 110권)

결정할 것

  1. 천장 — 3번 (권장) / 없음 / 2번
  2. 실패 시 📕 — 전부 소모 (권장) / 절반 돌려줌
  3. 확률·비용 표 — 위 시작안 그대로 할지
