창기사 계열 통짜 시트 — 0회 준비

스펙 docs/specs/legacy-class-sheets.md · 창기사 · 용기병 · 할버디어 · 랜서 · 용황 · 전쟁군주 · 천마장군 · 2026-10-15

지금 상태: PixelLab 0회 (보류 — 검사 계열 시범 승인 뒤 계획서 재승인). 생성 없이 할 수 있는 준비만 했다.
  • 7종 기준 그림: 지금 게임의 대기 자세를 1도트 = 1px 로 찍어 칸(창 96, 할버드·도끼창 128)과 발 기준점에 맞췄다.
  • SHEET_ON 에 7종 줄을 넣었다 (모두 false — 시트가 승인되면 켠다). 주소 ?sheets=0 이면 전부 꺼진다.
  • 동작 키 매핑: 스킬 자세의 무기 각도 wa → cast 줄. 공용 sheetFrame 에 cast.wrap(각도를 한 바퀴로 감싸 비교)을 더했다 — 할버드 대회전 wa 가 −6.5 ~ +7.8 로 돈다.
  • 시트 조립 dev/spear/build.py: 프레임 소스(지금은 기존 그림 자리표시, 나중엔 생성 결과)와 상관없이 같은 규격으로 시트·메타·몽타주·GIF 를 만든다. 칸 가장자리 닿음(잘림) 검사, hand(무기 끝)·head 점 자동.

2. 기준 그림 (지금 게임 그대로, 칸·발 기준점에 맞춤)

순서: 창기사 · 용기병 · 랜서 · 할버디어 · 용황 · 천마장군 · 전쟁군주 (1차 → 2차 → 3차). 발을 같은 자리에 맞췄다. 흑백·실루엣은 같은 계열 구분 확인용이다.

4. 동작별 프레임 몽타주 — 자리표시 (지금 게임 그림을 새 칸에 넣은 것)

생성 결과가 아니다. 칸 크기·발 기준점·잘림·cast 각도·파생 동작(hurt·death)을 확인하려고 지금 조립식 그림을 그대로 넣었다. 녹색 줄 = 발, 빨강 = hand, 파랑 = head, 칸에 닿으면 빨간 테두리.

    dev/skills.html 콘솔에서 spear/capture.js 를 불러 await spearCap('dragoon') (수신기 python -I dev/spear/recv.py dev/spear/shots 8896) → python -I dev/spear/build.py dragoon --install → node dev/boxer/sheet-meta.js → 새로고침 뒤 SHEET_ON.dragoon = true. 끝나면 git checkout src/sprites/meta.js 하고 src/sprites/dragoon.* 를 지운다.

6. 정할 것

  1. 실루엣이 비슷한 쌍: 기존 그림에서 창기사·용기병·용황(뾰족 투구 + 세운 창)이 흑백 실루엣으로 많이 닮았다. 시트는 지금 그림을 기준으로 하므로 그대로 옮기면 닮음도 옮겨진다. 생성 때 용기병에 날개 달린 투구·용 비늘 망토, 용황에 뿔 왕관·용 날개 망토처럼 틀을 바꿀지.
  2. 원형 공유: 찌르기형 5종(창기사·용기병·랜서·용황·천마장군)과 휩쓸기형 2종이 원형 동작을 나눠 쓰는 계획(PixelLab 최대 14회)을 검사 계열 시범 결과에 맞춰 다시 올린다.
