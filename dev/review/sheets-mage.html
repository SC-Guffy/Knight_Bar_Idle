지금 상태 (2026-10-16): 새 방향 준비 중 (맨 위 ★ 절). 아래 0절의 마네킹 시트는 폐기된 방식이다 — 7종 시트를 만들었으나 로드맵 검수 품질 미달 — 보류 (방식 재검토 중). PixelLab usage 7 (승인 7, 재시도 0, 추가 호출 금지) · ComfyUI 0장. 게임 스위치(SHEET_ON)는 꺼 둠.
  • 7종 기준 그림: 지금 게임 그림을 3배로 찍어 1배 도트로 줄였다. 칸은 96, 발 기준점은 (44, 88)이다. 마력탄·지팡이 빛은 빼고 찍었다.
  • SHEET_ON 에 7종 줄을 넣었다. 모두 false 이고, 시트가 승인되면 켠다. 주소에 ?sheets=0 을 붙이면 전부 꺼진다.
  • 동작 키 매핑: 마법사 스킬 자세는 지팡이 기울기 bowA 만 줄 때가 있다. 그래서 공용 sheetFrame 의 cast 조건에 bowA 를 더했다. cast 줄은 key: "bowA" 로 프레임을 고른다.
  • 지팡이 구슬 빛은 시트에 넣지 않는다. 공용 drawHeroSheet 가 hand 점(구슬 가운데)에 코드로 얹는다(sheetStaffGlow). 스킬이 마력을 모으면(pull) 커진다.
  • 앉기 줄이 없는 기존 직업 시트는 마을·캠프 앉기만 예전 조립식으로 그린다.
  • 시트 조립 dev/sheets-mage/build.py: 팔레트 고정, 외곽선 통일, 발 맞춤, hand·head 점을 자동으로 잡는다. guard·hurt·death 는 PixelLab 없이 idle 에서 만든다.
  • 연결 시험 dev/skills.html?patch=sheets-mage: 기준 그림 한 장으로 만든 시험 시트를 끼워 게임에서 돌린다. 시험 시트는 src/sprites 에 넣지 않았다.

② 동작 관절 설계 — 막대 인형 (검사 세션 skel.py 형식, dev/sheets-mage/skel.py) · 그림체 B · 키 46 비율로 다시 맞춤

2.5등신으로 짠 동작의 모양은 그대로 두고 마디 길이만 3등신 키 46(192칸에서 약 92)으로 늘렸다: 다리 ×2, 몸통 ×1.15, 어깨 ×1.3, 팔 ×1.9, 머리 ×1.8. 지팡이는 키의 0.75(앞 52·뒤 16)로 했다. 발은 x 66 에 둔다(겨눔 때 지팡이가 앞으로 길어서). 평타A 당김 각도는 −125°·−135° 로 세웠다. 모든 프레임이 192칸 안이고 땅 위다.

형식은 검사 세션 skel.py 와 같다: 192칸, 발 (96, 176), 얼굴 오른쪽, 관절 13 + 머리 5. 빨강 = 지팡이 든 앞팔·앞다리, 파랑 = 뒷팔·뒷다리, 금색 선 = 덧그릴 지팡이(끝 하늘 점 = 구슬), 회색 = 기준 자세. 크게 과장: 몸통 기울기, 무릎, 발 디딤, 두 팔을 모두 움직인다. 지난 마네킹 애니는 손만 2~12칸 움직였다. 프레임마다 지팡이 각도(덧그리기용)와 cast 키 자세 bowA 를 적었다. 지팡이 끝·물미가 192칸 안이고 땅 아래로 들어가지 않는지는 자동으로 확인했다. 요청 재료는 skel/keys-<동작>.json 이다. first_frame 은 새 기준 그림이 나온 뒤 채운다.

0. 결과 — 7종 시트 (PixelLab usage 7 · ComfyUI 0장) · 검수 품질 미달, 보류 (스위치 꺼 둠)

무엇: 지팡이 원형 마네킹 한 장으로 PixelLab 원형 동작 5개를 만들었다. idle 4f · walk 8f · atkA 4f · atkB 4f · cast 8f 이고 usage 합계 7, 재시도 0이다(로드맵 승인 그대로). 원형 동작 프레임마다 7종을 입혔다(dev/sheets-mage/pipeline.py). 머리는 직업 그림에서 옮기고, 지팡이는 공용 wpn.py 로 덧그렸다. 뇌전술사는 시안 B 머리다. cast 키 자세 5장은 지팡이 각도로 골랐다. 시트는 src/sprites/<직업>.png·json 에 넣었다.
  • 원형 애니가 "이펙트 없이"라고 해도 구슬에서 빛줄기·흰 덩어리를 그렸다. 다시 뽑지 않고 고쳤다: 몸과 떨어진 덩어리는 버리고, 몸에 붙은 빛줄기는 구슬색으로 잡혀 덧그리기 때 지워진다. 지팡이를 통째로 빛줄기로 바꾼 프레임은 손에서 빛줄기 방향으로 직업 지팡이를 세운다.
  • cast 에 "머리 뒤로 젖혀 든" 자세는 없었다. bowA −1.4 키는 머리 위로 세운 자세로 대신한다.
  • 게임 스위치: SHEET_ON 마법사 7종은 false 그대로다. 공유 코드를 켜는 것은 사용자 확인 뒤에 한다. 아래 링크는 시험 패치로 그 페이지 안에서만 켠다.

7종이 같이 움직이는 모습 (idle → walk → atkA → atkB → cast 키 5장 → hurt → death, 3배)

한 줄이 한 직업이다. 칸은 idle · walk 3장 · atkA 2장 · atkB 2장 · cast 5장(bowA −1.4 · −0.7 · −0.2 · 0.7 · 1.2) · hurt · death 끝이다.

3-1. 지팡이 원형 마네킹 · 직업 입히기 시안 (정지 그림, PixelLab 0회 · ComfyUI 0장)

2026-10-16 사용자 승인: 뇌전술사 시안 B 확정 · 3차는 2차 시트 편집 · 무기는 공용 "덧그리기". 아래 입힌 결과는 지팡이를 덧그리기로 바꾸고 뇌전술사를 시안 B 머리로 입힌 판이다.

무엇: 검사 계열과 같은 "와이어프레임" 방식의 마법사판이다.
  • 마네킹(왼쪽 첫 칸): 견습 마법사 몸에서 모자·머리카락을 빼고 민머리에 눈만 남겼다. 부위마다 다른 색 3단으로 칠했다. 부위는 머리, 몸통(빨강), 바지(파랑), 신발(갈색), 손(금색), 지팡이 자루(초록)·갈래(보라)·구슬(청록)이다. PixelLab 애니가 이 색을 지키면 프레임마다 부위를 색으로 다시 가를 수 있다.
  • 입히기 (dev/sheets-mage/mannequin.py dress):
    • 머리(모자·머리카락·관·후광)는 직업 그림에서 통째로 옮겨 마네킹 머리 아랫줄 가운데에 맞춘다. 지팡이에 닿은 외곽선은 빼고 옮긴다.
    • 몸은 같은 자리 직업 색으로 칠하고, 없으면 직업 부위 3단 색으로 칠한다.
    • 지팡이 덧그리기 (공용 모듈 dev/sheets-common/wpn.py): 직업 지팡이 그림을 떼어 낸다. 지팡이 색만 바꿔 같은 자세로 찍은 캡처와의 차이로 뗀다. 이 그림을 마네킹 지팡이 칸의 손 점·끝 방향에 RotSprite 로 돌려 얹고, 쥔 손은 그 위에 다시 그린다. 그래서 화염 갈래·서리 결정·뇌전 꺾인 갈래·3차 홀 모양이 그대로 남는다.
    • 마네킹 밖의 망토·목도리 자락은 몸통과 같은 이동량으로 옮긴다.
  • 지팡이 부위 가르기: 지팡이 색만 자루 #ff00ff·갈래 #00ff00·구슬 #00ffff 로 바꿔 한 번 더 찍었다. 두 장의 차이로 칸을 정확히 갈랐다(손이 쥔 자리도).
  • 2차·견습은 잘 이어진다: 마법사·화염술사·빙결술사·뇌전술사는 원래 그림과 거의 같다(목도리 자락 포함). 몸 비율이 마네킹과 같아서다.
  • 3차는 몸이 5칸 더 크다(키 40 · 2차 35). 그래서 견습 몸 마네킹에 입히면 대마도사·빙결의 군주의 옷 무늬가 어긋난다. → 결정: 3차는 2차 시트 편집으로 만든다. 키 차이로 깨지면 그때 3차용 큰 마네킹 계획서를 낸다.
  • 정지 그림은 마네킹과 직업이 같은 자세라 쉽다. 실제 시험은 PixelLab 원형 애니(팔·지팡이가 움직인 프레임)에 입혀 보는 것이다. 검사 계열 시범 결과로 방식이 정해지면 계획서를 다시 낸다.

덧그리기 각도 시험 — 마네킹 지팡이만 돌린 가짜 프레임 (치켜듦 −150° / 기본 −79° / 앞으로 겨눔 −10° / 내리꽂기 40°)

팔 자세는 그대로 두고 지팡이만 돌린 시험이라 팔이 어색한 것은 정상이다. 실제로는 원형 애니가 팔과 지팡이를 같이 움직인다. 7종 모두 직업 지팡이가 손 점을 축으로 끝 방향을 따라간다. 1px 자루도 끊기지 않는다.

뇌전술사 실루엣 바꾸기 시안 B — 모자 대신 뻗친 머리 + 뿔 장식 관 (사용자 결정 ③)

  • 모자를 지우고 금발을 뒤로 뻗친 다발로 바꿨다. 이마에는 남색 관과 앞쪽 하늘색 보석을 넣고, 관 양끝에서 V 자로 벌어지는 하늘색 번개 뿔 둘을 세웠다. 코드로 그린 손도트 시안이다(electro_head).
  • 실루엣: 마법사는 뾰족 모자 하나, 시안 B 는 위로 벌어진 뿔 둘에 뒤로 뻗친 머리다. 흑백·실루엣에서 바로 갈린다. 화염술사(뒤통수 불꽃 다발 + 목도리)와도 틀이 다르다.
  • 3차 뇌제는 지금 흰 머리에 금관·후광이다. 시안 B 를 따르면 "뿔 관 → 더 큰 금빛 뿔 관 + 후광"으로 이어진다(3차 편집 때 반영).
