🏰 성벽 지키기 — 스펙 검토 페이지

스펙 docs/specs/castle-defense.md (상태: 확정 · 2026-10-13 — 사용자 결정 5가지 반영). 숫자 입력칸을 바꾸면 아래 표·그래프·시뮬이 다시 계산된다. 게임 코드는 아직 없다.

1. 스펙 요지

목표
  • 오른쪽에서 몰려오는 무리를 빨리 잡는 콘텐츠. 탑(버티기)·미궁(생존)과 달리 처치 속도를 시험.
  • 10웨이브, 한 판 3분 이하. 판 안 강화(카드) 없음.
  • 🧱 성벽돌 → 성벽 영구 업그레이드 · 📕 수련의 서 → 교관. 교관은 성벽 위에서 같이 싸운다.
핵심 규칙
  • 최고 스테이지 40 해금 · 무료 입장권 하루 3장 · 골드 구매(탑과 같은 곡선, 5장 보유).
  • 1~100단계, 차례로. 단계 L 의 적 = 스테이지 20 + 2L 급. 깬 최고 단계는 1장으로 소탕.
  • 기사는 맞지 않는다 — 몬스터는 기사를 지나 성벽만 친다 (일반 1/1.4초, 보스 8/2초). 내구도 100, 0 이면 실패.
  • 5·10웨이브 보스. 웨이브 간격 12초, 다 잡으면 3초 뒤 다음 웨이브.
  • 레인 길이 최대 480px (창 폭이 달라도 광역 효율이 같게).

2. 화면 목업 (하단바 150px, 정지 그림)

왼쪽부터: (넓은 창이면 성 안 풍경) · 성벽(내구도 바·균열) · 성벽 위 투석기·교관(칸당 1px)·궁수 · 성벽 앞 해자 · 기사(가장 앞선 적 쪽으로 이동) · 오른쪽 끝에서 4마리씩 쏟아지는 무리. 배경색·몬스터는 그 단계 적 스테이지의 필드.

3. 난이도 곡선 — 단계 → 적 스테이지

적 스테이지 = 기준 + 단계당 × L
적 스테이지 단일 대상·업그레이드 0 이 깨려면 필요한 내 최고 스테이지 광역(2.5)·업그레이드 0 단일·업그레이드 전부 Lv10 점선 = 필드 경계 (10단계마다)
"필요한 내 최고 스테이지" = 적 스테이지 − Δ. Δ 는 아래 6번 웨이브 시뮬이 찾는다 (업그레이드를 바꾸면 초록 선이 움직인다).

4. 웨이브 구성 (1 · 5 · 10웨이브 예시)

5. 보상표

막은 웨이브·잡은 수에 따라 (단계 )
처치 점수: 일반 1, 보스 10. 실패 판은 "막은 웨이브까지 다 잡고 다음 웨이브의 절반을 잡았다"고 가정. 첫 돌파는 🧱 만 ×2 (📕 은 보너스 없음).
단계별 다 막았을 때 (소탕 1회 = 이 값)

6. 업그레이드 (🧱, 각 Lv10) + 웨이브 시뮬

Lv n→n+1 비용 (막대) · 누적 (선, 오른쪽 축)
시뮬: 업그레이드 레벨을 바꿔 보기 — 간이 모델: 기사는 가장 앞선 적을 치고, 광역은 근처 몬스터에 같이 들어가는 몫으로 근사. 실제 스킬 광역은 구현 뒤 dev/castle-sim.js 로 다시 맞춘다.

7. 하루 수급량 추정

📕 하루 10~13권 (무료 입장) · 🧱 업그레이드 6종 Lv10 까지 약 10일 — 사용자 결정 (10-13)

업그레이드 기간 시뮬 — 겹치는 수급(첫 돌파 🧱 ×2·입장권 구매)을 넣어도 너무 빨라지지 않는가

하루: 무료 3장 + 구매 n장. 그중 "하루 오르는 단계"만큼은 첫 돌파 도전(성공 가정, 🧱 ×2), 나머지는 최고 단계 소탕. 🧱 이 6종 Lv10 비용 합계에 닿는 날.

8. 사용자 결정 (2026-10-13, 로드맵 세션 창)

  1. ✅ 기사는 맞지 않는다 — 처치 속도로만 겨룬다.
  2. ✅ 성벽 위 교관이 실제 피해 — 10초마다 공격력 × 0.4 × 별 수.
  3. ✅ 📕 무료 입장 기준 하루 10~13권 — 다 막은 판 3.4 + 0.01L 권 (교관 별 값 총 110권 ≈ 10일분). 첫 돌파 보너스 없음.
  4. ✅ 단계 곡선 20 + 2L 유지 — 100단계는 장기 목표.
  5. ✅ 업그레이드 약 10일 — 비용 80×1.4n → 18×1.4n (6종 합 33,480 → 7,530), 🧱 단계 배율 1+L/25 → 1+L/100 (시작 단계와 상관없이 9~13일로 모음). 7번 시뮬 표 참고.
