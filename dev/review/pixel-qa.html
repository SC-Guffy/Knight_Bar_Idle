요지

  • 목표: 사람 손질 없이 품질을 올리는 생성 → 검수 → 수리 반복 루프의 첫 부품. 그림을 게임에 들어간 모습으로 보고 합격(pass) · 무료 수리(fix) · 다시 뽑기(regen)를 판정하고 근거와 고칠 방법을 낸다.
  • 구조: ⓪ 게임 로더 그대로 돌려 게임 모습 만들기 → ① 규격 검사 → ② 자동 지표(경보·근거) → ③ Claude 비평 서브에이전트(채점표 7항목) + 사용자 판정을 쌓는 취향 기록.
  • 보정 결과: 지표만으로는 부족하다. 탈락 6장 중 4장만 잡고, 확정 시트 170장 중 16%를 잘못 잡는다. 그래서 지표는 경보로만 쓰고 판정은 비평이 한다.
  • 첫 적용은 VFX 시트(정답 자료가 가장 많음) → 캐릭터 시트(색깔놀이 실루엣 검사 추가) → 아이콘·배경.

다시 뽑기 6쌍 — 게임 로더를 거친 모습 (위 탈락 · 아래 합격)

직업색 시트는 대표색 #4da6ff 로 칠했다. 빨간 칩 = 지금 기준에서 뜬 경보. 탈락 이유는 사용자 판정(10-16) 그대로다.

블라인드 시험 — 비평 에이전트 12회 (이름 지우고 섞음)

결과

  • 탈락작 6장은 6장 모두 regen 으로 판정했고, 이유도 사용자 이유와 대부분 맞다 (k37 "벽돌 탑처럼 보인다" = 사용자 "요새가 조각조각", k36 "외곽선 벗김 뒤 남은 부스러기·점선 호" = "벗기면 테두리만").
  • 반대로 합격작에 박하다: 확정안 A 로는 합격작 6장 중 4장을 떨어뜨린다. 비평이 "3 = 게임에 넣어도 됨"보다 낮게 주는 경향이 있다.
  • 평균 점수로 쌍을 비교하면 6쌍 중 5쌍에서 합격작이 높다. 예외인 k37 은 비평이 새 그림도 "아래 파편이 잡부스러기"라며 regen 을 줬다.
  • B 는 이 12장에 맞춰 고른 기준이라 과적합일 수 있다 → 확정 시트 30장 오경보 시험으로 따로 확인해야 한다.
  • 한 장 검수 시간: qa.py 0.1초 + 비평 24~37초.

비평 채점표 (1~5)

항목보는 것
1 의도 일치스펙의 "목표 모습" 문장대로인가, 엉뚱한 물체(칼·산·요새)가 없는가
2 읽힘게임 배율에서 모양이 한눈에 들어오는가 (견습 기사 옆 크기)
3 깔끔함부스러기·색종이·지글거림
4 명암밝은 쪽이 주인공, 어두운 덩어리로 뭉개지지 않음, 흑백으로도 모양이 섬
5 도트다움AI 흐림 계조·계단 잡음·섞인 도트 크기·1도트 하이라이트 소실
6 움직임커짐 → 절정 → 흩어짐, 튀지 않음, 마지막 프레임이 자연스럽게 사라짐
7 프로젝트 규칙검은 외곽선 파티클 금지 · 색깔놀이 금지 · UI 톤(남보라+은회색)
