요지

  • 목표: 사람 손질 없이 품질을 올리는 생성 → 검수 → 수리 반복 루프의 첫 부품. 그림을 게임에 들어간 모습으로 보고 합격(pass) · 무료 수리(fix) · 다시 뽑기(regen)를 판정하고 근거와 고칠 방법을 낸다.
  • 구조: ⓪ 게임 로더 그대로 돌려 게임 모습 만들기 → ① 규격 검사 → ② 자동 지표(경보·근거) → ③ Claude 비평 서브에이전트(채점표 7항목) + 사용자 판정을 쌓는 취향 기록.
  • 보정 결과: 지표만으로는 부족하다. 탈락 6장 중 4장만 잡고, 확정 시트 170장 중 16%를 잘못 잡는다. 그래서 지표는 경보로만 쓰고 판정은 비평이 한다.
  • 첫 적용은 VFX 시트(정답 자료가 가장 많음) → 캐릭터 시트(색깔놀이 실루엣 검사 추가) → 아이콘·배경.
