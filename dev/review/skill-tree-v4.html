한눈에

판 = 스킬 지도

판에는 스킬·키스톤·스탯 점만 있다. 메인 스킬(강철 베기)에서 시작해 점을 따라가면 다음 스킬이 열린다. 줄 하나 = 싸움 방식 하나(연타·발도·검기), 왼쪽→오른쪽으로 깊어진다.

스킬 안 = 언제나 같은 3줄

스킬을 누르면 위력(Lv 1~5: 위력·쿨) · 모습(★ → ★★ → ★★★) · 변형(2연참 같은 추가 효과)이 나온다. 모든 스킬이 같은 모양이라 하나만 배우면 다 읽힌다.

스탯 = 길 위의 작은 점

아이콘 없는 점 15개. 스킬과 스킬 사이 길에 놓여서, 다음 스킬로 가는 길에 자연히 찍힌다. 점 하나 🌟1, 한 번이면 끝.

규칙을 줄였다

숫자 게이트(갈래 12포인트·융합 6/6)를 없애고 "앞에 있는 걸 배우면 열린다" 하나로. 융합 = 두 줄의 둘째 스킬을 다 배우면. 궁극기 = 3차 전직하면 1Lv 공짜(메인 스킬처럼).
