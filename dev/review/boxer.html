게임 캡처

1. 요지

파이터 계열 스킬에는 쿨타임이 없다. 기(氣)를 모아서 쓴다. 2차마다 기를 채우는 방식이 다르다.
  • 기 게이지 → 주 기술(직업의 대표 기술)이 쓴다. 게이지 모양·채우는 법이 직업마다 다르다.
  • 투지 → 기를 쓴 만큼 쌓인다. 물려받은 원투·Lv70 기술·궁극기가 각자 문턱마다 나간다. 스킬을 새로 배워도 다른 스킬이 덜 나가지 않게 하려고 둔 칸이다.
  • 결투·레이드·원정 시작 때 게이지와 투지가 가득 → 첫 몇 초에 스킬이 한 번씩 나가는 구조가 쿨타임 직업과 같다.
  • 쿨타임 효과 변환: ⏱️ 노드 → ☯️ 기 절약(소모 ×0.6 = 충전 ×1.67) · 고유 발동 cdreset → 게이지 최대치 50% 즉시 충전.
  • 사용자 결정: 이름(파이터 / 스트라이커 / 킥복서 / 기공사 → 챔피언 / 템페스트 / 그랜드마스터) · 새 기사만 · 장풍 2단 고정.
  • 출시: 1·2차 4종 먼저, 3차 3종은 다음 패치. 렌더링은 통짜 스프라이트 시트, 이펙트는 PixelLab 텍스처 48장.

5. 기준 그림 — 손도트 → ComfyUI 시안 → PixelLab 최종

사용자 피드백("권투가 왜 이렇게 저퀄이야")으로 기준 그림을 다시 뽑았습니다. ComfyUI(Z-Image + 픽셀 LoRA)로 직업마다 시안 12장(모두 84장) → 하나를 골라 바탕을 지우고 키 40도트로 줄여 256×256 판에 놓음 → PixelLab image-to-pixelart(256 → 64, 직업당 1회) → 바탕·발밑 그림자 정리, 발 바닥 y=58, 게임과 같은 바깥 외곽선 #0b0d14 (dev/boxer/to_pixel.py). 기존 직업은 게임의 drawHero 로 그려 1칸=1px 로 복원했습니다. 모두 같은 축척(4배 확대)입니다.
7:3 v2 (3차 키 맞춤) — 최신: 3차 3종도 1·2차와 같은 42칸 방식으로 다시 뽑아 계열 7종이 모두 기존 기사와 같은 키입니다. 3차는 스타일 참고 4장 중 1장을 부모 2차 그림으로 바꿔 특징을 이었습니다 — 챔피언 = 스트라이커 + 사자 갈기·망토·황금 건틀릿, 템페스트 = 킥복서 + 바람 목도리·발밑 회오리, 그랜드마스터 = 기공사 + 후광·금빛 장식. 보강: 스트라이커 장갑을 금속판 장갑(striker_g 28번)으로, 킥복서를 무릎 든 자세(47번, 추가 생성 없이 이미 뽑은 64장에서)로 바꿨습니다.
