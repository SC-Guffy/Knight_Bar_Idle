요청 4가지 → 이렇게 바꾼다

① 액티브 칸 = 위력·쿨만

액티브·궁극기 5칸, 융합 3칸은 찍을 때마다 위력 +15% · 쿨 −6%(융합 +25%·−8%)만 오른다. 모습은 칸으로 바뀌지 않는다. 칸 비용 🌟2 → 🌟1.

② 모습 = 모습 노드

칸에 뿌려져 있던 ★·★★·★★★ 모습을 스킬 옆에 붙은 모습 노드 3개(◆)로 뺐다. 2연참처럼 따로 찍는다. 앞 모습 + 그 스킬 칸(★ 2칸 · ★★ 4칸 · ★★★ 5칸)이 있어야 열린다. 하나당 🌟2.

③ 스탯 = 단조로운 작은 점

스탯 노드는 아이콘 없는 작은 점. 칸(1/3)도 없애고 한 번 찍으면 끝인 점 15개로 쪼개 길 위에 깔았다(합계 효과는 그대로: 공격 +6%·체력 +9%…). 글자만 한 줄(공격 +2%).

④ 메인 스킬 1칸에서 시작

1차 전직하면 메인 스킬(강철 베기) 1칸이 공짜로 찍힌 채 판 가운데 왼쪽에 놓인다. 거기서 스탯 점 길을 따라 한 칸씩 뻗어 나가야 2차 스킬·키스톤에 닿는다. 다른 시작점은 없다.

찍은 순서 (보이는 변화)

비용 비교 (검성 줄기, 택1·궁극기 변형은 하나씩)

판 전체 비용이 지금(226)과 거의 같게 맞췄다 → 10일차 열심 유저가 거의 다 찍는 속도는 그대로. 메인 스킬 1칸 공짜(−1)만큼 아주 조금 빠르다.

정해야 할 것

  1. 모습 노드 비용·조건: 시안 = 🌟2씩, ★ 2칸 · ★★ 4칸 · ★★★ 5칸 필요(지금 칸 모습과 같은 시점). 칸 조건 없이 앞 모습만 있으면 열리게 할까?
  2. 융합 모습: 시안 = ★★·★★★ 두 개(🌟2·3). 지금도 1칸 기본 → 2칸 ★★ → 3칸 ★★★ 이라 같은 단계로 둠.
  3. 스탯 점 강제 통과: 2차 스킬에 닿으려면 스탯 점 3~4개를 지나야 한다(길마다 🌟4~5). 스탯이 싫은 빌드도 꼭 지나가는 게 맞나?
  4. 모습 고르기: 지금처럼 찍은 모습 안에서 낮은 모습을 골라 쓸 수 있게 남긴다(위력은 그대로).
