🎟 입장권 골드 구매 (도전의 탑 · 재료의 미궁) — 스펙 검토

스펙 docs/specs/ticket-buy.md (상태: 초안 · 2026-10-13). 아래 입력칸을 바꾸면 표·그래프가 다시 계산된다. 게임 코드는 아직 바꾸지 않았다.

1. 스펙 요지

목표
  • 하루 무료 3장을 다 쓴 뒤에도 골드로 탑·미궁에 더 들어간다 (골드 하수구).
  • 탑·미궁 구매 규칙을 하나로: "골드만 있으면 산다, 살수록 비싸진다".
  • 하루 2~3장은 무리 없이, 4장째부터 확 부담.
핵심 규칙
  • 오늘 n번째 구매 배율 ×0.5 → 1 → 2 → 3.5 → 6, 이후 ×1.7씩. 자정에 초기화, 구매 수는 콘텐츠마다 따로.
  • 산 입장권은 콘텐츠마다 5장까지, 자정에 사라지지 않음. 무료부터 쓴다.
  • 탑: 골드 그대로(몹 골드 ×300 = 사냥 30분치), 마력석 제거.
  • 미궁: 몹 골드 ×600 (사냥 1시간치) — 한 판 보상 가치에 맞춤.

사용자가 정할 것

  • 미궁 기준값 ×600 (추천). ×300 이면 중반부터 미궁 입장권이 창고 교역보다 싼 목재·철광석 구매 수단이 된다 → 아래 2·3절에서 기준값을 바꿔 비교.
  • 탑은 마력석만 빼고 골드를 올리지 않는다 (추천). 빠지는 마력석이 보유량 대비 작다 → 4절.

2. n번째 구매 가격

"사냥 시간치"는 몹 골드 × 300 = 30분 (골드 보너스 제외 명목값, src/data.js 주석). 탑은 지금도 같은 골드에 마력석이 붙는다 — 바뀐 뒤엔 골드만.

3. 미궁: 구매 가격 vs 한 판 보상 가치 (사냥 시간으로 환산)

n번째 구매 가격 (미궁)탑과 같은 ×300 이었다면지금 스테이지 미궁 한 판 가치
미궁 한 판 기대 보상 (진행 봇 스냅샷 · 시드 7) dgUnitValue × DG_RUN_UNITS × 그림 가중치 비율
🪵+🪨 환산: 창고 첫 교역(몹 골드 × 200 = 사냥 20분치 → 창고 2시간 생산량) 비율. 두 번째 교역부터 값이 2배씩 오르니 낮게 잡은 값. 골드 몫은 사냥 약 5분치 (dungeon.js 주석의 "30분치"는 재화 6종이 나누기 전 값 — 구현 때 바로잡는다).

5. 세이브 이행

  • S.dg 에 탑과 같은 이름으로 tixExtra: 0 · buyDay: '' · bought: 0 추가 → freshDungeon() 기본값에 넣으면 끝.
  • core.js migrate 가 Object.assign(fresh, 옛 세이브) 로 얕게 병합하므로 옛 세이브는 0장·오늘 0장 구매로 열린다. 별도 이행 코드·환급·알림 없음.
  • 탑 세이브 필드는 그대로. 이미 쓴 마력석은 돌려주지 않는다 (산 시점 규칙대로 산 것).
  • 서버는 탑·미궁 입장권을 검증하지 않는다 (server/ 에 사용처 없음) → 서버 변경 없음.

6. 수용 기준 (구현 뒤 확인)

상태기준
⬜탑 구매에 마력석이 들지 않는다 (💎 0 으로 3장 산 뒤 4장째 구매 성공)
⬜탑 골드 가격 그대로 — 스테이지 60, n=0~5: 14,086,878 / 28,173,757 / 56,347,514 / 98,608,150 / 169,042,543 / 287,372,323
⬜미궁 가격 — 스테이지 60, n=0~5: 28,173,757 / 56,347,514 / 112,695,028 / 197,216,300 / 338,085,086 / 574,744,646 · 스테이지 15 첫 구매 7,703
⬜구매 수는 콘텐츠마다 따로 (탑 3장 산 뒤에도 미궁은 ×0.5)
⬜산 입장권 5장 한도 · 골드 부족 · 해금 전(스테이지 15 미만) 구매 불가
⬜무료부터 쓴다 (tixUsed 1→2→3 뒤에 tixExtra 감소), 다 쓰면 "자정에 충전 · 구매 가능"
⬜자정이 지나면 무료 3장·가격 ×0.5 로 돌아오고 산 입장권은 남는다
⬜옛 세이브(S.dg 새 필드 없음)가 migrate 에서 에러 없이 0장으로 열린다
⬜UI 스크린샷: 미궁 구매 줄, 탑 구매 줄 마력석 칩 없음, 5장 가득 시 비활성 + 사유 글씨, 도전 탭 칩 합계
⬜회귀: node dev/progress-bot.js --days 3 에러 없음, 미궁 한 판 정산 정상
