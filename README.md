# Knight Bar ⚔️

화면 하단에 붙어 사는 방치형 기사 키우기 (Electron, macOS).
기사를 원정 보내 두고 다른 일을 하다가, 돌아오면 정산하고 정비해서 다시 보내는 게임입니다.

```
npm install
npm start
```

### 업데이트 배포

설치된 앱은 게임 화면(`index.html`, `src/`)을 웹 버전(GitHub Pages, https://sc-guffy.github.io/Knight_Bar_Idle/)에서 불러온다.

- **게임 코드만 바꿨으면** `main`에 푸시하면 끝. 웹 버전이 1~2분 안에 갱신되고, 켜져 있는 앱도 5분마다 확인해서 저장한 뒤 새 버전으로 다시 불러온다 (`ui.js`의 `watchForUpdates`).
- 게임 업데이트를 푸시할 때는 `src/data.js`의 `GAME_VERSION`을 올린다. 캠프 창 탭 줄 오른쪽 끝에 이 값이 나온다.
- **`main.js`·`preload.js`를 바꿨을 때만** 설치 파일을 새로 만들어 Releases 에 올린다. 웹 코드에서 새 `window.bar` 기능을 쓸 때는 예전 앱에 없을 수 있으니 `if (window.bar.새기능)`으로 확인하고 쓴다.
- 웹을 불러오지 못하면(오프라인 등) 앱에 들어 있는 파일로 연다. `npm start`(개발)는 항상 로컬 파일을 열고, `KB_WEB=주소`로 다른 웹 주소를 지정할 수 있다.
- 예전(0.1.x) 앱의 로컬 세이브는 처음 웹 주소로 열 때 한 번 옮긴다 (`main.js`의 `migrateLocalStorage`, `store.html`).

### 설치 파일 만들기

```
npm run dist:mac   # dist/KnightBar-mac-arm64.dmg, KnightBar-mac-x64.dmg
npm run dist:win   # dist/KnightBar-win-x64.exe
```

- `productName` 은 영문(`KnightBar`)으로 둔다. 한글이면 패키징된 앱이 켜자마자 죽는다. Finder 표시 이름만 `CFBundleDisplayName` 으로 "기사 키우기".
- 세이브·계정은 앱 이름과 상관없이 `~/Library/Application Support/knight-bar` 에 둔다 (`main.js` 의 `setPath`).
- Apple 서명이 없어서(ad-hoc 서명) 받은 사람은 처음 열 때 경고가 뜬다. 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기".

## 플레이 루프

```
[출정] 보급품(부적·영약) 고르기 → 출발
   ↓  하단바에서 방치 — 스태미나가 줄고 가방에 전리품(장비·골동품·소비 아이템)이 쌓임
[귀환] 스태미나 소진 / 가방 가득 / 귀환 명령 → 캠프로 걸어서 복귀, macOS 알림 + 메뉴바 ❗
   ↓  캠프의 기사(말풍선)나 HUD 클릭 → 캠프 창
[정산] 원정 일지 확인 → 전리품 챙기기 (장비는 창고로, 골동품은 재화로, 소비 아이템은 보급품으로)
   ↓
[정비] 마을 건설 · 훈련 · 장비 장착·강화 · 보급품 구매 · 휴식(스태미나 회복) → 재출정
```

- **스태미나**: 원정 중 초당 소모(기본 100 = 4분, 완전 휴식 3분). 여관을 올릴수록 원정이 길어져(Lv10 약 42분, Lv20 약 10시간) 점점 방치할 수 있습니다. 캠프에서만 회복되고 도시락으로 즉시 회복할 수 있습니다.
- **스테이지**: 화면을 왼쪽에서 오른쪽으로 한 바퀴 지나가는 게 한 스테이지입니다. 잡몹이 화면에 깔리고 보스는 항상 우하단에 서 있으며, 보스를 잡고 오른쪽 끝을 넘어가면 다음 스테이지가 됩니다.
- **필드**: 20스테이지마다 필드가 바뀝니다 — 🌿 푸른 초원(1~20) → 🪦 묘지 무덤(21~40) → 🐸 독안개 늪(41~60) → 🌋 화산 동굴(61~80) → ❄️ 얼어붙은 설원(81~100) → 🏰 마왕성(101~). 필드마다 나오는 몬스터·보스·지형이 다르고, 필드 마지막 스테이지의 **필드 보스**(더 강함)를 한 번이라도 잡아야 다음 필드가 열립니다. 캠프 아래쪽에서 열린 필드를 골라 출정할 수 있습니다.
- **쓰러짐**: 스태미나 10을 잃고 그 자리에서 다시 일어납니다. 그 원정 동안은 보스 없이 잡몹만 바퀴를 돌며 파밍하고(HUD에 🔁, 보스에게 졌으면 같은 스테이지·잡몹에게 졌으면 한 스테이지 아래), 다음 출정 때 보스에 다시 도전합니다.
- **마을**: 한 번에 한 건물만 지을 수 있고, 원정 중에도 공사는 계속됩니다.
  - 🎯 훈련장: 훈련 레벨 상한
  - 🛏️ 여관: 최대 스태미나와 휴식 속도
  - 📦 창고: 가방 칸 수
  - ⚒️ 대장간: 무기 배율
- **훈련**: 골드로 공격력·체력·방어·수완을 올립니다. 모두 상한이 없고(훈련장 레벨 상한만 있음) 캠프에서만 할 수 있습니다.
  - 🛡️ 방어: 받는 피해 감소 = Lv/(Lv+80) — Lv 80 50%, Lv 240 75% (직업·장비의 피해 감소와 곱으로 합쳐 최대 85%)
  - 💰 수완: 골드·경험치 획득 Lv당 +3% (몬스터 처치·레이드 보상)
  - 공속·치명은 훈련으로 못 올리고 **직업**과 **장비**(무기 공속 · 장신구 치명)에서만 얻습니다. 예전 공속·치명 훈련 단계는 쓴 골드를 돌려줍니다.
- **장비**: 무기(공격력 + 등급별 공속, 대장간 배율 적용)·갑옷(체력)·장신구(등급별 치명 확률 + 치명 피해) 세 부위. 공속·치명은 스테이지와 상관없이 등급으로 정해지고 강화로는 단계당 4%만 오릅니다. 줍는 대로 장비 창고에 쌓이고, 🗡️ 장비 탭에서 자동 장착과 일괄 판매를 할 수 있습니다. 능력치는 등급과 드랍된 스테이지로 정해집니다.
- **일괄 판매**: 팔 등급을 칩으로 체크하고 버튼 하나로 팝니다(두 번 눌러 확인). 기본은 일반~영웅만 체크되어 있습니다. 🔗 세트 장비는 별도의 세트 칩(기본 해제)을 체크했을 때만 팔리고, 장착 중인 장비는 항상 빠집니다.
- **장비 도감**: 부위·등급마다 고유한 이름·설명·도트 아이콘을 가진 장비 39종 (`src/data.js`의 `GEAR_ITEMS`·`GEAR_SPR`). 등급이 높을수록 희귀해서, 원정 1회 기준 영웅은 4~5회에 1개, 전설은 약 40회에 1개꼴입니다. 영웅·전설 장비는 줍는 순간 배너로 알리고, 가방에서는 실루엣과 `???`로만 보이다가 캠프에서 챙길 때 정체가 드러납니다.
- **강화**: 부위마다 +25까지. 강화 단계는 장비가 아니라 **부위**에 붙어 있어서 다른 장비로 바꿔 껴도 유지됩니다. 골드·철광석(+10부터 마력석)이 들고, 구간이 올라갈수록 성공률이 떨어지고 실패 시 하락(+6~)·초기화(+16~) 위험이 생깁니다. 📜 보호 주문서를 켜 두면 하락·초기화가 나왔을 때 대신 부서집니다. 확률표는 `src/data.js`의 `ENHANCE` (0에서 +20까지 평균 약 700회, +25까지 약 4.8만 회).
- **오프라인**: 앱을 꺼 둔 시간도 원정·휴식·건설이 그대로 진행된 것으로 계산됩니다.

## 계정 · 랭킹 · 결투

- **계정**: 첫 실행 때 닉네임을 정합니다. 닉네임이 곧 계정이고 서버에서 중복될 수 없습니다(한글·영문·숫자·_ 2~12자, 대소문자 무시).
- **저장**: 진행은 이 기기에 먼저 저장되고 30초마다(그리고 앱을 끌 때) 서버에 올라갑니다. 오프라인이어도 게임은 계속되고, 연결되면 다시 올라갑니다. 켤 때 서버 기록이 더 최근이면 그걸 불러옵니다.
- **계정 변경**: 메뉴바 아이콘 → `계정 변경…`에서 새 기사를 만들거나, 이 기기의 다른 기사로 바꾸거나, 다른 기기의 기사를 **복구 코드**로 가져옵니다. 복구 코드는 같은 창에서 볼 수 있습니다.
- **랭킹**: 캠프의 🏆 랭킹 탭. 최고 스테이지순 / 결투 점수순으로 볼 수 있습니다.
- **결투**: 랭킹에서 다른 기사의 ⚔️ 결투 버튼. 두 기사가 서버에 저장된 능력치(원정 버프 제외)로 자동으로 싸우고, 서버가 계산한 결과를 캠프 창에서 재생합니다. 이기면 상대의 결투 점수(Elo, 시작 1000)를 가져옵니다. 결투는 5초에 한 번.

## 보스 레이드

- 캠프의 🐉 레이드 탭. **1~4명**이 파티를 짜서 보스를 잡습니다. 방 목록에서 들어가거나 보스를 골라 방을 만들고, 파티원이 모두 ✅ 준비하면 방장이 출정합니다.
- 로비(방 목록·참가·준비·출정)는 서버가 들고 있고, 방에 있는 동안 2초마다 상태를 주고받습니다. 90초 동안 소식이 없으면 방에서 나간 것으로 봅니다.
- 전투는 결투처럼 서버가 파티원들의 **저장된 능력치**로 끝까지 계산하고, 모두의 캠프 앞 하단바에서 같은 전투가 재생됩니다. 보스는 주로 맨 앞 기사를 때리고, 몇 초마다 전원에게 광역기를 씁니다. 75초가 지나면 광폭해지고 120초 안에 못 잡으면 실패.
- **난이도**: 보스마다 한 구간의 목표가 되도록 맞췄습니다. 그 보스를 열자마자는 4명이 모여도 어렵고, 4인 파티는 입장 스테이지 +3~5, 2인은 +6, 혼자는 +8~10쯤부터 잡을 수 있습니다 (뒤 보스일수록 조금씩 더 빡빡함). 파티 인원이 늘어도 보스 체력은 조금만(4인 1.3배) 늘어서 모일수록 확실히 유리합니다.
- **입장권**: 출정할 때 1장 소모. 매일(자정 기준) 3장보다 적으면 3장까지 무료로 채워지고, 그 이상은 골드·마력석으로 삽니다. 하루에 살수록 1.6배씩 비싸지며(자정 초기화) 최대 5장까지 보유.
- **정산**: 파티원별 피해량·받아 낸 피해·회복과 기여도(피해 75% + 받아 낸 피해 15% + 회복 10%)를 보여 주고, 기여도 1위가 **MVP — 재화 1.5배**. 이기면 그 보스의 **처치 상자**를 받고, 정산 화면에서 열면 높은 등급 장비가 쏟아집니다. 지면 재화 25%만.

| 👑 슬라임 킹 | 10 | 고급~전설 (희귀 위주) | 말랑 젤리 철퇴 · 점액 왕의 망토 · 슬라임 킹의 왕관 |

- **고유 장비**는 그 보스의 처치 상자에서만 나오고, 강화와 별개로 붙는 특수 효과(공격력·체력·공속·치명·받는 피해 감소·타격 회복·골드/경험치 획득 증가)가 있습니다. 등급도 보스를 따라 오릅니다 (슬라임 킹 영웅 → 고블린 족장·리치 킹 전설 → 늪의 군주·화염룡 신화 → 서리 거인 초월 → 마왕 태초). 고유 장비는 원래 등급 대신 별도의 **🔗 세트** 등급(초록·금색)으로 표시되고, 상세에 원래 등급(능력치 기준)이 '○○급 능력치'로 나옵니다. 반지 칸은 왕관·목걸이도 끼는 **장신구** 칸이 됐습니다.
- **첫 처치 보상**: 보스를 처음 잡으면 그 처치 상자에 고유 장비 1부위가 확정으로 들어 있습니다(아직 없는 부위 우선). 그 뒤로는 상자당 3~6%로 잘 안 나옵니다.
- **세트 효과**: 같은 보스의 고유 장비(무기·갑옷·장신구)를 2부위·3부위 끼면 세트 효과가 붙습니다. 예) 슬라임 왕가 2세트 체력 +8% / 3세트 공격력 +8% · 공속 +5%, 마왕의 권능 2세트 공격력 +20% · 체력 +15% / 3세트 공속 +15% · 치명 +8% · 치명 피해 +50% · 받는 피해 -5%. 자동 장착은 세트를 따지지 않으니 세트를 맞췄다면 자동 장착을 꺼 두세요.
- 보스 수치는 `server/raid.js`의 `RAID_BOSSES`, 이름·외형·상자·입장권 값은 `src/data.js`의 `RAID_BOSSES` (두 표의 id·stage 는 같아야 함).

## 전직 트리

```
                    견습 기사
        ┌──────────────┼──────────────┐
  Lv20  검사            창기사           레인저
       ┌─┴─┐          ┌─┴─┐          ┌─┴─┐
  Lv45 성기사 검성     용기병 할버디어   저격수 마궁수
```

- 캠프의 ⚜️ 전직 탭에서 합니다. 1차는 Lv 20 · 💎10 · 골드 500, 2차는 Lv 45 · 💎80 · 골드 50K가 필요하고, 되돌릴 수 없습니다.
- 직업마다 외형(투구·갑옷·색·망토/방패/후광), 무기, 공격 모션, 이펙트가 다릅니다.

## 구조

| 파일 | 역할 |
|---|---|
| `main.js` | 투명 오버레이 창, 클릭 통과, 캠프 모드(창을 화면 전체로 확장), 메뉴바 아이콘 |
| `preload.js` | 렌더러 ↔ 메인 IPC |
| `index.html` | HUD·캠프 창 마크업과 스타일 |
| `src/data.js` | 밸런스 수치, 건물·보급품·전리품·장비·강화 테이블, 도트 스프라이트 |
| `src/classes.js` | 전직 트리: 무기, 전직 조건, 직업별 스탯 보정과 외형 |
| `src/gear.js` | 전리품 뽑기, 가방 정산, 장비 장착·판매·강화 규칙. DOM을 모름 (core.js 보다 먼저 로드) |
| `src/raid.js` | 레이드 입장권, 결과 정산(보상·MVP), 처치 상자 열기. DOM을 모름 (core.js 보다 먼저 로드) |
| `src/core.js` | 게임 규칙 (상태·저장, 스탯 계산, 원정·전리품 드랍·건설, 오프라인 시뮬레이션). DOM을 모름 |
| `src/world.js` | 하단바 실시간 전투·이동·렌더링, 결투·레이드 재생 |
| `src/net.js` | 서버 통신: 계정(닉네임·토큰), 세이브 동기화, 랭킹, 결투 요청, 레이드 로비 |
| `src/ui.js` | HUD, 캠프 창(랭킹·레이드 로비·정산 포함), 계정 창, 알림, 부팅/메인 루프 |
| `server/index.js` | 서버 API (의존성은 `pg` 하나) |
| `server/store.js` | 저장소: `DATABASE_URL`이 있으면 Postgres, 없으면 `DATA_DIR`의 JSON 파일 |
| `server/duel.js` | 결투 시뮬레이션과 결투 점수(Elo) |
| `server/raid.js` | 레이드 보스 수치와 파티 전투 시뮬레이션 (로비는 `server/index.js`, 서버 메모리) |
| `render.yaml` | Render 배포 설정 (웹 서비스 + Postgres) |

### 직업 추가하기
- `src/classes.js`에서 `WEAPONS`에 무기를, `BODY`에 몸통 스프라이트를, `CLASSES`에 직업(스탯 보정 `mods`, 외형 `look`, 부모 `from`)을 추가하고 `CLASS_TREE`에 배치합니다.
- 전투 수치는 `core.js`의 `stats()` 한 곳에서 합칩니다.
- 기존 모션(`swing`·`dual`·`thrust`·`sweep`·원거리)에 없는 새 공격 방식이 필요하면 `world.js`의 `drawWeapon`과 `releaseAttack`에 추가합니다.

## 개발용 환경 변수

| 변수 | 설명 |
|---|---|
| `KB_SPEED=20` | 스태미나·휴식·건설 시간을 20배속 |
| `KB_USER_DATA=/경로` | 세이브를 별도 폴더에 둠 (실제 세이브 보호) |
| `KB_SNAPSHOT=/경로/a.png` | `KB_SNAPSHOT_DELAY`ms 뒤 창을 PNG로 저장 |
| `KB_SERVER=http://localhost:3000` | 접속할 서버 주소 (기본 `https://knight-bar.onrender.com`, `settings.json`의 `serverUrl`로도 지정 가능) |
| `KB_EVAL='js'` | 로드 1초 뒤 렌더러에서 실행 (예: `depart(); simulate(2400); openCamp()`) |

```
KB_SPEED=20 KB_USER_DATA=/tmp/kb npm start
```

## 서버

로컬에서 띄우기 (DB 없이 `server/data/accounts.json`에 저장):

```
cd server && npm install && npm start
KB_SERVER=http://localhost:3000 KB_USER_DATA=/tmp/kb npm start
```

| API | 설명 |
|---|---|
| `GET /api/nickname?name=` | 닉네임 사용 가능 여부 |
| `POST /api/accounts` | `{ nickname, state?, profile? }` → `{ nickname, token }`. 중복이면 409 |
| `GET /api/me` · `PUT /api/me` | 내 세이브 읽기/쓰기 (`Authorization: Bearer <token>`) |
| `GET /api/ranking?sort=stage\|duel` | 상위 100명 + (인증 시) 내 순위 |
| `POST /api/duels` | `{ opponent }` → 결투 결과와 재생 기록 |

토큰(복구 코드)은 서버에 SHA-256 해시로만 저장됩니다.

### Render 배포 (DB는 Supabase)

1. **Supabase**에서 프로젝트를 만들고 Connect → **Session pooler** 연결 문자열(`postgresql://postgres.xxxx:[비밀번호]@aws-...pooler.supabase.com:5432/postgres`)을 복사합니다. Render는 IPv6를 못 쓰므로 Direct connection 대신 pooler 주소를 씁니다.
2. Render 대시보드 → **New → Blueprint** → 이 저장소를 선택하면 `render.yaml`대로 웹 서비스(`knight-bar`)가 만들어집니다.
3. `knight-bar` → **Environment**에서 `DATABASE_URL`에 1의 연결 문자열을 넣습니다. 테이블은 서버가 처음 뜰 때 자동으로 만듭니다.
4. 서비스 주소가 `https://knight-bar.onrender.com`이 아니면 `src/net.js`의 `DEFAULT_SERVER`를 바꾸거나 `KB_SERVER`로 지정합니다.

- 무료 웹 서비스는 15분간 요청이 없으면 잠들고, 첫 요청에 깨어나는 데 1분쯤 걸립니다. 클라이언트는 이를 감안해 계정·랭킹 요청을 최대 70초까지 기다립니다.
- Render 무료 웹 서비스의 디스크는 재시작마다 비워지므로, Render에서 `DATABASE_URL`이 없으면 서버는 파일 저장으로 넘어가지 않고 시작을 멈춥니다.
- Supabase 무료 프로젝트는 일정 기간 활동이 없으면 일시 중지될 수 있습니다(대시보드에서 다시 켤 수 있음).
